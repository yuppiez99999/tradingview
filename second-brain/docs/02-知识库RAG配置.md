# 知识库（RAG）配置

> 知识库让 AI 在回答前**先检索你的笔记**，从而基于你的真实知识作答。

---

## 什么是知识库 RAG？

RAG = Retrieval-Augmented Generation（检索增强生成）。

原理：你的笔记被切分成小块 → 每块转换成向量嵌入 → 存入向量数据库。
当你在对话中提问时，AI 先检索最相关的笔记片段，再基于这些内容回答。

效果：AI 的回答不再凭空编造，而是基于**你自己的知识**。

---

## 创建知识库

### 在 Cherry Studio 中操作

1. 左侧点 **知识库** 标签页
2. 点 **+ 添加知识库**
3. 填写信息：

| 字段 | 建议值 |
|------|--------|
| 名称 | `第二大脑` |
| 类型 | 本地目录 |
| 路径 | `C:\Users\Administrator\ZCodeProject\second-brain` |
| 嵌入模型 | 你已有的 embedding 模型 |

### 嵌入模型选择

| 模型 | 来源 | 说明 |
|------|------|------|
| text-embedding-3-small | OpenAI | 便宜、速度快、效果好 |
| embedding-3 | 智谱 BigModel | 国产、中文友好 |
| bge-large-zh | 本地部署 | 完全离线，但需要本地模型服务 |

**要求**：对应的模型 API Key 需要在 Cherry Studio 的「模型服务」里先配好。

---

## 分块设置（高级）

嵌入前，笔记会被切成小块。不同内容建议不同块大小：

| 内容类型 | 块大小 | 重叠 | 说明 |
|----------|--------|------|------|
| 短笔记/想法 | 500 字符 | 50 | 避免一个块包含多个不相关主题 |
| 技术文档 | 800 字符 | 100 | 保持代码片段完整 |
| 长文章/读书笔记 | 1000 字符 | 150 | 中文笔记建议偏大 |
| 每日笔记 | 600 字符 | 80 | 通常较短 |

> Cherry Studio 默认设置对大多数场景已够用，初期不必调。

## 在对话中使用

### 方式一：手动 @

在对话输入框上方点 **@** → 选择知识库 `第二大脑` → 输入问题。

AI 会先检索相关笔记，再基于检索结果回答。

### 方式二：自动关联

在助手设置里，把知识库设为**默认启用**，每次对话自动检索。

### 检索效果优化建议

- **提问具体化**：「我在健康领域记过什么」比「健康」检索效果更好
- **保持笔记结构化**：有标题、分点、标签的内容更容易被精准匹配
- **定期刷新嵌入**：笔记变动后点知识库旁的**刷新按钮**重新嵌入

---

## 注意事项

1. **知识库 ≠ 实时同步**：笔记改了要手动刷新嵌入（或 Cherry Studio 自动检测变更）
2. **嵌入消耗 token**：大量笔记首次嵌入可能需要一些时间和 API 调用
3. **隐私安全**：笔记内容通过嵌入 API 处理，确认你信任对应的模型提供商
4. **检索质量取决于笔记质量**：结构清晰、标签准确的笔记检索效果更好
