# 第二大脑日常工作流

## 📋 每日工作流程

### 1. 早晨 (10分钟)
- **清点 Inbox**: 检查 `0-Inbox/` 目录，将昨日收集的信息分类整理
- **检查项目进度**: 快速浏览 `1-Projects/` 中的活跃项目
- **记录今日计划**: 在 `Daily/` 中创建当日计划

### 2. 工作中 (随时)
- **捕获想法**: 遇到任何想法、灵感、待办事项，直接说 "记一下：[内容]"
- **会议记录**: 开会时使用 "开会：[主题]" 指令自动创建会议记录
- **信息收集**: 遇到有用信息，使用 "剪藏：[要点]" 保存到资源库
- **任务跟踪**: 在项目中跟踪任务完成情况

### 3. 每日结束 (15分钟)
- **整理收件箱**: 将 Inbox 中待处理的信息分类到相应目录
- **更新项目**: 记录当日项目进展
- **记录学习**: 将学到的新知识整理到资源库
- **明日规划**: 在 Daily 中规划次日重点任务

## 🔄 PARA 分类法使用指南

### Projects (1-Projects/) - 有明确目标的项目
- **特点**: 有截止日期、有明确目标、需要多步完成
- **示例**: "新项目：开发个人博客系统，目标是三个月内上线"
- **文件名**: `YYYY-MM-DD-项目名称.md`
- **状态**: active | done | paused

### Areas (2-Areas/) - 长期维护的领域
- **特点**: 持续关注、长期发展的领域
- **示例**: "个人成长"、"技术学习"、"健康管理"
- **文件名**: `YYYY-MM-DD-领域主题.md`
- **无需状态**: 除非明确暂停

### Resources (3-Resources/) - 参考资料
- **特点**: 有价值的可重用信息
- **子分类**:
  - 读书笔记: `3-Resources/读书笔记/`
  - 文章剪藏: `3-Resources/文章剪藏/`
  - 工具资源: `3-Resources/工具资源/`
  - 学习资料: `3-Resources/学习资料/`
- **文件名**: `YYYY-MM-DD-标题.md`

### Archives (4-Archives/) - 已完成/不再活跃
- **用途**: 存放已完成的项目、不再关注的领域、过时的资源
- **保留理由**: 未来可能需要参考历史记录

### Inbox (0-Inbox/) - 待处理入口
- **用途**: 所有新信息的临时存放处
- **处理原则**: 当日内必须分类整理，不应长期堆积

## 🎯 常用场景处理

```
你: "记一下：可以用 AI 帮助自动生成项目周报"
AI: 创建 `0-Inbox/2026-06-29-想法-AI自动生成周报.md`
```

### 场景 2: 开始新项目
```
你: "新项目：学习 Rust 编程，目标是一个月内能编写小工具"
AI: 创建 `1-Projects/2026-06-29-学习Rust编程.md`（使用项目模板）
```

```
你: "开会：产品规划会议，参会人有张三、李四，讨论下季度产品路线图"
AI: 创建对应会议记录，包含参会人、讨论要点、决议、行动项
```

### 场景 4: 整理学习资料


### 场景 5: 周回顾
```
你: "周回顾"
AI: 分析 Inbox、Projects、Areas，生成总结报告和下周建议
```

## 🛠️ 高级功能

### 1. 跨会话记忆 (Memory MCP)
- **功能**: 自动记住人名、项目、关系等，在不同对话中保持记忆
- **自动触发**: 当你提到人物、项目关系时自动记录
- **手动查询**: "我之前关于 XX 记过什么？"

### 2. 智能检索 (知识库 RAG)
- **功能**: AI 回答时会先检索你的相关知识库
- **使用方法**: 在对话上方点击 `@` 选择「第二大脑」知识库
- **自动关联**: 检索结果会自动引用相关笔记

### 3. 文件智能操作 (Filesystem MCP)
- **功能**: AI 可以直接读取、编辑、创建知识库中的文件
- **智能分类**: 自动根据内容类型选择合适的目录和模板
- **双向链接**: 自动在笔记间建立关联链接

## 📊 效率提升技巧

### 1. 批量处理
- 每固定时间（如午休、下班前）集中处理 Inbox
- 使用 "清理 Inbox" 指令批量整理

### 2. 模板复用
- 善用 Templates 中的模板快速创建标准化文档
- 根据需要自定义模板，如模板项目中添加特定字段

### 3. 标签管理
- 建立统一的标签体系，便于检索和分类
- 避免过多标签，保持简洁实用

### 4. 定期回顾
- **每日**: 快速查看当日进展
- **每周**: 详细回顾项目进展和学习收获
- **每月**: 评估目标完成情况，调整下月计划

## 🚀 进阶使用模式

### 1. 项目管理增强
- 在项目笔记中添加 `## 📊 进度跟踪` 部分
- 定期更新任务完成情况
- 记录项目里程碑和重要决策

### 2. 知识网络构建
- 主动在笔记间建立关联
- 使用 `## 🔗 相关链接` 区块创建知识图谱
- 定期梳理相关主题，形成知识体系

### 3. 个人成长追踪
- 在 Areas 中记录技能发展
- 定期回顾学习进展
- 建立个人知识库的索引目录
