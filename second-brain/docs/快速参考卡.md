# 第二大脑快速参考卡

## 🚀 基础指令

### 信息捕获
| 指令 | 功能 | 示例 |
|------|------|------|
| "记一下：[内容]" | 保存想法到 Inbox | "记一下：可以用AI帮助写周报" |
| "新项目：[名称]，目标是[目标]" | 创建新项目 | "新项目：学习Python，目标是数据分析" |
| "开会：[主题]，参会人有[人员]" | 创建会议记录 | "开会：产品规划，参会人有张三、李四" |
| "读书笔记：《[书名]》[内容]" | 保存读书笔记 | "读书笔记：《设计模式》单例模式特点" |
| "剪藏：[要点]" | 保存文章剪藏 | "剪藏：AI发展趋势：大模型、多模态" |

### 信息查询
| 指令 | 功能 | 示例 |
|------|------|------|
| "我之前关于XX记过什么？" | 查询历史记录 | "我之前关于AI记过什么？" |
| "我之前关于张三有什么记录？" | 查询人物信息 | "我之前关于张三有什么记录？" |
| "查看[项目名称]进度" | 查询项目状态 | "查看学习Python进度" |
| "帮我找找[关键词]" | 智能检索知识库 | "帮我找找机器学习相关内容" |

### 系统管理
| 指令 | 功能 | 示例 |
|------|------|------|
| "周回顾" | 生成周度回顾 | "周回顾" |
| "月回顾" | 生成月度回顾 | "月回顾" |
| "清空Inbox" | 整理待处理信息 | "清空Inbox" |
| "更新项目[名称]进度" | 更新项目状态 | "更新项目学习Python进度" |

## 📁 PARA 目录速查

### 0-Inbox/ - 待处理信息
- 所有新信息的临时存放处
- 当日内必须分类整理
- **指令**: "记一下：[内容]"

### 1-Projects/ - 有明确目标的项目
- 有截止日期、多步完成的目标
- 文件名: `YYYY-MM-DD-项目名称.md`
- **指令**: "新项目：[名称]，目标是[目标]"

### 2-Areas/ - 长期维护的领域
- 持续关注、长期发展的领域
- 文件名: `YYYY-MM-DD-领域主题.md`
- **指令**: "记录[领域]相关内容"

### 3-Resources/ - 参考资料
- 有价值的可重用信息
- 子分类:
  - 读书笔记: `3-Resources/读书笔记/`
  - 文章剪藏: `3-Resources/文章剪藏/`
  - 工具资源: `3-Resources/工具资源/`
- **指令**: "读书笔记：《[书名]》"

### 4-Archives/ - 已完成/不再活跃
- 已完成的项目、过时的资源
- **自动归档**: 项目完成时自动移动

### Daily/ - 每日记录
- 日常计划、总结、随笔
- 文件名: `YYYY-MM-DD.md`
- **指令**: "今日计划"、"今日总结"

## 🎯 标签系统

### 常用标签
- **项目相关**: project, active, done, paused
- **个人领域**: career, health, finance, family
- **技术分类**: programming, ai, ml, web
- **内容类型**: idea, note, meeting, resource
- **优先级**: high, medium, low
- **状态跟踪**: todo, in-progress, review

## 🔗 核心功能

### 1. 智能分类
- 自动识别内容类型
- 选择合适的目录和模板
- 建立笔记间关联

### 2. 跨会话记忆
- 记住人物关系和项目背景
- 提供上下文相关建议
- 持续积累知识图谱

### 3. 知识检索
- 基于向量嵌入的智能检索
- 结合记忆库的关联检索
- 标注信息来源

### 4. 自动提醒
- 项目进度跟踪
- 截止日期提醒
- 定期回顾建议

## ⚡ 快捷操作

### 日常使用
- **早晨**: "帮我查看今天的计划和项目进度"
- **工作中**: "记一下：[想法]" / "开会：[主题]"
- **下班前**: "今日总结" / "清空Inbox"

### 项目管理
- **启动**: "新项目：[名称]，目标是[目标]"
- **跟踪**: "查看[项目名称]进度"
- **更新**: "更新项目[名称]进展"

### 学习成长
- **记录**: "读书笔记：《[书名]》"
- **总结**: "周回顾" / "月回顾"
- **查询**: "我之前关于XX记过什么？"
