# 日常工作流

> 第二大脑的日常使用节奏：捕获 → 整理 → 检索 → 表达。

---

## 每日（5 分钟）

### 随时捕获
任何想法、链接、会议要点、灵感——**立刻发给 AI，别先分类**。

对「第二大脑管家」说：

| 你说 | AI 做什么 |
|------|----------|
| "记到 Inbox：以后用 AI 自动化周报" | 创建 `0-Inbox/2026-06-29-AI自动化周报.md` |
| "记住：张三今天说下周一交设计稿" | memory 存关系：张三→下周一→设计稿 |
| "剪藏这段：[粘贴内容]" | 创建 `0-Inbox/` 笔记，打上标签 |
| "读书笔记：《原子习惯》：核心观点是……" | 创建 `3-Resources/读书笔记/` 笔记 |
| "新项目：学 Rust，目标是写一个 CLI 工具" | 用项目模板创建 `1-Projects/` 笔记 |

### 关键原则
- **零摩擦捕获**：想记就记，不要「等一下再说」
- **先 Inbox 后整理**：来不及分类的先进 0-Inbox
- **让 AI 做苦力**：格式化、标签、归类交给 AI

---

## 每周回顾（30 分钟，建议周日）

对 AI 说：
> "帮我做本周回顾"

AI 会自动执行：
1. 读取 `0-Inbox/`，列出待整理项
2. 检查 `1-Projects/` 各项目进度
3. 提示停滞的项目（超过 7 天没更新的）
4. 建议归档已完成的项目
5. 生成本周回顾笔记到 `Daily/`

你也可以更具体地引导：
> "看看 Inbox 里有什么没整理的"
> "项目 X 进度怎么样了？"
> "有没有暂停太久的项目需要重新评估？"

---

## 每月回顾（1 小时，建议月底）

> "帮我做本月回顾"

AI 执行：
1. 汇总本月所有周回顾
2. 分析各领域的活跃度
3. 提示需要关注的领域
4. 生成月度总结

---

## 捕获指令速查

```
"记到 Inbox：XXX"           → 0-Inbox/
"新项目：XXX，目标是YYY"    → 1-Projects/（项目模板）
"更新项目 XXX：完成了YYY"   → 更新已有项目笔记
"读书笔记：《书名》：要点…"  → 3-Resources/读书笔记/
"剪藏：[内容]，来源是 [URL]"→ 3-Resources/文章剪藏/
"开会记录：XXX 会议，要点…" → 项目下或 3-Resources/
"记住：AAA 是 BBB 的 CCC"  → memory 创建实体+关系
"忘掉：XXX"                → memory 删除
```

---

## 检索指令速查

确保对话中 **@第二大脑 知识库** 已启用。

```
"我之前关于 XX 记过什么？"     → 知识库检索
"张三是谁？"                    → memory 查询
"总结我所有关于 YY 的笔记"      → 知识库检索 + AI 总结
"这个月我在健康领域做了什么？"  → 知识库按时间+领域过滤
"有什么项目快到期了？"           → 扫描 1-Projects/ 中的 deadline
```
