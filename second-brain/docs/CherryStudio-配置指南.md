## 🚀 下一步：在 Cherry Studio 中配置

### 步骤 1: 导入 MCP 服务器配置

1. 打开 Cherry Studio
2. 点击左下角 **设置 ⚙️**
3. 左侧选择 **MCP 服务器**
4. 点击右上角 **编辑 JSON**（或切换到 JSON 模式）
5. 将 `config/mcp-servers.json` 的内容完整复制粘贴进去
6. 保存配置

**验证连接**：
- 保存后，每个服务器旁边应显示 **绿色 ✓ 已连接**
- 如果显示红色，请检查：
  - Node.js 是否已安装（版本 v18+）
  - 网络连接是否正常（首次运行会下载包）

### 步骤 2: 创建知识库「第二大脑」

1. Cherry Studio 左侧点击 **知识库** 标签页
2. 点击 **+ 添加知识库**
3. 填写以下信息：
   - **名称**: `第二大脑`
   - **类型**: 选择 **本地目录**
   - **路径**: `C:\Users\Administrator\ZCodeProject\second-brain`
   - **嵌入模型**: 选择你已有的模型（推荐智谱 embedding 或 OpenAI text-embedding-3）
4. 点击保存，等待索引完成

### 步骤 3: 创建助手「第二大脑管家」

1. Cherry Studio 左侧点击 **助手** 标签页
2. 点击 **+ 创建助手**
3. 填写以下信息：
   - **名称**: `第二大脑管家`
   - **系统提示词**: 将 `config/agent-prompt.md` 的内容粘贴进来
   - **模型**: 选择 GLM-4.5-AIR 或 GLM-5-Turbo（或其他你喜欢的模型）
4. 在 **MCP 工具** 部分：
   - 确保 **memory** 和 **filesystem** 开关已打开
5. 保存助手

## 🔧 故障排除

### MCP 服务器连接失败
1. 打开命令行运行：`npx -y @modelcontextprotocol/server-memory`
2. 如果报错，请检查 Node.js 版本是否 >= 18
3. 确保网络连接正常

### 知识库检索不到内容
1. 确保笔记已创建
2. 点击知识库旁边的 **刷新按钮** 重新嵌入
3. 检查文件路径是否正确

### Memory 记不住东西
1. 确认 `config/memory.json` 文件存在
2. 确认对话中 MCP memory 工具已启用
3. 尝试在对话中使用 memory 相关指令
