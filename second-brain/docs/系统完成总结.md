## 🚀 立即开始使用

### 步骤 1: 导入配置到 Cherry Studio
1. 打开 Cherry Studio → 设置 → MCP 服务器
2. 编辑 JSON → 复制 `config/mcp-servers.json` 内容
3. 保存，确认服务器连接成功

### 步骤 2: 创建知识库
1. 知识库标签页 → + 添加知识库
2. 名称：`第二大脑`
3. 类型：本地目录
4. 路径：`C:\Users\Administrator\ZCodeProject\second-brain`

### 步骤 3: 创建助手
1. 助手标签页 → + 创建助手
2. 名称：`第二大脑管家`
3. 系统提示词：复制 `config/agent-prompt.md` 内容
4. 开启 memory 和 filesystem 工具
