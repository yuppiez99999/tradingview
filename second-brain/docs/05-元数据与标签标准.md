# 元数据与标签标准

> 规范笔记的 frontmatter 和标签，让知识库检索更精准。

---

## YAML Frontmatter

每篇笔记开头用 YAML 格式写元数据，AI 和 Cherry Studio 都能解析。

### 完整字段说明

```yaml
---
title: 笔记标题                    # 必填，简明扼要
date: 2026-06-29                   # 必填，创建日期
updated: 2026-06-29                # 可选，最后修改日期
type: project                      # 必填，见下方类型枚举
tags: [tag1, tag2, tag3]           # 必填，至少一个标签
status: active                     # project/inbox 类型必填
deadline: 2026-07-31               # 可选，仅 project 类型
source: https://example.com        # 可选，信息来源（URL/书名/会议名）
related: [其他笔记文件名]          # 可选，关联笔记
---
```

### type 类型枚举

| 类型 | 说明 | 对应目录 |
|------|------|----------|
| `project` | 有目标有截止日期 | `1-Projects/` |
| `area` | 长期维护的领域 | `2-Areas/` |
| `resource` | 参考资料 | `3-Resources/` |
| `archive` | 已归档 | `4-Archives/` |
| `inbox` | 待整理 | `0-Inbox/` |
| `daily` | 每日笔记 | `Daily/` |
| `meeting` | 会议记录 | 项目下或 Resources 下 |

### status 状态枚举

| 状态 | 说明 |
|------|------|
| `active` | 进行中 |
| `paused` | 暂停 |
| `done` | 已完成 |

## 标签命名规范

### 规则
- 全小写
- 多词用连字符连接：`machine-learning`
- 中英文均可，但同一概念统一用一种语言
- 不要用嵌套层级，用扁平标签 + 组合

### 常用标签清单

```
# 内容类型
meeting-notes      会议记录
book-notes         读书笔记
article-clip       文章剪藏
tutorial          教程
cheatsheet         速查表
idea              灵感/想法

# 技术领域
ai                人工智能
llm               大语言模型
prompt-engineering 提示工程
rag               检索增强生成
mcp               模型上下文协议
python            Python
web               Web 开发
data-analysis     数据分析

# 工作
project-planning  项目规划
team-management   团队管理
communication     沟通协作

# 生活
health            健康
finance           财务
learning          学习
career            职业发展
tool              工具推荐
```

> 建议把这份标签清单另存为 `3-Resources/工具清单/标签表.md`，方便随时查阅和增补。

## 文件命名规范

| 类型 | 格式 | 示例 |
|------|------|------|
| Inbox 条目 | `YYYY-MM-DD-简短标题.md` | `2026-06-29-AI自动化周报.md` |
| 项目 | `YYYY-项目名.md` | `2026-学习Rust.md` |
| 每日笔记 | `YYYY-MM-DD.md` | `2026-06-29.md` |
| 读书笔记 | `书名-读书笔记.md` | `原子习惯-读书笔记.md` |
| 文章剪藏 | `YYYY-MM-DD-文章标题.md` | `2026-06-29-RAG原理解析.md` |
| 会议记录 | `YYYY-MM-DD-会议主题.md` | `2026-06-29-产品周会.md` |
| 周回顾 | `YYYY-WNN-周回顾.md` | `2026-W26-周回顾.md` |

## 笔记内部结构模板

```markdown
---
title: 笔记标题
date: YYYY-MM-DD
type: resource
tags: [tag1, tag2]
source:
---

# 笔记标题

## 摘要
一句话概括这篇笔记的核心内容。

## 正文
（内容区域）

## 要点
- 要点 1
- 要点 2
- 要点 3

## 行动项
- [ ] 行动 1
- [ ] 行动 2

## 相关链接
- [[相关笔记1]]
- [[相关笔记2]]
```

## AI 生成笔记时自动遵守

当你通过「第二大脑管家」让 AI 创建笔记时，AI 会自动：
1. 使用正确的 YAML frontmatter
2. 按命名规范起文件名
3. 存放到正确的 PARA 目录
4. 打上合理的标签
5. 在末尾添加「相关链接」区块

你只需要告诉 AI 内容，格式化的事交给它。
