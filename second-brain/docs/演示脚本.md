# 深度学习入门

## 第三章：反向传播算法

### 核心概念
反向传播是训练神经网络的核心算法，通过计算损失函数对各参数的梯度来更新网络权重。

### 算法步骤
1. 前向传播计算预测值
2. 计算损失函数
3. 反向传播计算梯度
4. 更新参数

### 关键公式
- 损失函数：L = (y_pred - y_true)²
- 梯度：∂L/∂w = ∂L/∂a * ∂a/∂w

## 💡 理解要点
- 反向传播的本质是链式法则的应用
- 梯度下降是参数更新的基础方法
- 需要注意梯度消失和爆炸问题
