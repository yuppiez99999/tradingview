# 快速开始

> 零基础上手 Cherry Studio 第二大脑，按顺序做这三件事即可。

## 前置条件

1. 已安装 **Cherry Studio**（你已经在用了）
2. 已安装 **Node.js**（Cherry Studio 的 MCP 服务器需要 npx 来启动）
   - 下载：https://nodejs.org → 选 LTS 版本
   - 验证：打开命令行输入 `node --version`，能看到版本号就行

---

## 第一步：配置 MCP 服务器（5 分钟）

MCP 让 AI 能「记住」和「读写文件」，是第二大脑的双引擎。

1. 打开 Cherry Studio → 左下角 **设置 ⚙️**
2. 左侧选 **MCP 服务器**
3. 点右上角 **编辑 JSON**（或 JSON 模式切换）
4. 把 `config/mcp-servers.json` 的内容**整个复制粘贴进去**
5. 保存

保存后每个服务器旁边应显示**绿色 ✓ 已连接**。如果显示红色，
请确认 Node.js 已安装且 `npx` 命令可用。

> 💡 也可以手动添加：
> - 点 **+ 添加服务器**
> - Memory 服务器：名称 `memory`，命令 `npx`，参数 `-y @modelcontextprotocol/server-memory`
> - Filesystem 服务器：名称 `filesystem`，命令 `npx`，参数 `-y @modelcontextprotocol/server-filesystem C:\Users\Administrator\ZCodeProject\second-brain`

---

## 第二步：配置知识库（3 分钟）

知识库让 AI 回答前**先检索你的笔记**，基于你的真实知识作答。

1. Cherry Studio 左侧点 **知识库** 标签页
2. 点 **+ 添加知识库**
3. 名称填：`第二大脑`
4. 类型选 **本地目录**
5. 路径选：`C:\Users\Administrator\ZCodeProject\second-brain`
6. 嵌入模型选你已有的（推荐智谱 embedding 或 OpenAI text-embedding-3）
7. 点保存，等待索引完成

> 💡 使用时在对话输入框上方点 **@** 选择「第二大脑」知识库即可。

---

## 第三步：创建「第二大脑管家」助手（2 分钟）

1. Cherry Studio → 左侧 **助手** 标签页
2. 点 **+ 创建助手**
3. 名称：`第二大脑管家`
4. 把 `config/agent-prompt.md` 的内容**粘贴到系统提示词**里
5. 模型选你喜欢的（推荐 GLM-4.5-AIR 或 GLM-5-Turbo）
6. 底部的 MCP 工具开关：**打开 memory 和 filesystem**

保存。

---

## 🎉 完成！开始使用

新建对话 → 选「第二大脑管家」→ 试试这些指令：

| 你说 | AI 做什么 |
|------|-----------|
| "记住：我的同事张三负责后端开发" | 用 memory 存人脉关系 |
| "存一下这个想法：以后用 AI 自动化周报" | 创建 Inbox 笔记 |
| "新项目：学习 Rust，目标是一个月能写小工具" | 创建项目笔记（带模板） |
| "我之前记过什么？" | 检索知识库 + memory |
| "帮我做周回顾" | 清点 Inbox、检查项目进度、生成回顾 |

更多用法见 `docs/04-日常工作流.md`。

## ⚠️ 常见问题

**Q: MCP 服务器显示红色/连接失败**
A: 打开命令行运行 `npx -y @modelcontextprotocol/server-memory`，看是否报错。
最常见原因是 Node.js 未安装或版本太旧。

**Q: 知识库检索不到内容**
A: 笔记建好后需要点知识库旁边的**刷新按钮**重新嵌入。

**Q: memory 记不住东西 / 新会话忘掉了**
A: 确认 `memory.json` 文件路径正确，且对话中 MCP memory 工具已启用。
