## 详细逐项审计

### 规则 8: 前视偏差与幸存者偏差 —— 评级 C

**现状**: 回测脚本 (`backtest_current_portfolio.py`) 使用 Qlib 框架，但未见明确的财报实际披露日处理逻辑。Qlib 数据默认使用报告期截止日而非披露日。

**缺口**:
- 未验证 Qlib 数据中的 `ann_date` (披露日) 字段是否被正确使用
- 停牌处理未见显式逻辑
- 涨跌停限制未在回测模拟中体现

**建议**: 在回测配置中增加 `use_actual_announce_date=True` 参数，并在 `backtest.yaml` 中显式声明前视偏差检查开关。

### 规则 6: 技术栈与DevOps —— 评级 C+

**现状**: 全系统使用 Python，无 C++/Rust 组件。无 FPGA 硬件加速。日志使用标准 logging 模块，无结构化日志格式。无 PTP 时钟同步。

**缺口**:
- 全 Python 实现，无延迟分层 (超低延迟/中延迟/高延迟)
- `logger.py` (7.8KB) 存在但为统一封装，非工业级结构化日志
- 无分布式追踪 (tracing)
- CPU/内存监控依赖 `system_health_check.py` (7.1KB)，非专业监控栈 (Prometheus/Grafana)

**优势**:
- 有影子账户概念 (AI决策沙箱 `ai_decision_sandbox.py`)
- 有完整的 PowerShell 定时任务注册体系
- 有 `service_manager.ps1` 服务管理

### 规则 7: 过拟合防护 —— 评级 B-

**现状**: Qlib 训练器从 v3 到 v9 共 12 个迭代版本，`lgb_enhanced_trainer.py` (67KB) 和 `lgb_tscv_trainer.py` (30KB) 函数量较大。

**缺口**:
- 未见显式的 Purged K-Fold 交叉验证实现
- 未见参数敏感性分析模块
- 未见 BIC/MDL 复杂度惩罚
- 未见"样本外仅用一次"的原则性约束

**优势**:
- 有 TSCV (时间序列交叉验证) 训练器
- 已进行多次模型迭代 (v3→v9)，说明有持续改进意识

### 规则 9: 交易成本 —— 评级 B+

**现状**: `utils/transaction_cost_model.py` 实现了 Square-Root Law 市场冲击模型、波动率调整、佣金计算、机会成本。代码质量高、参数清晰。

**缺口**:
- 滑点未按大盘股/小盘股/微盘股分层
- 缺少容量模型 (策略容量天花板估计)
- 佣金率 万三 偏高 (实际可做到 万1.5-万2)

**优势**:
- Almgren-Chriss 风格的平方根冲击模型已实现
- 有参与率上限 (15%)
- 有波动率调整系数

### 规则 3: 风控多层防御 —— 评级 A-

**现状**: 风控体系是 v8.3 的核心亮点。`risk_guard_integrator.py` 实现四Guard联动，`kill_switch.py` 实现三级熔断，`stop_loss_monitor.py` 实现止损。

**优势**:
- 四层回撤响应 (5%/8%/12%/15%) 清晰分级
- 波动率目标缩仓 (AQR-style Vol Targeting)
- 三级熔断协议 (保证金 50%/75%/95%)
- 熔断事件记录到 JSONL 日志

**缺口**:
- 缺少事前微秒级风控检查 (受限于全Python架构)
- 撤单率监控未实现
- 无跨品种相关性崩溃检测
- `drawdown_controller.py` 被引用但未在代码中看到独立文件

### 规则 12/13: 期权对冲 —— 评级 A- / B+

**优势**:

## 优先改进建议 (Top 5)

1. **回测前视偏差修复** — 在回测配置中增加 `actual_announce_date` 检查，验证 Qlib 数据是否使用披露日而非报告截止日。这是最容易引入系统性偏差的问题。

2. **Purged K-Fold 交叉验证** — 为 LGB 训练器增加时序 Purged KFold，避免训练集和验证集之间的信息泄漏。当前 TSCV 实现需验证是否有 embargo 机制。

3. **滑点分层建模** — 在 `transaction_cost_model.py` 中按市值分组 (大/中/小/微盘) 设置不同的滑点参数，替代当前统一的 10bps。

4. **Vega 动态监控** — 在 `greek_hedge_manager.py` 中增加 Vega 的动态上限计算 (基于隐含波动率期限结构和 VIX 水平)，替代当前的静态 100000 上限。

5. **研产代码目录分离** — 将 v8.3 之前的 178 个归档文件移出主目录，建立 `src/research/` 和 `src/production/` 两个独立目录树。
