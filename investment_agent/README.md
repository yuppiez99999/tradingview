# 硅能智投智能投资代理系统

## 项目概述
硅能智投智能投资代理系统是专为"硅能智投"公司开发的AI驱动量化投资管理平台，管理300万投资规模的资产组合。

## 核心功能
- **智能投资决策**: AI驱动的投资决策引擎
- **组合管理**: 20个标的自动化管理（5 ETF + 14 股票 + 1 现金）
- **三级风控**: 个股止损、组合回撤控制、日内断路器
- **自动化任务**: 7类定时任务（盘前、盘中、盘后、周度、月度）
- **AI晨报生成**: 每日AI驱动的投资晨报
- **实时监控**: Streamlit监控面板

## 技术架构
- **数据层**: Wind金融终端 + AkShare备用
- **AI层**: 硅基流动 DeepSeek-V4 + 智谱AI备用
- **策略层**: 多因子模型 + 动量择时 + 风险平价
- **风控层**: 三级风控体系 + VaR计算
- **执行层**: 自动化订单管理 + 持仓追踪

## 快速开始

### 1. 安装依赖
```bash
pip install pandas numpy scipy scikit-learn requests
```

### 2. 配置API密钥
编辑 `config/config.py`，填入真实的API密钥：
```python
API_CONFIG = {
    'wind': {
        'username': 'your_wind_username',
        'password': 'your_wind_password',
        'api_key': 'your_wind_api_key',
    },
    'silicon_flow': {
        'api_key': 'your_siliconflow_api_key',
    },
}
```

### 3. 运行系统
```bash
python main.py
```

## 风险控制体系

### 第一级：个股止损
- 宽基ETF: -8%减半仓
- 科技股: -12%清仓
- 制造业: -10%清仓
- 防御股: -8%减半仓
- 黄金: -5%清仓

### 第二级：组合回撤控制
- -5%: 预警检查
- -8%: 仓位降至70%
- -10%: 仓位降至50%
- -15%: 全部止损

### 第三级：日内断路器
- 单日-3%: 停止买入
- 单日-5%: 强制减仓30%

## 自动化任务
1. **06:30** - 盘前数据采集
2. **06:40** - AI晨报生成
3. **08:30** - 盘前策略计算

5. **15:30** - 盘后数据归档
