# 云端部署小白教程 — 从零到第一个训练作业跑通

| 项 | 值 |
|---|---|
| 适用 | **完全没用过云、没碰过终端的小白** |
| 设备 | MacBook Pro M5 Max |
| 目标 | 跟着做完,在华为云上跑通一个量化训练,模型下载回 Mac |
| 耗时 | 4–6 小时(含等待,可分几天做) |

---

## 这个教程教你做什么(先读这段)

**用大白话说:** 你现在量化系统在 Mac 上跑,但有些大模型训练 Mac 跑不动或太慢。本教程教你把训练任务"搬"到华为云上去跑,跑完把训练好的模型"拿"回 Mac 用。

**打个比方:** 就像你家(本地 Mac)洗衣机太小洗不了大件,把大件送到洗衣店(华为云)洗,洗完拿回家。

**做完你会得到:** 一个在云端训练好的 LightGBM 模型文件,下载回 Mac 后能直接用。

**全程 13 步**,每步都有"做什么→怎么做→怎么确认做对了→避坑",跟着做就行。

---

## 开始前,你需要准备的东西

1. **你的 Mac**(M5 Max,能上网)
2. **一张身份证**(华为云要实名认证)
3. **一个手机号**(注册华为云用)
4. **一张银行卡或支付宝**(华为云要验证支付方式,但本教程花费约 ¥0.5,几乎不花钱)
5. **项目代码已在 Mac 上**(在 `~/28-终极量化交易系统8.4/` 目录,且数据在 `~/QuantData/`)

> ⚠️ **如果第 5 条没准备好:** 先把项目代码和数据放到 Mac 上。如果你是从 Windows 机器迁过来的,确保这两个文件夹存在:
> - `~/28-终极量化交易系统8.4/`(代码)
> - `~/QuantData/`(数据,里面有 `qlib_data/`、`data_cache/` 等)

## 第 1 步:注册华为云账号并实名认证

### 这一步做什么
在华为云注册一个账号,并用身份证实名认证。**没有实名认证,后面什么都做不了。**

### 怎么做

**1.1 打开华为云官网**

打开浏览器(Safari 或 Chrome),在地址栏输入:

    https://www.huaweicloud.com/

按回车。

**1.2 注册**

- 看页面右上角,有个"注册"按钮,点它
- 填你的手机号
- 点"获取验证码",手机收到短信,输入 6 位验证码
- 设一个密码(记下来!建议存到 Mac 的"备忘录"app 里)
- 勾选"我已阅读并同意"
- 点"注册"

**1.3 登录**

注册完会自动登录。如果没登录,右上角点"登录",输手机号+密码。

**1.4 实名认证(关键!)**

- 登录后,看页面右上角,点你的头像(或手机号)
- 弹出菜单里点"账号中心"
- 在左侧菜单找"实名认证",点它
- 选"个人认证"
- 填真实姓名、身份证号
- 上传身份证正面照片(点"上传"→ 选你电脑里的身份证照片)
- 上传身份证反面照片
- 点"提交"
- 可能要做人脸识别,对着摄像头按提示做

**1.5 等审核**

- 通常几秒钟到几分钟就通过
- 页面显示"实名认证:已通过"就对了
- 如果显示"审核中",等一会儿刷新页面

### 怎么确认做对了

- 页面右上角点头像 →"账号中心" → 看到"实名认证:已通过"✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| 手机号已注册 | 你之前注册过,直接"登录"或"找回密码" |
| 身份证照片传不上去 | 照片太大了,用 Mac 预览打开 → 导出 → 调小到 2MB 以内 |
| 实名认证不通过 | 确认姓名和身份证号完全一致;光线好的地方重拍身份证 |
| 一定要银行卡吗 | 实名认证不需要,但后面创建资源可能要绑定支付方式;在"费用中心"→"账户总览"→ 绑定 |

## 第 2 步:创建一个"子账号"并拿到密码钥匙(AK/SK)

### 这一步做什么
华为云给你一个"编程钥匙"(AK/SK),后面用命令行操作云的时候,要用这把钥匙证明"我是我"。

> **什么是 AK/SK?** AK 是"账号 ID"(像用户名),SK 是"密钥"(像密码)。两个合起来就是你的编程登录凭证。**SK 特别重要,只显示一次,一定要保存好!**

### 怎么做

**2.1 进入 IAM(统一身份认证)服务**

- 在华为云首页,看页面左上角,有个"控制台"按钮,点它
- 进入控制台后,左上角有个"服务列表"图标(三条横线 ≡),点它
- 在搜索框输入"IAM"
- 点搜索结果里的"统一身份认证服务 IAM"

**2.2 创建用户**

- 左侧菜单点"用户"
- 点右上角"创建用户"
- 填写:
  - **用户名:** 输入 `qt-admin`
  - **凭证类型:** 勾选"编程访问"(✅)和"管理控制台访问"(✅)
  - **密码:** 设一个密码,记下来(存备忘录)
  - **用户组:** 选 `admin`(如果没有,先点"创建用户组",名字叫 `admin`,给它所有权限)
- 点"确定"

**2.3 拿到 AK/SK(关键!立即保存)**

创建成功后,页面会弹出一个框,显示:

    AK:      XXXXXXXXXX...(一串字母数字)
    SK:      XXXXXXXXXX...(一串字母数字)

**⚠️ 这是 SK 唯一一次显示!关掉就再也看不到了!**

立即操作:
1. 把 AK 和 SK 都复制下来
2. 打开 Mac 的"终端"(下面第 3 步会教你怎么打开),但现在先复制保存

**保存到 Mac 钥匙串(最安全的方式):**

先打开终端(Spotlight 搜索 `终端` 或 `Terminal`,回车),在终端里输入(把 `你的AK` 换成实际 AK):

    security add-generic-password -a yuppiefree2025 -s huaweicloud_ak -w "你的AK"

按回车。再输入:

    security add-generic-password -a yuppiefree2025 -s huaweicloud_sk -w "你的SK"

按回车。

**2.4 给子账号权限**

- 左侧菜单点"用户组"
- 点 `admin` 组
- 点"权限管理"页签
- 点"添加权限"
- 搜索并添加这几个:
  - `OBS OperateAccess`(对象存储操作权限)
  - `ModelArts FullAccess`(AI 开发平台全部权限)
  - `SWR FullAccess`(容器镜像服务全部权限)
  - `CCE FullAccess`(容器引擎全部权限,可选)
- 点"确定"

### 怎么确认做对了

在终端输入:

    security find-generic-password -a yuppiefree2025 -s huaweicloud_ak -w

按回车,应该输出你的 AK(一串字母数字)。✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| 创建时没勾"编程访问",没有 AK/SK | IAM → 用户 → qt-admin →"修改"→ 勾选编程访问 → 重新生成 |
| SK 忘了没保存 | IAM → 用户 → qt-admin →"访问密钥"→ 删除旧的 → 新建 → 这次一定保存! |
| `admin` 组不存在 | 先创建用户组:`用户组`→`创建用户组`→ 名字 `admin` → 给所有权限 |
| 权限添加后还是报权限错误 | 等 1–2 分钟权限生效,再试 |

## 第 3 步:安装"终端工具"并连上华为云

### 这一步做什么
装一个叫"华为云 CLI"的命令行工具,让你能在终端里用命令操作华为云(而不是总要点网页)。

> **什么是 CLI?** Command Line Interface,命令行界面。就是在终端里输命令,代替点网页按钮。更快,且能写脚本自动化。

### 怎么做

**3.1 打开终端**

- 按 `Cmd + 空格`(同时按住 Command 键和空格键),弹出 Spotlight 搜索
- 输入 `终端` 或 `Terminal`
- 回车,打开终端窗口

> 以后所有带 `代码框` 的命令,都是在终端里输入,然后按回车。

**3.2 装 Homebrew(Mac 的"软件商店")**

在终端输入这一整行,按回车:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

**等几分钟**,它会下载安装。中间可能要你输 Mac 开机密码,输完按回车(输密码时屏幕不显示字符,正常的)。

**3.3 装华为云 CLI**

    brew install huaweicloud-cli

等几分钟。

**3.4 配置 CLI(告诉它你的钥匙)**

在终端输入这一整行(这是一条命令,全部复制粘贴进去),按回车:

    hcloud configure set --access-key=$(security find-generic-password -a yuppiefree2025 -s huaweicloud_ak -w) --secret-key=$(security find-generic-password -a yuppiefree2025 -s huaweicloud_sk -w) --region=cn-east-3

**3.5 验证连上了**

    hcloud IAMListUsers

按回车。

### 怎么确认做对了

第 3.5 步应该输出一串 JSON,里面有 `qt-admin` 这个用户名。✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| `brew: command not found` | Homebrew 没装好;重新跑 3.2 那条命令 |
| `hcloud: command not found` | 装完后路径没生效;输入 `export PATH="/opt/homebrew/bin:$PATH"` 再试 |
| `IAMListUsers` 报权限错误 | 回第 2 步,确认给 `admin` 组加了权限 |
| 3.4 那条命令报错 | 钥匙串里没存 AK/SK;回第 2.3 步重新存 |

## 第 4 步:在云上建两个"大桶"存数据(OBS)

### 这一步做什么
建两个"桶"(Bucket),一个存训练数据,一个存训练出来的模型。

> **什么是 OBS?** 对象存储服务。你可以理解成云上的"无限大硬盘"。你把数据传上去,训练时从里面读,训练完把模型存进去。

### 怎么做

**4.1 进入 OBS 服务**

- 华为云控制台 → 左上角 ≡ → 搜索 `OBS` → 点"对象存储服务 OBS"

**4.2 建第一个桶(存训练数据)**

- 左侧菜单点"并行文件系统"或"桶"(不同版本叫法不同)
- 点右上角"创建桶"
- 填写:
  - **桶名:** `qt-data`(如果提示被占用,改成 `qt-data-你的名字`,比如 `qt-data-zhangsan`)
  - **区域:** 选"华东-上海一"
  - **存储类别:** 选"标准存储"
  - **桶策略:** 选"私有"
- 点"立即创建"
- 看到"创建成功"提示

**4.3 建第二个桶(存训练出的模型)**

重复 4.2,桶名用 `qt-models`(同样,被占用就加后缀)。

**4.4 用命令验证**

在终端输入:

    hcloud OBSListBuckets

按回车。

### 怎么确认做对了

4.4 应该列出两个桶:`qt-data` 和 `qt-models`。✅

> ⚠️ **记住你的桶名!** 如果用了带后缀的名字(如 `qt-data-zhangsan`),后面所有命令里都要用这个完整名字。

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| 提示"请先开通服务" | 在 OBS 页面点"开通服务",需要实名认证(第 1 步) |
| 桶名被占用 | 桶名是全球唯一的(所有华为云用户共用),加你的名字后缀 |
| 找不到"创建桶" | 左侧菜单可能叫"并行文件系统",点它就有创建按钮 |

## 第 5 步:把训练数据传到云上

### 这一步做什么
把 Mac 上的训练数据(约 730MB)上传到 OBS 桶里,这样云端训练时能读到。

### 怎么做

**5.1 下载 obsutil(OBS 上传工具)**

在终端依次输入(每行输完按回车,等上一条执行完再输下一条):

    cd ~/Downloads

    curl -O https://obs-community.obs.cn-north-1.myhuaweicloud.com/obsutil/current/obsutil_darwin_arm64.tar.gz

    tar xzf obsutil_darwin_arm64.tar.gz

    sudo mv obsutil /usr/local/bin/

最后一条会要你输 Mac 开机密码,输了按回车。

**5.2 验证装好了**

    obsutil version

应该输出版本号。

**5.3 配置 obsutil(告诉它你的钥匙和地址)**

在终端输入这一整行,按回车:

    obsutil config -ak=$(security find-generic-password -a yuppiefree2025 -s huaweicloud_ak -w) -sk=$(security find-generic-password -a yuppiefree2025 -s huaweicloud_sk -w) -endpoint=obs.cn-east-3.myhuaweicloud.com

应该看到 `Set obsutil config successfully!`

**5.4 上传 Qlib 数据(270MB,约 2 分钟)**

    obsutil cp -r -f ~/QuantData/qlib_data/ obs://qt-data/qlib_data/

> 如果你桶名有后缀,把 `qt-data` 换成你的完整桶名。

等它跑完,会显示 `Upload [succeeded]`。

**5.5 上传行情数据(40MB)**

    obsutil cp -r -f ~/QuantData/data_cache/ obs://qt-data/data_cache/

**5.6 上传配置文件**

    obsutil cp -r -f ~/28-终极量化交易系统8.4/config/ obs://qt-data/config/

**5.7 验证上传成功**

    obsutil ls obs://qt-data/ -limit=10

### 怎么确认做对了

5.7 应该列出 `qlib_data/`、`data_cache/`、`config/` 三个文件夹。✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| `curl: (6) Could not resolve host` | 网络问题;换网络或用浏览器下载 obsutil(搜"华为云 obsutil 下载") |
| `obsutil: command not found` | `sudo mv` 没成功;直接用全路径 `~/Downloads/obsutil` 代替 `obsutil` |
| `Access Denied` | AK/SK 错或没权限;回第 2 步检查 |
| 上传很慢 | 家宽上传带宽小,730MB 正常要 5–15 分钟,耐心等 |
| `endpoint does not exist` | 地址拼错了;确认是 `obs.cn-east-3.myhuaweicloud.com`(注意有 `.myhuaweicloud.com`) |

## 第 6 步:在云上建一个"镜像仓库"(SWR)

### 这一步做什么
建一个存 Docker 镜像的地方。后面我们会把训练代码打包成镜像,存到这里,训练时从这里取。

> **什么是 Docker 镜像?** 你可以理解成一个"打包好的软件包",里面包含代码+依赖+运行环境。云端跑训练时,就是用这个包来跑。

### 怎么做

**6.1 进入 SWR 服务**

- 控制台 → ≡ → 搜 `SWR` → 点"容器镜像服务 SWR"

**6.2 创建组织(类似文件夹)**

- 左侧菜单点"组织管理"
- 点"创建组织"
- 组织名输入 `qt`
- 点"确定"

**6.3 获取登录命令**

- 左侧菜单点"登录指令"
- 点"生成临时登录指令"
- 弹出一个命令,类似:

      docker login -u cn-east-3@XXX -p XXXXX swr.cn-east-3.myhuaweicloud.com

- 点"复制"

**6.4 在终端登录**

打开终端,粘贴刚才复制的命令,按回车。

应该看到 `Login Succeeded`。

### 怎么确认做对了

终端显示 `Login Succeeded`。✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| 没开通 SWR | 在 SWR 页面点"开通服务" |
| `docker: command not found` | 你还没装 Docker;先做下面"装 Docker"步骤 |
| `docker login` 报错 `Cannot connect to the Docker daemon` | Docker Desktop 没启动;打开"启动台"→ 找 Docker → 点开 → 等鲸鱼图标稳定再试 |

**装 Docker(如果没装):**

1. 在终端输入:`brew install --cask docker`
2. 装完打开"启动台"(Launchpad)→ 找 Docker 图标 → 点开
3. 等状态栏的 Docker 鲸鱼图标变稳定(不再动画)
4. 终端输入 `docker --version` 验证,应该输出版本号

## 第 7 步:把训练代码打包成 Docker 镜像(最关键一步)

### 这一步做什么
把你的训练代码+依赖打包成一个 Docker 镜像,这样云端能跑你的代码。

### 怎么做

**7.1 创建放 Dockerfile 的文件夹**

在终端输入:

    mkdir -p ~/28-终极量化交易系统8.4/cloud/docker

**7.2 创建 Dockerfile**

Dockerfile 就是告诉 Docker"怎么打包"的配方文件。

在终端输入下面这条命令,它会创建文件并写入内容(整段复制粘贴,按回车):

    cat > ~/28-终极量化交易系统8.4/cloud/docker/Dockerfile.qlib-trainer << 'EOF'
    FROM python:3.11-slim
    RUN pip install --no-cache-dir uv
    WORKDIR /app

    COPY pyproject.toml uv.lock ./
    RUN uv sync --frozen --no-dev
    RUN pip install pyqlib lightgbm

    COPY ms_strategy/cloud_train/ ./ms_strategy/cloud_train/
    COPY ms_strategy/training/ ./ms_strategy/training/
    COPY qlib/ ./qlib/
    COPY utils/ ./utils/
    COPY config/ ./config/
    COPY configs/ ./configs/
    COPY lgb_trainer/ ./lgb_trainer/
    COPY lgb_enhanced_trainer.py lgb_tscv_trainer.py autolearn_trainer.py ./

    ENV QT_PLATFORM=cloud
    ENV QLIB_DATA_DIR=/cache/data/qlib_data/cn_data
    ENV QUANT_DATA_ROOT=/cache/data

    CMD ["uv", "run", "python", "ms_strategy/cloud_train/modelscope_train.py"]
    EOF

**7.3 创建 .dockerignore(告诉 Docker 哪些不要打包)**

    cat > ~/28-终极量化交易系统8.4/.dockerignore << 'EOF'
    data/
    data_cache/
    models/
    logs/
    reports/
    output/
    .venv/
    __pycache__/
    .pytest_cache/
    .mypy_cache/
    .ruff_cache/
    game/
    games/
    *.ps1
    cache/
    EOF

**7.4 开始打包(构建镜像)**

> ⚠️ **这步很重要!** 因为你的 Mac 是 ARM 架构(M5 芯片),云上是 x86 架构,必须加 `--platform linux/amd64`。

在终端输入(这是一条命令,全部复制):

    cd ~/28-终极量化交易系统8.4 && docker build --platform linux/amd64 -t swr.cn-east-3.myhuaweicloud.com/qt/qt-qlib-trainer:latest -f cloud/docker/Dockerfile.qlib-trainer .

按回车,然后**等 10–20 分钟**。会看到一堆 `Step 1/x : ...` 的输出,最后:

    Successfully tagged swr.cn-east-3.myhuaweicloud.com/qt/qt-qlib-trainer:latest

**7.5 验证镜像打包成功**

    docker images | grep qt-qlib-trainer

### 怎么确认做对了

7.5 应该列出一行,有镜像名 `swr.../qt/qt-qlib-trainer` 和大小(约 1–2GB)。✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| `docker build` 一直卡着不动 | 网络慢,在下载基础镜像;可以先 `docker pull --platform linux/amd64 python:3.11-slim` 预下载 |
| `COPY failed: file not found` | 某个文件夹不存在;在终端 `ls ~/28-终极量化交易系统8.4/ms_strategy/cloud_train/` 确认存在 |
| `platform linux/amd64 not supported` | 打开 Docker Desktop → 设置(齿轮)→ 勾选"Use Rosetta 2 for x86/amd64 emulation"→ 应用 |
| 构建到 `uv sync` 报错 | 依赖装不上;试试在 Dockerfile 里把 `uv sync` 改成 `pip install -r requirements.txt` |
| 构建太慢/卡死 | 确认 `.dockerignore` 生效了(没把 `data/` `models/` 打进去);`docker build` 加 `--no-cache` 重试 |

## 第 10 步:提交你的第一个训练作业(高潮!)

### 这一步做什么
告诉 ModelArts:"用我传上去的镜像和数据,跑一个 LightGBM 训练"。

### 怎么做(用控制台,最直观)

**10.1 开始创建**

- ModelArts →"训练管理"→"训练作业"→ 点"创建训练作业"

**10.2 填基本信息**

- **作业名称:** `qt-modelscope-csi300`
- **描述:** `我的第一个云端训练`(随便写)

**10.3 填算法信息**

- **算法来源:** 选"自定义"
- **镜像:** 选"SWR 镜像"→ 浏览 → 选 `qt/qt-qlib-trainer:latest`
- **启动命令:** 复制粘贴下面这整段:

      uv run python ms_strategy/cloud_train/modelscope_train.py --data-dir /cache/data/qlib_data/cn_data --market csi300 --start 2015-01-01 --end 2026-08-14 --train-end 2024-12-31 --valid-end 2025-06-30 --model lightgbm --num-leaves 128 --boost-round 500 --learning-rate 0.02 --max-depth 8 --output /cache/output

**10.4 填资源信息**

- **资源池:** 选"公共资源池"
- **资源规格:** 选 `modelarts.bm.8c32g.cpu`(8 核 32G CPU)
- **计算节点个数:** `1`
- **永久保存日志:** 勾选(✅)

**10.5 填数据存储(告诉它数据在哪)**

- 找"数据存储"或"训练输入"区域
- 点"添加"
  - **数据来源:** 选"OBS"
  - **OBS 桶:** 选 `qt-data`
  - **本地路径:** 输入 `/cache/data`
- 再点"添加"配训练输出:
  - 这步在不同版本界面不同,可能叫"训练输出位置"
  - **OBS 桶:** 选 `qt-models`
  - **本地路径:** 输入 `/cache/output`

**10.6 提交!**

- 检查一遍填的都对
- 点页面底部"立即创建"
- 弹窗确认,点"是"

**10.7 看作业状态**

- 回到"训练作业"列表
- 看到 `qt-modelscope-csi300`
- 状态会变化:`初始化` → `运行中` → `已完成`
- **等 5–30 分钟**

**10.8 看训练日志**

- 点作业名 `qt-modelscope-csi300`
- 点"日志"页签
- 应该看到:
  - `qlib.init` 成功的输出
  - `Alpha158` 特征工程
  - LightGBM 训练进度
  - 最后有 IC、Rank IC 等指标

### 怎么确认做对了

作业状态显示"已完成"✅,日志里有训练指标输出。

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| 一直"初始化" | 公共池排队;等 5–10 分钟;或换规格 |
| 状态"失败" | 点作业名看日志,找报错原因(见下) |
| 日志 `ModuleNotFoundError: No module named 'qlib'` | 镜像里没装 pyqlib;回第 7.2 步,Dockerfile 里加 `RUN pip install pyqlib`,重新构建(第 7.4)并推送(第 8.1) |
| 日志 `FileNotFoundError: /cache/data/qlib_data` | 数据没挂载对;回 10.5 检查 OBS 桶和本地路径 |
| 日志 `qlib.init failed` | 数据不完整;回第 5 步确认 `qlib_data/cn_data/` 里有 `calendars/`、`instruments/`、`features/` |
| 日志 `OBS access denied` | IAM 权限缺 OBS;回第 2.4 步加 `OBS OperateAccess` |
| 训练太慢或超时 | 先把 `--boost-round 500` 改成 `--boost-round 100` 跑通,再调大 |
| 找不到"创建训练作业"按钮 | ModelArts 界面更新了;找类似入口,或用 CLI 提交(见本教程末尾) |

## 如果某一步卡住了怎么办

### 通用排查顺序

1. **先看该步的"⚠️ 避坑"表格** — 90% 问题这里都有答案
2. **看错误信息** — 终端报错会告诉你具体原因,复制错误信息去搜
3. **检查网络** — 很多问题是网络慢/断
4. **检查权限** — `access denied` 类问题都是权限不够,回第 2 步
5. **检查名字拼写** — 桶名、镜像名、路径,一个字母错都不行

### 常见错误对照

| 你看到的错误 | 意思 | 怎么办 |
|---|---|---|
| `command not found` | 命令没装或路径不对 | 按教程装对应工具 |
| `access denied` / `permission denied` | 权限不够 | 回第 2 步加权限 |
| `not found` / `No such file` | 路径或名字错 | 逐字对照教程检查 |
| `connection refused` / `timeout` | 网络问题 | 换网络或等一会重试 |
| `already exists` | 之前创建过了 | 直接用已有的,不用重建 |
