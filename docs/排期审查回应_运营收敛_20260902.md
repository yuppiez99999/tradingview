## 四、四项决策（用户 2026-09-02 拍板）

### 决策 1：Q4 稳定观察期冻结口径 —— 冻结生产写入，保留 shadow

- **窗口**：09-19 ~ 12-10（与既有 12-10 功能冻结衔接，12-31 发布）
- **冻结（生产写入动作）**：
  - 因子入库（含 Wave 5 CHAIN_MOM_60D S6/S7 入库 → 后置 2027，验证继续 shadow）
  - feature flag 开启（生产链路 flag on）
  - preset 切换（`v9_200w_preset` 灰度切换除外，见决策 4 —— 灰度路线本身是发布主线的一部分）
  - 新模块进入生产链路
- **保留**：shadow 研究支线（Wave 7-ERL、GNN S6/S7 验证、MVSK+qlib shadow 30 天）、bug 修复、风险/性能优化、工程化支线 C（文档/CI/测试资产）
- **理由**："改动速度超过验证速度"的风险源于生产写入，不源于 shadow 验证本身；完全冻结会浪费 Q4 验证产能

### 决策 2：Wave 11-A 推迟至 2027

- 原 09-07~09-25"立即降本"9 项目子轨道推迟，与 11-B/C、Wave 9-GH 合并 2027 窗口
- 执行"2027 前不引入新 GitHub 项目 / 新框架 / 新模型"原则

### 决策 3：v8.7.1 零侵入两项提前至 Q4 稳定观察窗

| 提前项 | 缺口性质 | 说明 |
| --- | --- | --- |
| Chaos 六场景灾难演练 | 零侵入（纯测试资产） | Wind 断开 / QMT 断开 / 数据错一天 / ETF 停牌 / 期权无法成交 / 模型输出异常；发布前完成反而提升实盘安全性 |
| System Health Score 聚合（运营中心第一步） | 零侵入（报告侧） | 聚合现有遥测：模型（IC/ICIR/漂移）、数据（degradation_log）、交易（成交率/滑点 TCA）、风险（VaR/regime）、资金（NAV 偏差），单一评分落盘进每日状态报告 |

- **不提前**（维持 2027-01+，铁律不变）：风险预算 regime 打通（侵入生产链路，须 shadow ≥7 天）、Alpha Registry 统一化、Decimal 资金链改造（P2）、生产端成本模型核验（P3）
- v8.7.1 排期铁律相应修订：零侵入两项例外提前，其余严格发布后

### 决策 4：实盘资金口径 —— 200 万 v9_200w_preset 为主

- 12-31 实盘主组合按 `v9_200w_preset` 灰度路线确立：20 万测试 → 100 万灰度 shadow 30 天 → 200 万正式
- v5.10 500 万组合**降级为对照观察**（不上实盘切换）
- 前置依赖不变：v8.7 发布门禁全绿（D11 双条件达标）后启动 Sprint3-1
- Production Edition 方案以 200 万口径为基底
