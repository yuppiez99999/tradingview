## Phase 2：TA 多视角拆解 + airllm 验证（P2，第 3-4 周）

### 2.1 TA 多视角拆解（P2-A）

**目标**：解决 G4 黑盒化，把 TA `state_summary` 拆成 5 个准专家视角喂入辩论/聚合。

**改动点**：`utils/finance_agent_orchestrator.py` 的 `orchestrate_tradingagents()` 方法

当前：TA 整条流水线 → 1 个 AgentConsensus（1 票）
改造后：TA `state_summary` 的 5 个报告 → 5 个 ModelView → 喂入 `ai_decision` 的 `aggregate()`

```python
# Phase 2: 拆 TA state_summary 为多视角
def orchestrate_tradingagents_multi_view(self, symbol, date=None):
    result = self._tradingagents_bridge.analyze(symbol, date)
    state_summary = result.get("state_summary", {})
    
    # 将 5 个报告映射为 5 个 ModelView
    view_map = {
        "market_report": ("technical", "技术面"),
        "news_report": ("news", "新闻面"),
        "fundamentals_report": ("fundamental", "基本面"),
        "social_report": ("sentiment", "情绪面"),
        "sentiment_report": ("sentiment_alt", "情绪面2"),
    }
    
    views = []
    for key, (role, label) in view_map.items():
        report = state_summary.get(key, "")
        if report:
            # 用 LLM 从报告提取方向性判断
            action, strength, confidence = self._extract_view_from_report(report, label)
            views.append(ModelView(role=role, action=action, 
                                   strength=strength, confidence=confidence,
                                   reasoning=report[:300]))
    
    return views  # 返回多视角列表，由 ai_decision.aggregate() 融合
```

**验收标准**：
- [ ] TA 返回的 5 个报告均能提取出 ModelView
- [ ] 多视角聚合后的决策质量（夏普/胜率）不低于单票模式
- [ ] `state_summary` 为空时优雅降级（返回空列表，不影响主决策）

**回退条件**：多视角聚合质量下降 → 回退单票模式

## Phase 3：TDAM 写侧迁移 + TA A 股适配器（P3，第 5-8 周）

### 3.1 TDAM 写侧迁移（P3-A）

**目标**：决策日志从 cairn 文件系统迁移到 TDAM，cairn 降级为导出镜像。

**执行步骤**：
1. 安装官方 Python SDK：`pip install tencentdb_agent_memory_sdk_python`
2. 在 `ai_decision/orchestrator.py` 的 `_write_audit()` 中增加 TDAM 写入：
   ```python
   # Phase 3: 决策日志双写（cairn + TDAM）
   def _write_audit(decision):
       # 原有 cairn 文件写入（保持兼容）
       _write_cairn_log(decision)
       # 新增 TDAM 写入
       try:
           from tdam_sdk import MemoryClient
           client = MemoryClient(base_url="http://localhost:8125")
           client.write_chat_memory(
               agent_id="ai_decision_orchestrator",
               conversation=decision.to_dict(),
               metadata={"symbol": decision.symbol, "action": decision.action}
           )
       except Exception as e:
           logger.warning("TDAM 写入失败，回退 cairn: %s", e)
   ```
3. 观察期 2 周：双写运行，对比一致性
4. 切换：cairn LOG.md 变为 TDAM 导出镜像（每日导出）

**验收标准**：
- [ ] TDAM 写入成功率 ≥99%
- [ ] cairn 与 TDAM 日志一致性 100%
- [ ] TDAM 检索响应时间 <500ms

**回退条件**：写入异常率 >1% → 停止 TDAM 写入，保持 cairn 文件系统
