## 四、Docker 封装计划 (v8.7 发布后)

### 4.1 镜像设计

```
qt-system:8.7  (完整系统, Python 3.14-slim)
├── qt-system:8.7-base   (基础依赖层, 可缓存)
├── qt-system:8.7-trainer (模型训练, 含 torch/lightgbm)
└── qt-system:8.7-runtime (盘后工作流, 轻量级)
```

### 4.2 Dockerfile 要点

- 基础: `python:3.14-slim` (CPU)
- 系统依赖: `libgomp1` (LightGBM), `libopenblas` (numpy)
- Python 依赖: `requirements_lock.txt` (排除 pyautogui/pywinauto, Windows GUI)
- torch: CPU 版本 (`--index-url https://download.pytorch.org/whl/cpu`)
- 入口: `daily_workflow.py` (盘后工作流)
- 数据卷: `data/ models/ logs/ reports/ config/`
- 环境变量: `QT_PLATFORM=docker`, `QUANT_DATA_ROOT=/app`

### 4.3 docker-compose.yml 要点

- 服务: `qt-runtime` (盘后工作流) + `qt-trainer` (模型训练, 按需)
- 卷: `qt-data` (数据持久化) + `qt-config` (配置)
- 网络: `host` (akshare/wind_mcp 需访问外部 API)
- 调度: cron 或 Windows 任务计划触发 `docker compose run`

### 4.4 注意事项

1. **Windows GUI 依赖**: pyautogui/pywinauto 无法在 Linux Docker 使用, 需条件安装或排除
2. **券商接口**: 实盘交易需直接访问券商 API, Docker 网络模式用 `host`
3. **数据安全**: config/ 含敏感配置, 用 Docker secrets 或环境变量注入
4. **镜像体积**: torch CPU ~200MB + 全依赖 ~1GB, 总镜像 ~1.5GB
5. **CI/CD**: Dockerfile 可用于 GitHub Actions 标准化测试环境
