## 3. 优化原则（延续 08-27 三主线收敛，再加三条）

1. **主线 A 最高优先级**：v8.7 发布与稳定 —— 一切资源冲突让位。
2. **支线 B 研究分流**：shadow / 研究模式，不进生产链路（ETF P3、CTX-A4、S6 纸交易、qlib/MVSK shadow）。
3. **支线 C 工程服务化**：QC / ERL / GH+ 服务主线，不主导路线。
4. **（新）关键路径单线化**：D11 → B3/B4 → Sprint 2 → Sprint 3 → Sprint 4，关键路径上的任务不并行扩张。
5. **（新）支线预算制**：每周支线合计 ≤2 人天；被动观察项（数据积累类）零成本。
6. **（新）发布冻结窗**：12-10 起功能冻结，只修不加。
