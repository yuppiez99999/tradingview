## 0. 设计原则（不变）

所有措施**非侵入**：不修改既有业务模块，仅通过门禁 / 旁路 / 包裹 / CI 实现，门禁随阶段渐进收紧。达成机构级"可审计、可观测、可回滚、可拦截"的 90% 下限；剩余 10%（全仓 Decimal 化、legacy 全单测、拆巨文件）为阶段 3 可选升级。

## 3. 可达 vs 需代码改动（诚实分层）

**靠非侵入手段即可达到机构下限（本路线图目标）：**
- 可审计：PR + 评审 + 基线快照（需先修 R1/R2 让 PR 真实可审）
- 可观测：`logging_shim` 包裹 stdout + 禁新增 print
- 可回滚：git 收敛 + protected main + 快照比对
- 可拦截：PR 增量门禁 + `ci_integrity_check` + 预交易风控 + kill-switch
- 可验证：Q1–Q5 行为契约测试 + 回测无前视校验 + 数值旁路对账

**需存量代码改动才可达（阶段 3 可选，不阻塞）：**
- 全仓 Decimal 化（当前 1 处）
- legacy 模块 100% 单测（P0 链路基本无）
- 拆 6230 行 `daily_workflow.py`
- 亚毫秒低延迟执行（对个人组合无必要）
