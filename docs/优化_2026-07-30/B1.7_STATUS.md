## 共享模块

**新增**: `utils/positions_loader.py`

### API

```python
from utils.positions_loader import load_positions, get_positions_list, get_positions_dict

# 1. 原始 dict (失败返回 {})
data = load_positions()

# 2. 持仓列表 (positions dict 的 values)
items = get_positions_list()

# 3. {code: item} 映射
codes = get_positions_dict()

# 自定义路径 / 默认值
data = load_positions(path="/custom/positions.json", default={"positions": {}})
```

### 特性
- **路径自适应**: 从 `__file__` 推导项目根目录, 不依赖 CWD
- **失败安全**: 文件缺失或解析失败时返回 `default` (默认 `{}`)
- **原子读取**: 内部使用 `utils.concurrency.read_json_locked` 防止并发损坏
- **优雅降级**: 并发模块不可用时回退到普通 `json.load`
