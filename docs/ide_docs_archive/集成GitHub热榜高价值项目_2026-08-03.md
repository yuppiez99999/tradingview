### 5.2 改动清单

#### 5.2.1 PiMonoProvider(替换 LlmClientProvider 内部实现)
- **文件**: [ai_decision/providers.py](file:///e:/各种PY程序/28-终极量化交易系统8.4/ai_decision/providers.py)

- **配置**: `configs/llm_providers.yaml` 新增 `pimono.endpoint`、`pimono.default_model`

#### 5.2.2 记忆层新建
- **文件**: 新建 `ai_decision/memory_store.py`
- **设计**: 参考 [NevaMind-AI/memU](https://github.com/NevaMind-AI/memU) 的主动型记忆理念,封装为 `MemoryStore` 类

  - `recall(role, context, top_k=5)` — 召回相关历史决策

#### 6.3.2 Orchestrator 接入微调模型
