# GitHub 热门项目深度集成方案（2026-07-26 第二批）

## Context

**问题/需求**：用户要求将本周 GitHub 热门项目报告（`E:\各种PY程序\10_第三方项目\GitHub热门项目报告\GitHub热门项目报告_2026年7月第4周.md`）中的 3 个相关项目**深度集成到生产代码**（非 shallow clone 参考）。

**集成来源**：本周 GitHub Trending Top 10 中与量化交易相关的 3 个项目：
1. **code-review-graph** (+4,791 星) — 本地代码智能图谱工具，MCP 兼容
2. **cangjie-skill** (+1,364 星) — RIA--TV++ 内容蒸馏方法论

**预期结果**：
- 量化系统获得代码审查工具（开发时）、研究蒸馏信号源（第 6 信号源，weight=0.03）、金融 Agent 协调器（Shadow Mode）
- 新增 35-40 个测试（测试金字塔 120 → 155-160）
- **不破坏 500 万实盘**：所有生产改动用 post-mix 模式 + Shadow Mode，可一键回滚

1. **不修改主融合公式**：`alpha(0.70) + llm(0.10) + etf(0.12) + macro(0.08) = 1.00` 不变，research_distilled 用 post-mix 叠加

4. **Shadow Mode 不入信号路径**：finance_agent_orchestrator 仅写审计日志
5. **Python 3.8.9 兼容**：所有新模块用 `from __future__ import annotations`
6. **不修改 requirements.txt**：可选依赖（pdfplumber）用 lazy import + 降级
7. **不触碰孤儿 submodule**：`ms_strategy/`、`factor_kill_switch.py`、`research/vibe_trading_factor_analysis/safety/` 不动
