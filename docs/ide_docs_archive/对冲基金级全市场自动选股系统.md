# 对冲基金级全市场自动选股系统

## Context（背景与目标）

当前系统已有 458 个工业级因子（GTJA191/Alpha101/QLib158/Academic/Fundamental）和 AKShare 全市场数据源，但缺乏端到端的「全市场 → 候选股」pipeline。`realtime_monitor/watch_my_universe.py` 仅监控硬编码的 14 个标的，无法自动发现可交易股票。

**目标**：以对冲基金工业级标准构建全市场自动选股系统，输入沪深300+中证500约800只成分股，输出分层组合（20短+30中+50长=100只）+ 可视化报告 + 回测验证 + 每日定时运行。

## 对冲基金 Pipeline 设计

```
[沪深300+中证500成分股 ~800只]
        ↓
   风险前置过滤
   (剔除 ST/停牌/上市<60日/成交额<5000万/价格<2元)
        ↓
   批量因子计算 (458 因子 × 800 只)
        ↓
   横截面均衡多因子打分
   (动量30%+反转20%+量价20%+波动率15%+流动性15%)
        ↓
   行业内中性化排名
        ↓
   分层组合构建 (短20+中30+长50)
        ↓
   风险预算约束
   (单股≤5%, 单行业≤25%, 年化波动率15-20%)
        ↓
   输出: 候选股 + 行业分布 + 风险敞口 + 可视化报告
```

## 实现步骤

### 步骤 1: 创建 `utils/universe/stock_universe.py`

**职责**：获取候选股票池

**关键函数**：
- `get_hs300_constituents() -> pd.DataFrame` — 沪深300成分股（通过 `akshare.index_stock_cons_csindex("000300")`）
- `get_zz500_constituents() -> pd.DataFrame` — 中证500成分股
- `get_universe(pool="hs300_zz500") -> List[str]` — 合并去重，返回 800 只股票代码列表
- 复用 [akshare_data_source.py](file:///e:/各种PY程序/28-终极量化交易系统8.4/utils/akshare_data_source.py) 的 `_fetch_spot_cache()` 拉全市场快照

**输出**：股票代码列表 + 名称 + 所属指数

### 步骤 2: 创建 `utils/universe/risk_filter.py`

**职责**：风险前置剔除（对冲基金标准做法）

**关键函数**：
- `filter_universe(symbols: List[str], spot_df: pd.DataFrame, config: RiskFilterConfig) -> pd.DataFrame`

**过滤规则**（机构标准）：
- 剔除 ST/*ST/退市风险股（名称匹配）
- 剔除停牌（最新价为 0 或成交量为 0）
- 剔除上市不足 60 个交易日（避免新股波动）
- 剔除 20 日平均成交额 < 5000 万（流动性不足）
- 剔除最新价 < 2 元（仙股风险）
- 剔除当日换手率 > 30% 或 < 0.1%（异常活跃/死股）

**输出**：DataFrame，含 code/name/price/amount/turnover/market_cap/industry

### 步骤 3: 创建 `utils/universe/factor_scorer.py`

**职责**：批量计算因子并横截面打分

**关键函数**：
- `batch_compute_factors(symbols: List[str], klines_cache: Dict[str, pd.DataFrame], factor_ids: List[str]) -> pd.DataFrame` — 行=股票，列=因子值
- `cross_sectional_score(factor_df: pd.DataFrame, weights: Dict[str, float]) -> pd.Series` — 加权打分
- `industry_neutralize(scores: pd.Series, industry_map: Dict[str, str]) -> pd.Series` — 行业中性化（行业内 z-score）

**因子均衡权重**（用户选择）：
| 因子类别 | 权重 | 来源 |
|---------|------|------|
| 动量 momentum | 30% | GTJA191 动量类 63 个 + Alpha101 动量因子 |
| 反转 reversal | 20% | GTJA191 反转类 38 个 |
| 量价 volume | 20% | GTJA191 量价类 82 个 |
| 波动率 volatility | 15% | GTJA191 波动率类 26 个 + Academic |
| 流动性 liquidity | 15% | GTJA191 流动性类 2 个 + QLib158 |

**复用模块**：
- [vibe_trading_adapter.py](file:///e:/各种PY程序/28-终极量化交易系统8.4/utils/vibe_trading_adapter.py) 的 `VibeFactorAdapter.compute_single_stock()` 计算单股全因子
- [akshare_data_source.py](file:///e:/各种PY程序/28-终极量化交易系统8.4/utils/akshare_data_source.py) 的 `get_historical_klines()` 拉 K 线

**性能优化**：
- 进程池并行计算（`concurrent.futures.ProcessPoolExecutor`，max_workers=4）
- K 线数据本地缓存（`data/cache/klines_YYYYMMDD.parquet`）
- 因子计算结果缓存

### 步骤 4: 创建 `utils/universe/portfolio_builder.py`

**职责**：分层组合构建 + 风险预算

**关键函数**：
- `build_layered_portfolio(scores: pd.Series, industry_map: Dict, config: PortfolioConfig) -> LayeredPortfolio`
- `_select_short_term(scores, n=20)` — Top 20 短线（高动量 + 高流动性）
- `_select_mid_term(scores, n=30)` — Top 30 中线（均衡多因子）
- `_select_long_term(scores, n=50)` — Top 50 长线（低波动 + 高质量）
- `apply_risk_constraints(portfolio, constraints) -> Portfolio` — 风险预算约束

**风险约束**（对冲基金标准）：
- 单股权重 ≤ 5%
- 单行业暴露 ≤ 25%
- 组合年化波动率目标 15-20%
- 三层权重：短线 20% / 中线 30% / 长线 50%

**复用模块**：
- [risk_budget_engine.py](file:///e:/各种PY程序/28-终极量化交易系统8.4/utils/risk_budget_engine.py) 的风险检查
- [portfolio_optimizer.py](file:///e:/各种PY程序/28-终极量化交易系统8.4/utils/portfolio_optimizer.py) 的权重优化

### 步骤 5: 创建 `utils/universe/report_generator.py`

**职责**：可视化报告（matplotlib，无外部前端依赖）

**关键函数**：
- `generate_full_report(portfolio: LayeredPortfolio, output_dir: Path) -> ReportPaths`

**报告内容**：
1. **候选股清单表**（CSV + Markdown）：代码/名称/行业/打分/入选层/权重/入选理由
2. **行业分布饼图**：三层组合的行业暴露
3. **因子贡献柱状图**：各类因子对 Top 100 的贡献度
4. **风险敞口雷达图**：动量/反转/波动/流动性/规模 5 维
5. **打分分布直方图**：全市场打分分布 + Top 100 标记
6. **汇总报告 Markdown**：组合摘要 + 风险指标 + 调仓建议

### 步骤 6: 创建 `utils/universe/scheduler.py`

**职责**：每日盘后自动运行

**关键函数**：
- `run_daily_scan(trade_date: str, output_dir: Path) -> ScanResult` — 主流程编排
- `setup_windows_task()` — 注册 Windows 计划任务（每日 16:00 运行）

**调度逻辑**：
```
15:30 - 拉取全市场实时快照
15:35 - 风险过滤
15:40 - 批量计算因子（约 5-10 分钟）
15:50 - 横截面打分 + 行业中性化
15:55 - 组合构建 + 风险预算
16:00 - 生成报告 + 写入 JSON/CSV
16:05 - 发送飞书通知（可选）
```

## 性能与可行性

- **数据量**：800 只 × 250 日 K 线 = 20 万条记录，AKShare 单次拉取约 5-10 分钟
- **因子计算**：800 只 × 458 因子 = 36.6 万次计算，进程池并行约 8-15 分钟
- **总耗时**：约 15-25 分钟（首次）/ 5-10 分钟（有缓存）
- **内存**：峰值约 2GB
- **依赖**：仅 akshare + matplotlib + 已有依赖，无新增

## 风险与降级

1. **AKShare 限流** → 增加重试 + 间隔，缓存 K 线到本地 parquet
2. **因子计算超时** → 优先计算核心 50 个因子（GTJA191 经典因子），其余按需
3. **数据缺失** → 跳过该股票，记入日志
4. **回测样本不足** → 用 walk-forward，每窗口 60 日，共 4 个窗口
