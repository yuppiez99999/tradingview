## 三、CVaR 风险计量交付（W7.3.3 G11）

新建 `utils/risk/cvar.py` ~599 行 + `utils/risk/risk_module_adapters.py` 扩展 + `config/system_config.json` 扩展。

| 组件 | 内容 |
|---|---|
| 数据类 | `CVaRConfig`（frozen dataclass）+ `CVaRResult`（frozen dataclass）+ `CVaRCalculator` |
| 三种方法 | historical（排序分位）/ parametric（normal & student-t Cornish-Fisher 近似）/ evt（委托 tail_risk_evt） |
| fallback 链 | evt→historical 逐级降级 + method_used 透明记录 + warning 拼接 |
| VaR 对比 | var_95/var_99 限额校验 + breach_level（NONE/WARN/CRITICAL）+ var_comparison dict |
| Adapter | `VaRMonitorAdapter.make_decision()` 扩展 cvar_95/cvar_99 分支（feature flag `USE_CVAR_RISK_METRIC` 守卫） |
| 配置 | `system_config.json` 新增 `risk_metric` 子段（method/confidence/limits/fallback_chain）+ feature flag 注册 |

测试：106 passed（95 cvar + 4 adapter + 7 existing）/ 覆盖率 97.24% / 5 次重复稳定；回归 138 passed。SDD 文档全套（spec.md 35.7KB + design.md 44.7KB + tasks.md 30.7KB）。

设计原则：尾部风险计量优先于 VaR，fallback 链保证可用性，feature flag 守卫渐进启用，与 v8.6 风控一脉相承（尾部保护优先于收益）。
