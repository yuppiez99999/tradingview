## 3. 两个 Phase 详细排期

### Phase A：ECL MVP（2026-09-07 ~ 10-09，5 周低强度穿插，~11 人天）

**目标**: append-only 事件日志 + 经验库 + 只读检索旁路，全部 flag 默认 off，生产零行为变更
**模式**: 每周 ≤2 人天穿插（09-20 B4 完成前仅离线开发，不碰运行中系统）；总缓冲 3 周吸收 B3/B4 或 shadow 验证挤占

| 任务 ID | 任务 | 交付物 | 验收标准 | 预估工期 | 依赖 | 蓝本 |
|---------|------|--------|----------|----------|------|------|
| CTX-A1 | EventStore append-only 事件日志 | `utils/infra/ecl/event_store.py`（~250 行）+ 单测 | 仅 INSERT 无 UPDATE/DELETE 路径；单条写入 <10ms；replay(as_of) 可重建任意时点状态；纠正走 compensation 事件 | 3d | 无 | maka |
| CTX-A2 | ExperienceStore 经验库 + 检索 | `utils/infra/ecl/experience_store.py`（~300 行）+ 嵌入降级链（sentence-transformers → FTS5 → hash 向量） | 场景指纹生成；Top-K 相似检索 <500ms；运行时自动探测三档嵌入 | 4d | CTX-A1 | OpenViking |
| CTX-A3 | EOD 旁路接线（sink 模式） | `log_decision` sink 注册 + `15_每日工作流/` EOD 末尾旁路写入 + flag×3（USE_ECL_EVENT_LOG / USE_ECL_EXPERIENCE / USE_ECL_RETRIEVAL） | 三 flag 默认 False；开启后 E2E 决策输出与关闭逐字节一致（diff=0）；写入失败不阻塞主流程 | 2d | CTX-A1 | — |
| CTX-A4 | 历史回填 + 增益验证（YAGNI 门禁） | `scripts/backfill_ecl_events.py` + `reports/ecl/` 检索质量报告 | 回填 `reports/evolution/` 历史 JSON ≥30 交易日；相似场景 T+5 收益方向一致率统计；**≥55% → 开放 Phase B 注入类任务；<55% → ECL 降级为纯审计回放工具，Phase B 注入类取消** | 2d | CTX-A2, A3 | — |

**Phase A 门禁**:
- ✅ EventStore 不可变性 + 回放通过（A1）
- ✅ 检索延迟 <500ms，嵌入降级链三档可跑（A2）
- ✅ flag 全 off 默认 + diff=0 E2E 断言通过（A3）
- ✅ 回填验证结论明确（过/不过 YAGNI 门禁），写入 `cairn/experience-context-layer.md` §五.5（A4）
- ✅ pre-commit + CI 全过；新增模块 200-400 行；`cairn/LOG.md` 追加条目

## 5. 全局验收标准

### 5.1 量化指标

| 维度 | 指标 |
|------|------|
| 事件日志 | 仅追加不可变；单条写入 <10ms；任意时点状态可回放 |
| 经验检索 | Top-K 相似场景 <500ms；嵌入降级链三档自动切换 |
| 零行为变更 | 三 flag 开启后生产决策输出 diff=0（E2E 断言） |
| 回填增益 | 相似场景 T+5 收益方向一致率 ≥55%（YAGNI 门禁，决定 Phase B 注入类任务去留） |
| 多模态原型 | Top-10 检索人工评估命中率 ≥60%（探索性指标） |

### 5.2 工程门禁

- 所有改动通过 pre-commit + CI（ruff/mypy/bandit/pytest）
- 新增模块 200-400 行（AGENTS.md §5.3），单测同步
- 不可变性原则（AGENTS.md §5.1）：不原地改 df
- P0 文件无裸 print；零硬编码绝对路径
- `log_decision` sink 注册制，不改既有签名，向后兼容

### 5.3 文档归档

- 每任务完成 → `cairn/LOG.md` 追加条目（摘要 + 指针）
- Phase A 完成 → `cairn/experience-context-layer.md` 更新（A4 门禁结论）
- 全量完成 → `docs/Wave10完成报告_20270628.md`
- 提交规范（AGENTS.md §9）：`feat(infra): CTX-A1 集成 EventStore append-only 事件日志`

## 6. 风险与缓解

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| 09 月窗口被 B3/B4/shadow 验证挤占 | 高 | 中 | Phase A 低强度模式（每周≤2d）+ 3 周缓冲（至 10-09）；A1/A2 纯离线开发可随时暂停 |
