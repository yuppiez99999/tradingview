           <string>--phase</string><string>all</string>
         </array>
         <key>WorkingDirectory</key><string>/Users/yuppiefree2025/28-终极量化交易系统8.4</string>

3. 写一键安装脚本 `mac/install_launchd.sh`:

       #!/bin/zsh

       echo "已注册任务:"
       launchctl list | grep com.qt

                'group.id': 'win-executor',
                'sasl.username': config['kafka_user'],
                'sasl.password': config['kafka_pass'],
                'security.protocol': 'SASL_SSL',
            })
            self.consumer.subscribe(['qt.signal', 'qt.param', 'qt.command'])
            self.producer = Producer({...})
            self.broker = ThsBrokerAdapter(config['ths'])
            self.risk = RiskGuard(config['risk'])

        def handle_signal(self, msg):
            signal = json.loads(msg.value())
            # 本地风控二次校验
            if not self.risk.approve(signal):
                self._report(msg, status='rejected_by_risk')
                return
            # 调用同花顺下单
            order = self.broker.place_order(signal)
            self._report(order)

        def _report(self, order):
            self.producer.produce('qt.execution_report', json.dumps(order))

        def run(self):
            while True:
                msgs = self.consumer.poll(1.0)
                for msg in msgs:
                    self.handle_signal(msg)

    if __name__ == '__main__':

    from confluent_kafka import Consumer, Producer, KafkaError
    from dataclasses import dataclass

    @dataclass
    class QtKafkaConfig:
        brokers: str
        sasl_user: str
        sasl_pass: str

    class QtKafka:
        def __init__(self, config: QtKafkaConfig):
            common = {
                'bootstrap.servers': config.brokers,
                'sasl.username': config.sasl_user,
                'sasl.password': config.sasl_pass,
                'security.protocol': 'SASL_SSL',
                'sasl.mechanisms': 'PLAIN',
            }
            self.producer = Producer(common)
            self._consumer_common = common

        def produce(self, topic, value: dict):
            self.producer.produce(topic, json.dumps(value).encode())
            self.producer.flush()

        def consumer(self, topics, group_id):
            cfg = {**self._consumer_common, 'group.id': group_id}
            c = Consumer(cfg)
            c.subscribe(topics)
            return c

**目标:** 新架构(Mac→Windows 代理)与原 Windows 直跑并行,对比信号一致性。

**操作:**

1. Windows 代理 `live: false`(dry-run),原 Windows 机继续实盘
2. Mac 策略产信号 → Windows 代理 dry-run 下单 → 记录"若执行会下什么单"
3. 对比:新架构 dry-run 单 vs 原架构实盘单,计算一致率
4. 每日生成对账报告 `reports/shadow_reconcile/`

**验证:** 信号一致率 ≥ 99%。**耗时:** 3 工作日。

### D54–D55 不一致项排查与修复

**目标:** 一致率 < 99% 时排查。

**操作:** 逐单对比,定位差异源(数据版本/模型版本/风控参数),修复后重测。**耗时:** 2 工作日。

### D56 风控阈值对齐

**目标:** Windows 代理风控与原架构完全一致。

**操作:** 对比 `utils/risk/` 配置,逐参数对齐,单元测试验证。**耗时:** 1 工作日。

### D57 切换日(小仓位试运行)

**目标:** 选低风险时段(如盘后),切 10% 仓位到新架构实盘。

**操作:**

1. Windows 代理 `live: true`,但限仓 10%
2. 观察 1–2 日,无异常
3. 逐步放大到 30% → 50% → 100%

**耗时:** 1 工作日(启动)+ 持续观察。

### D58–D59 全量切换与旧机退役

**目标:** 100% 切到新架构,原 Windows 机降为备份。

**操作:**

1. 100% 仓位切新架构
2. 观察 1 周,稳定后原 Windows 机停机(保留为灾备冷备)
3. 更新文档:旧机角色标注"灾备冷备"

**耗时:** 2 工作日。
