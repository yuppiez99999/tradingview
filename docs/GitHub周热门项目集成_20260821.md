## 1. unsloth — 本地 LLM 训练增强

**适配器**: `utils/unsloth_adapter.py`

**核心 API**:
```python
from utils.unsloth_adapter import get_unsloth_adapter, is_unsloth_available

adapter = get_unsloth_adapter()
adapter.is_ready()                     # 是否可用
adapter.get_gpu_info()                 # GPU 信息 (供选择本地/API 模式)
model, tokenizer = adapter.load_finetuned("glm5-quant-v1")  # 加载微调模型
text = adapter.infer(model, tokenizer, "分析市场")          # 本地推理
adapter.list_finetuned()               # 已微调模型列表
```

**集成点**: `GLM5DecisionEngine.make_decisions()`
- 启动时调用 `is_unsloth_available()` 选择本地推理或 API 调用
- 盘中决策场景优先使用本地微调模型 (低延迟)
- 再平衡场景保留 API 调用 (深度推理)

**激活步骤**:
```bash
pip install unsloth_zoo
# 可选: pip install -e 10_第三方项目/unsloth/
```

**模型输出目录**: `models/unsloth_finetuned/<model_tag>/`

## 2. Switchyard — LLM 多模型路由

**适配器**: `utils/switchyard_adapter.py`

**核心 API**:
```python
from utils.switchyard_adapter import get_switchyard_adapter, is_switchyard_available

adapter = get_switchyard_adapter()
adapter.is_ready()                     # 是否可用
resp = adapter.route(
    messages=[{"role": "user", "content": "分析"}],
    model="auto",
    scene="intraday_decision",         # 自动映射到 qwen3-flash
    strategy="cost_aware",
)
adapter.benchmark_models(test_prompts, models=["qwen3-flash", "glm-5.2"])
adapter.get_status()
```

**集成点**: `GLM5Client.chat()` / `LiteLLMRouter`
- 启动时调用 `is_switchyard_available()` 选择路由器
- 可用时: 请求经 Switchyard 路由 (成本/质量/延迟策略)
- 不可用时: 回退到 LiteLLMRouter 原有 fallback 链

**场景模型映射**:
| 场景 | 模型 |
|------|------|
| intraday_decision | qwen3-flash |
| rebalancing_analysis | deepseek-v4-pro |
| macro_analysis | glm-5.2 |
| report_generation | qwen-plus |
| light_analysis | doubao-speed |

**激活步骤**:
```bash
# 编译 Rust 绑定
cd 10_第三方项目/Switchyard
cargo build --release
# 启动服务 (默认端口 7777)
./target/release/switchyard serve
```

## 3. OpenViking — AI Hedge Fund Agent 长期记忆

**适配器**: `quant_modules/ai_hedge_fund/openviking_memory.py`

**核心 API**:
```python
from quant_modules.ai_hedge_fund.openviking_memory import (
    get_openviking_memory, is_openviking_available,
)

memory = get_openviking_memory()
memory.is_ready()                     # 是否可用
memory.add_context(
    agent_id="warren_buffett",
    content="2024Q3 茅台毛利率 91.5%",
    metadata={"ticker": "600519", "type": "fundamental"},
)
results = memory.retrieve(
    agent_id="warren_buffett",
    query="茅台基本面",
    top_k=5,
)
memory.add_decision_audit(agent_id, decision, rationale)  # 决策审计
memory.get_agent_history(agent_id, days=30)               # 历史决策
```

**集成点**: `quant_modules/ai_hedge_fund/agents/` 20 位分析师
- 每位分析师 Agent 初始化时获取 `OpenVikingMemory` 单例
- 分析前: `retrieve()` 拉取相关历史记忆 (RAG)
- 分析后: `add_context()` 持久化新发现
- 决策时: `add_decision_audit()` 记录审计轨迹

## 设计原则

1. **不可变性**: 所有适配器创建新对象, 不修改第三方库内部状态
2. **优雅降级**: 第三方不可用时 `is_ready()=False`, 主系统回退到原有行为
3. **薄包装**: 不重写第三方 API, 仅做场景适配和类型转换
4. **KISS**: 每个适配器 200-280 行, 单一职责
5. **向后兼容**: 不修改主系统核心代码, 仅提供可选增强路径
