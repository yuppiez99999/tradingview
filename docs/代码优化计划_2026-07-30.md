#### 2.2 修复策略

```python
# BEFORE (危险)
try:
    risky_operation()
except Exception:
    pass  # 静默吞掉错误

# AFTER (正确)
try:
    risky_operation()
except SpecificException as e:
    logger.warning(f"操作失败: {e}", exc_info=True)
    # 优雅降级处理
except Exception as e:
    logger.error(f"未预期的错误: {e}", exc_info=True)
    raise  # 重新抛出未知异常
```

#### 2.3 执行顺序

1. **先修裸捕获** (`except:` → `except Exception as e:`)
2. **再修宽泛捕获** (添加日志记录 + exc_info)
3. **最后添加具体异常捕获**（如有需要）
