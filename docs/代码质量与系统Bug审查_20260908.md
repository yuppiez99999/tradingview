## 三、P2 — 逻辑 bug

### P2-1　`run_preflight` docstring 占位符不插值

**位置**: `scripts/launch_shadow_30day.py:834`

```python
def run_preflight() -> bool:
    """Shadow 30 天窗口 (评估窗 {EVAL_WINDOW_START}~{EVAL_WINDOW_END}) 启动前自检.
    ...
```

docstring **不是 f-string**（缺 `f` 前缀），`{EVAL_WINDOW_START}` / `{EVAL_WINDOW_END}` 原样显示，不会被替换。`help(run_preflight)` 或 IDE 悬停时用户看到未替换的占位符。

**修复**: 改为 f-string 或直接写死日期。注意 docstring 内有大量 `{}`（校验项编号等），若改 f-string 需转义所有字面 `{`/`}`。**更稳妥的做法**：直接写死 `"2026-09-13~2026-10-12"`。

### P2-2　MVSK active 模式权重归一化 bug（潜伏）

**位置**: `utils/universe/portfolio_builder.py:657-664`

今日改动把防御仓（style=国债，51.5%）排除出 MVSK 决策域后，`_compute_baseline_weights` 返回**子集归一化**权重（可优化子集和=1.0）。但 active 模式的合并逻辑未同步调整：

```python
if mvsk_mode == "active":
    weight_map = {
        h.symbol: mvsk_weights.get(h.symbol, h.weight) for h in portfolio.holdings
    }
    for h in portfolio.holdings:
        if h.layer == "mid":
            h.weight = weight_map.get(h.symbol, h.weight)  # ← 子集权重直接赋给全组合
```

**问题**: `mvsk_weights` 是子集归一化（和=1.0），防御仓不在其中（fallback 到原值 0.515）。赋值后全组合权重和 = 1.0（子集）+ 0.515（防御仓）= **1.515**，组合权重不再归一化。

**当前不触发**: `launch_shadow_30day.py:358` 硬编码 `mvsk_mode="shadow"`，active 分支不执行。但代码路径存在，一旦切换 active 即爆。

**修复**: active 模式下需将 mvsk_weights 按子集权重和缩放后再赋值：
```python
subset_total = sum(h.weight for h in portfolio.holdings if _is_mvsk_optimizable(h))
for h in portfolio.holdings:
    if _is_mvsk_optimizable(h):
        h.weight = mvsk_weights.get(h.symbol, 0.0) * subset_total
```

## 四、P2 — 口径风险（需业务确认）

### 口径-1　`weight_diff_l2` 语义变更，fail-fast 阈值需复核

**背景**: 今日改动把防御仓排除出 MVSK 决策域后，`weight_diff_l2` 从"全组合权重分歧"变为"可优化子集权重分歧"。

**数学关系**: 子集空间 L2 ≈ 全组合空间 L2 / (子集权重和)²。若子集占全组合 48.5%，则子集 L2 ≈ 全组合 L2 / 0.235 ≈ **4.25 倍**。

**fail-fast 阈值**: `MVSK_DIFF_THRESHOLD = 0.30`（`launch_shadow_30day.py:424`），注释口径为">0.30 = 组合权重完全背离"。

**风险**:
- 改动本意是消除防御仓造成的恒定 0.45 误报——排除后 L2 自然降到 0.05 以下，0.30 阈值不会误触发 ✅
- 但 0.30 在子集空间代表的"背离程度"比全组合空间更大（子集内某标的从 20%→74% 级别调整才触发）⚠️
- **历史 jsonl 记录的 L2 数值与评估窗内新记录不可比**——09-07~09-12 的预热记录是全组合口径，09-13 起是子集口径

**建议**: 评估窗已从 09-13 起（R-6 口径），预热记录不计入正式样本，口径切换点正好对齐。但需在 cairn 记录这个口径变更，并在 evaluator 报告中标注口径版本。
