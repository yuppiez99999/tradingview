# 云端部署小白教程(Windows 版)— 从零到第一个训练作业跑通

| 项 | 值 |
|---|---|
| 适用 | **Windows 10/11 用户,完全没用过云、没碰过命令行的小白** |
| 设备 | Windows 电脑(64 位) |
| 目标 | 跟着做完,在华为云上跑通一个量化训练,模型下载回 Windows |
| 耗时 | 4–6 小时(含等待,可分几天做) |

---

## 这个教程教你做什么(先读这段)

**用大白话说:** 你现在量化系统在 Windows 上跑,但有些大模型训练电脑跑不动或太慢。本教程教你把训练任务"搬"到华为云上去跑,跑完把训练好的模型"拿"回来用。

**打个比方:** 就像你家洗衣机太小洗不了大件,把大件送到洗衣店(华为云)洗,洗完拿回家。

**做完你会得到:** 一个在云端训练好的 LightGBM 模型文件,下载回 Windows 后能直接用。

**全程 13 步**,每步都有"做什么→怎么做→怎么确认做对了→避坑",跟着做就行。

> **Windows 版的好处:** 你的电脑和云都是 x86 架构,打包镜像时**不用**加 `--platform` 参数,比 Mac 版更简单。

---

## 开始前,你需要准备的东西

1. **你的 Windows 电脑**(64 位,Windows 10 或 11,能上网)
2. **一张身份证**(华为云要实名认证)
3. **一个手机号**(注册华为云用)

5. **项目代码已在电脑上**(在 `E:\各种PY程序\28-终极量化交易系统8.4\`)

> ⚠️ **如果第 5 条没准备好:** 确保项目文件夹存在,且里面有 `qlib_data\cn_data\`、`data_cache\`、`ms_strategy\cloud_train\` 等子目录。

## 第 1 步:注册华为云账号并实名认证

### 这一步做什么
在华为云注册一个账号,并用身份证实名认证。**没有实名认证,后面什么都做不了。**

### 怎么做

**1.1 打开华为云官网**

打开浏览器(Edge 或 Chrome),地址栏输入 `https://www.huaweicloud.com/`,回车。

**1.2 注册**

- 页面右上角点"注册"
- 填手机号 → 点"获取验证码"→ 输入短信验证码
- 设密码(记下来!存到记事本)
- 勾"我已阅读并同意"→ 点"注册"

**1.3 登录**

注册完自动登录。没登录就右上角点"登录"。

**1.4 实名认证(关键!)**

- 右上角点头像 →"账号中心"
- 左侧找"实名认证"→ 选"个人认证"
- 填真实姓名、身份证号
- 上传身份证正反面照片
- 点"提交"→ 可能要人脸识别

**1.5 等审核**

- 通常即时通过
- 页面显示"实名认证:已通过"就对了

### 怎么确认做对了

账号中心显示"实名认证:已通过" ✅

### ⚠️ 避坑

| 问题 | 解决 |

| 实名不通过 | 姓名身份证号要完全一致;重拍清晰照片 |

## 第 2 步:创建子账号并拿到钥匙(AK/SK)

### 这一步做什么
拿到"编程钥匙"(AK/SK),后面用命令行操作云时要用它证明身份。

> **什么是 AK/SK?** AK 是账号 ID(像用户名),SK 是密钥(像密码)。**SK 只显示一次,一定要保存好!**

### 怎么做

**2.1 进入 IAM 服务**

- 控制台 → 左上角 ≡ → 搜 `IAM` → 点"统一身份认证服务 IAM"

**2.2 创建用户**

- 左侧"用户"→ 右上角"创建用户"
- 填:
  - **用户名:** `qt-admin`
  - **凭证类型:** 勾"编程访问"✅ + "管理控制台访问"✅
  - **密码:** 设密码,记下来
  - **用户组:** 选 `admin`(没有就先创建 `admin` 组并给所有权限)
- 点"确定"

**2.3 保存 AK/SK(关键!)**

创建后弹出框显示 AK 和 SK。**立即复制保存!SK 关掉就再也看不到!**

打开记事本,先把 AK 和 SK 粘贴进去临时保存(后面要用来设置环境变量)。

**2.4 设置环境变量保存钥匙(Windows 方式)**

打开 PowerShell(下面第 3 步教你怎么打开,但现在先做这个):

按键盘 `Win 键 + X`,选"终端"或"Windows PowerShell",打开蓝色窗口。

输入(把 `你的AK` 换成实际的 AK,SK 同理):

    setx HUAWEICLOUD_AK "你的AK"

回车。再输入:

    setx HUAWEICLOUD_SK "你的SK"

回车。看到"成功: 已设置"就对了。

> **为什么要 setx?** 这会把 AK/SK 永久存到 Windows 环境变量里,以后打开新 PowerShell 窗口也能用,不用每次重新输。

**2.5 关掉这个 PowerShell 窗口,重新打开一个新的**(让环境变量生效)

验证:

    echo $env:HUAWEICLOUD_AK

应该输出你的 AK。✅

**2.6 给子账号权限**

- IAM →"用户组"→ 点 `admin` →"权限管理"→"添加权限"
- 搜索并添加:
  - `OBS OperateAccess`
  - `ModelArts FullAccess`
  - `SWR FullAccess`
- 点"确定"

### 怎么确认做对了

新 PowerShell 窗口里 `echo $env:HUAWEICLOUD_AK` 输出你的 AK ✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| 创建时没勾"编程访问" | IAM → 用户 → qt-admin → 修改 → 勾选 → 重新生成 |
| SK 忘了 | IAM → 用户 → qt-admin → 访问密钥 → 删旧建新,这次一定保存 |
| `echo $env:HUAWEICLOUD_AK` 输出空 | 没重新开 PowerShell;或 setx 拼错了,重新 setx |
| `admin` 组不存在 | 先创建用户组 `admin` → 给所有权限 |

## 第 3 步:安装命令行工具并连上华为云

## 第 5 步:把训练数据传到云上

### 这一步做什么
把电脑上的训练数据(约 730MB)上传到 OBS。

### 怎么做

**5.1 下载 obsutil(Windows 版)**

在 PowerShell 输入:

    cd $env:USERPROFILE\Downloads
    curl.exe -O https://obs-community.obs.cn-north-1.myhuaweicloud.com/obsutil/current/obsutil_windows_amd64.zip

等下载完。

**5.2 解压**

    Expand-Archive obsutil_windows_amd64.zip -DestinationPath obsutil

**5.3 把 obsutil 放到好找的位置**

    Move-Item obsutil\obsutil.exe $env:USERPROFILE\obsutil.exe

**5.4 验证装好了**

    & $env:USERPROFILE\obsutil.exe version

应该输出版本号。

> 为了方便,我们给 obsutil 设个别名。在 PowerShell 输入:

    Set-Alias obsutil "$env:USERPROFILE\obsutil.exe"

> ⚠️ 这个别名只在当前窗口有效。每次开新 PowerShell 都要重新设。或者把它加到 PowerShell 配置文件里(后面教)。

**5.5 配置 obsutil**

    obsutil config -ak=$env:HUAWEICLOUD_AK -sk=$env:HUAWEICLOUD_SK -endpoint=obs.cn-east-3.myhuaweicloud.com

看到 `Set obsutil config successfully!` 就对了。

**5.6 上传 Qlib 数据(270MB,约 2 分钟)**

    obsutil cp -r -f "E:\各种PY程序\28-终极量化交易系统8.4\qlib_data\" "obs://qt-data/qlib_data/"

> 路径里有中文,一定要用双引号包起来!

等显示 `Upload [succeeded]`。

**5.7 上传行情数据(40MB)**

    obsutil cp -r -f "E:\各种PY程序\28-终极量化交易系统8.4\data_cache\" "obs://qt-data/data_cache/"

**5.8 上传配置文件**

    obsutil cp -r -f "E:\各种PY程序\28-终极量化交易系统8.4\config\" "obs://qt-data/config/"

**5.9 验证**

    obsutil ls "obs://qt-data/" -limit=10

### 怎么确认做对了

5.9 列出 `qlib_data/`、`data_cache/`、`config/` ✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| `curl: command not found` | 用 `curl.exe`(Windows 10+ 自带);或用浏览器下载 |
| `obsutil` 不是命令 | 用全路径 `& $env:USERPROFILE\obsutil.exe` 代替;或先 `Set-Alias` |
| `Access Denied` | AK/SK 错或没权限;回第 2 步 |
| 路径报错 | 有中文/空格的路径必须用双引号包起来 |
| 上传慢 | 家宽上传慢,730MB 正常 5–15 分钟 |

## 第 6 步:在云上建镜像仓库(SWR)

### 这一步做什么
建一个存 Docker 镜像的地方。

> **什么是 Docker 镜像?** 打包好的软件包,含代码+依赖+环境。云端跑训练就用这个包。

### 怎么做

**6.1 装 Docker Desktop(如果没装)**

    winget install Docker.DockerDesktop

装完**重启电脑**。

重启后,打开 Docker Desktop(开始菜单搜 Docker),等它启动完成(状态栏鲸鱼图标稳定)。

验证:

    docker --version

应该输出版本号。

> ⚠️ Docker Desktop 需要 WSL2。如果启动报错说需要 WSL2,在 PowerShell 输入:
>
>     wsl --install
>
> 然后重启电脑。

**6.2 进入 SWR**

- 控制台 → ≡ → 搜 `SWR` → 点"容器镜像服务 SWR"

**6.3 创建组织**

- 左侧"组织管理"→"创建组织"→ 名字 `qt` → 确定

**6.4 获取登录命令**

- 左侧"登录指令"→"生成临时登录指令"→ 复制

**6.5 在 PowerShell 登录**

粘贴复制的命令,回车。看到 `Login Succeeded` 就对了。

### 怎么确认做对了

`Login Succeeded` ✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| `docker: command not found` | Docker Desktop 没装好或没启动;打开 Docker Desktop 等鲸鱼稳定 |
| Docker 启动报错要 WSL2 | `wsl --install` → 重启电脑 |
| `docker login` 报错 | Docker Desktop 没启动;或临时指令过期,重新生成 |
| `winget install Docker` 失败 | 去 https://www.docker.com/products/docker-desktop 手动下载安装 |

## 第 7 步:把训练代码打包成 Docker 镜像(最关键一步)

### 这一步做什么
把训练代码+依赖打包成 Docker 镜像。

### 怎么做

**7.1 创建放 Dockerfile 的文件夹**

    mkdir "E:\各种PY程序\28-终极量化交易系统8.4\cloud\docker" -Force

**7.2 创建 Dockerfile**

把下面整段复制到 PowerShell,按回车(它会创建文件并写入内容):

    @"
    FROM python:3.11-slim
    RUN pip install --no-cache-dir uv
    WORKDIR /app

    COPY pyproject.toml uv.lock ./
    RUN uv sync --frozen --no-dev
    RUN pip install pyqlib lightgbm

    COPY ms_strategy/cloud_train/ ./ms_strategy/cloud_train/
    COPY ms_strategy/training/ ./ms_strategy/training/
    COPY qlib/ ./qlib/
    COPY utils/ ./utils/
    COPY config/ ./config/
    COPY configs/ ./configs/
    COPY lgb_trainer/ ./lgb_trainer/
    COPY lgb_enhanced_trainer.py lgb_tscv_trainer.py autolearn_trainer.py ./

    ENV QT_PLATFORM=cloud
    ENV QLIB_DATA_DIR=/cache/data/qlib_data/cn_data
    ENV QUANT_DATA_ROOT=/cache/data

    CMD ["uv", "run", "python", "ms_strategy/cloud_train/modelscope_train.py"]
    "@ | Set-Content "E:\各种PY程序\28-终极量化交易系统8.4\cloud\docker\Dockerfile.qlib-trainer" -Encoding UTF8

**7.3 创建 .dockerignore**

    @"
    data/
    data_cache/
    models/
    logs/
    reports/
    output/
    .venv/
    __pycache__/
    .pytest_cache/
    game/
    games/
    *.ps1
    cache/
    "@ | Set-Content "E:\各种PY程序\28-终极量化交易系统8.4\.dockerignore" -Encoding UTF8

**7.4 开始打包**

> ⚠️ **Windows 版不用加 `--platform`!** 因为你的电脑和云都是 x86 架构,直接构建就行。这比 Mac 版简单。

    cd "E:\各种PY程序\28-终极量化交易系统8.4"
    docker build -t swr.cn-east-3.myhuaweicloud.com/qt/qt-qlib-trainer:latest -f cloud\docker\Dockerfile.qlib-trainer .

回车,**等 10–20 分钟**。最后看到:

    Successfully tagged swr.cn-east-3.myhuaweicloud.com/qt/qt-qlib-trainer:latest

**7.5 验证**

    docker images | findstr qt-qlib-trainer

### 怎么确认做对了

7.5 列出镜像,大小约 1–2GB ✅

### ⚠️ 避坑

| 问题 | 解决 |
|---|---|
| `docker build` 卡住不动 | 网络慢,在下载基础镜像;先 `docker pull python:3.11-slim` 预下载 |
| `COPY failed: file not found` | 文件夹不存在;确认 `dir "E:\各种PY程序\28-终极量化交易系统8.4\ms_strategy\cloud_train\"` 有内容 |
| 构建到 `uv sync` 报错 | 依赖装不上;Dockerfile 里把 `uv sync` 改成 `pip install -r requirements.txt` |
| 构建太慢 | 确认 `.dockerignore` 生效(没把 `data/` `models/` 打进去) |
| `docker build` 说找不到 Dockerfile | 路径用反斜杠 `\`,不是斜杠 `/`;确认 7.2 创建成功 |
| PowerShell 执行策略报错 | 输入 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 回车 Y |

## 第 10 步:提交你的第一个训练作业(高潮!)

### 这一步做什么
告诉 ModelArts 用你的镜像和数据跑一个 LightGBM 训练。

### 怎么做(用控制台,最直观)

**10.1 开始创建**

## 如果某一步卡住了

### 通用排查

1. **先看该步"⚠️ 避坑"** — 90% 问题这里都有
2. **看错误信息** — 复制错误去搜
3. **检查网络**
4. **检查权限** — `access denied` 都是权限问题,回第 2 步
5. **检查路径** — 有中文/空格必须用双引号

### Windows 特有避坑

| 问题 | 解决 |
|---|---|
| PowerShell 报"执行策略"错误 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` → Y |
| 路径有中文报错 | 所有含中文的路径用双引号包起来,如 `"E:\各种PY程序\..."` |
| `curl` 不是命令 | 用 `curl.exe`(Windows 10+ 自带) |
| `setx` 设了环境变量但新窗口读不到 | 拼写错了;`setx HUAWEICLOUD_AK "值"` 注意等号前后没空格 |
| Docker Desktop 启动失败 | 确保 BIOS 开了虚拟化;装 WSL2:`wsl --install`→重启 |
| `docker build` 报 `Error response from daemon` | Docker Desktop 没完全启动;等鲸鱼图标稳定 |

### 通用错误对照

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| `command not found` / `不是命令` | 没装或路径不对 | 按教程装对应工具 |
| `access denied` / `permission denied` | 权限不够 | 回第 2 步加权限 |
| `not found` / `No such file` | 路径或名字错 | 逐字对照检查,注意双引号 |
| `connection refused` / `timeout` | 网络问题 | 换网络或等一会重试 |
| `already exists` | 之前创建过了 | 直接用已有的 |

## 实战踩坑记录(2026-08-16 首次跑通)

> 以下为实际部署中遇到的问题及解决方案，补充教程正文未覆盖的坑。

### 坑1：Docker Desktop WSL2 虚拟磁盘损坏

| 项 | 内容 |
|---|---|
| 现象 | `docker` 命令反复报 `500 Internal Server Error`，重启 Docker Desktop 无效 |
| 原因 | C 盘磁盘空间不足（<5GB），WSL2 虚拟磁盘 I/O 出错导致损坏（SCSI 错误） |
| 解决 | 删除 `C:\Users\Administrator\AppData\Local\Docker\wsl\disk\docker_data.vhdx`，重启 Docker Desktop（会自动重建，但本地镜像全部丢失需重新 build） |
| 预防 | 保持 C 盘至少 10GB 空闲；定期清理 `npm-cache`、`Temp`、`uv` 等缓存目录 |

### 坑2：docker push 大 layer 断裂（broken pipe）

| 项 | 内容 |
|---|---|
| 现象 | `docker push` 推送大 layer（>300MB）时反复 `broken pipe` / `use of closed network connection` |
| 原因 | Docker Desktop 内部代理（`192.168.65.1:3128`）处理大文件上传时连接不稳定 |
| 解决 | 用 `crane` 工具代替 `docker push`。crane 直接用 HTTP API 推送，不经过 Docker Desktop 代理 |
| 命令 | `docker save -o image.tar <镜像>` → `crane push image.tar <SWR地址>` |
| crane 安装 | 从 GitHub 下载 `go-containerregistry_Windows_x86_64.tar.gz`，解压出 `crane.exe` |

### 坑3：ModelArts 覆盖 `/cache/` 目录

| 项 | 内容 |
|---|---|
| 现象 | 镜像里 `COPY` 到 `/cache/data/` 的数据在 ModelArts 运行时消失（`find /cache/data` 输出为空） |
| 原因 | ModelArts 启动容器时把 `/cache/` 挂载为空卷，覆盖了镜像里的数据 |
| 解决 | 把数据放到 `/app/` 下（WORKDIR，不被覆盖）：`COPY qlib_data/cn_data/ /app/qlib_data/cn_data/` |

### 坑4：qlib 0.9.7 数据结构要求

| 项 | 内容 |
|---|---|
| 现象 | 报 `ValueError: does not contain data for day` |
| 原因 | qlib 0.9.7 在 `provider_uri` 为字符串时，通过 `provider_uri/calendars/*.txt` 的文件名确定支持的频率。数据必须直接在 `cn_data/` 下，不能多套一层 `day/` 子目录 |
| 正确结构 | `cn_data/calendars/day.txt`、`cn_data/features/`、`cn_data/instruments/` |
| 错误结构 | `cn_data/day/calendars/`、`cn_data/day/features/`（多套了一层） |

### 坑5：`/app` 目录无写权限

| 项 | 内容 |
|---|---|
| 现象 | `PermissionError: [Errno 13] Permission denied: '/app/mlruns'` |
| 原因 | ModelArts 以 `ma-user`（UID 1000）运行，但 `/app/` 属于 root，ma-user 无写权限。qlib/mlflow 要在 WORKDIR 下写 `mlruns` 目录 |
| 解决 | Dockerfile 加 `RUN chmod 777 /app` |

### 坑6：LightGBM 缺 libgomp.so.1

| 项 | 内容 |
|---|---|
| 现象 | `OSError: libgomp.so.1: cannot open shared object file` |
| 原因 | `python:3.11-slim` 基础镜像缺 OpenMP 运行时库 |
| 解决 | Dockerfile 加 `RUN apt-get update && apt-get install -y --no-install-recommends libgomp1` |

### 坑7：ModelArts 镜像缓存

| 项 | 内容 |
|---|---|
| 现象 | 更新镜像后 ModelArts 仍用旧镜像（同样的 tag `latest`） |
| 原因 | ModelArts 按 tag 缓存镜像，同 tag 不重新拉取 |
| 解决 | 每次更新用新 tag（v2、v3、v4...），在 ModelArts 重新注册自定义镜像 |

### 坑8：资源规格太小导致 OOM

| 项 | 内容 |
|---|---|
| 现象 | 训练作业在特征工程后静默停止，无错误信息 |
| 原因 | 2核8G 内存不足，进程被 OOM killer 杀掉 |
| 解决 | 用 8核32G 或更大规格 |

### 坑9：SDK 提交作业报 `Custom image query failure` (ModelArts.2810)

| 项 | 内容 |
|---|---|
| 现象 | 用 ModelArts Python SDK (`create_training_job`) 提交作业报 400 错误 `Custom image query failure` |
| 原因 | SDK 请求体与控制台不同 — `image_url` 不能带 SWR 域名前缀，`engine_id` 传空字符串，不传 `pool_id` |
| 正确 | `image_url="qt1/qt-qlib-trainer:v7"`（不含 `swr.cn-east-3.myhuaweicloud.com/`），`engine_id=""`，`SpecResource` 不设 `pool_id` |
| 验证 | 对比 `list_training_jobs` 返回的控制台成功作业的 `algorithm.engine` 字段 |

### 坑10：SDK 日志预览 API 不含用户 stdout

| 项 | 内容 |
|---|---|
| 现象 | `show_training_job_logs_preview` 返回的日志全是 ModelArts 基础设施日志（sidecar/init），看不到训练 print 输出 |
| 原因 | 日志预览 API 只返回基础设施日志；用户 stdout 在单独的日志文件中，上传到 `log_export_path` 指定的 OBS 路径 |
| 解决 | 作业 `spec` 设 `log_export_path=LogExportPath(obs_url="obs://qt-models/output/")`；完成后从 OBS 下载 `output/modelarts-job-{job_id}-worker-0.log`，用正则解析 IC/RankIC/ICIR |
| 注意 | 设 `log_export_path` 后作业从 ~196秒 变为 ~755秒（OBS 上传开销），凌晨定时任务可接受 |

### 最终成功的配置

| 项 | 值 |
|---|---|
| 镜像 | `qt-qlib-trainer:v7` |
| Dockerfile 关键行 | `chmod 777 /app` + `libgomp1` + 数据在 `/app/qlib_data/cn_data/` |
| 启动命令 | `python ms_strategy/cloud_train/modelscope_train.py --data-dir /app/qlib_data/cn_data` |
| 资源规格 | 8 vCPUs \| 32 GiB |
| 训练耗时 | 约 13 分钟（特征工程 37 秒 + LightGBM 训练 12 分钟） |
| 结果 | 日均IC=0.0236, RankIC=0.0448, ICIR=0.1613 |
| SDK 提交 | `image_url` 不带 SWR 域名前缀，`engine_id=""`，不传 `pool_id` |
| 结果获取 | 从 OBS 下载 `output/modelarts-job-{job_id}-worker-0.log` 解析 |
