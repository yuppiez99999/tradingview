## 二、设计方案 — ShadowRealDataFeeder 生产化

### 2.1 类设计

```python
# 位置: utils/alpha/shadow_real_data_feeder.py

class ShadowRealDataFeeder:
    """Shadow 账户真实数据注入器 — 从 DataProvider 拉取真实行情,
    按当日持仓权重计算组合日收益, 增量写入 daily_returns.jsonl.

    设计原则:
        1. 不修改 ShadowAccountAdapter (Adapter 模式外观)
        2. 不切任何 Feature Flag (HC-1: 默认行为不变)
        3. 增量写入 (不覆盖历史记录, 仅追加新日期)
        4. 多源交叉校验 (TDX/AKShare/Wind 任一可用即可)
        5. fail-safe (数据源失败时跳过该日, 不抛异常中断流程)

    集成点:
        - v8.4_PostMarket 定时任务 (15:30 盘后)
        - 手动 CLI: py scripts/shadow_real_data_feeder.py --date 2026-08-04
    """

    def __init__(
        self,

        weights_source: str = "auto",  # auto/plan_file/positions_json

        verbose: bool = False,

        """注入单日真实收益.

        Args:
            date: 日期 (YYYY-MM-DD)

        # 4. 加权 daily_return = sum(weight * ret)
        # 5. 增量写入 daily_returns.jsonl (若 date 已存在则更新)
        ...

    def feed_history(
        self,

        end_date: str,
        weights_history: dict[str, dict[str, float]] | None = None,

        Args:
            start_date: 起始日期 (YYYY-MM-DD)

            date: 日期
```

### 2.2 数据源优先级与多源校验

```python
# 复用 MarketDataProvider 的 5 级降级链:
# Wind MCP > iFinD MCP > 通达信 (TDX) > AKShare > 新浪财经

# 多源交叉校验策略:
1. Primary: TDX (TCP, 速度快, A股专精)
2. Secondary: AKShare (HTTP, 公开数据)
3. 校验条件: |primary_ret - secondary_ret| / |primary_ret| < 0.01 (1%)
4. 不满足时标记 source_consistency="inconsistent", 仍写入但加 warning
```

### 2.3 持仓权重来源

| weights_source | 来源 | 适用场景 |
|----------------|------|----------|
| `auto` | 自动检测 (优先 plan_file, 退化 positions_json) | 默认 |
| `plan_file` | `reports/strategy/plan_YYYY-MM-DD.json` 的 `target_weights` | V9 策略组合 |
| `positions_json` | `data/positions.json` 实盘持仓 | 实盘模式 |
| `manual` | 调用方直接传入 dict | 测试/回填 |

### 2.4 输出格式 (与 daily_returns.jsonl 兼容)

```jsonl
{"date": "2026-08-04", "daily_return": 0.0085, "source": "w13a_real_market_feed", "updated_at": "2026-08-04T15:35:00", "symbols_count": 18, "cross_validated": true, "source_consistency": "high"}
```

**字段说明**:
- `date` (str): 日期
- `daily_return` (float): 加权日收益 (小数, 如 0.0085 = 0.85%)
- `source` (str): 数据来源标记, W1.3a 产出统一为 `w13a_real_market_feed`
- `updated_at` (str): ISO 时间戳
- `symbols_count` (int): 当日参与计算的标的数
- `cross_validated` (bool): 是否多源交叉校验
- `source_consistency` (str): high/medium/low/inconsistent

### 2.5 安全护栏

| 护栏 | 阈值 | 动作 |
|------|------|------|
| 单日异常收益 | `|daily_return| > 0.05` (5%) | 标记 warning 但仍写入, 触发人工核查 |
| 数据源全失败 | 0 个 symbol 成功 | 跳过该日, 不写入空记录 |
| 标的覆盖率 | `success_count / total < 0.8` (80%) | 标记 partial_coverage, 仍写入 |
| 跨源差异 | `max_diff > 0.01` | 标记 source_consistency=low |
