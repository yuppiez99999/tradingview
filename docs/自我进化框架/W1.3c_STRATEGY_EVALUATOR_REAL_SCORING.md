## 二、验证目标 (W1.3c 核心)

### 2.1 Public/Private 分离性验证

**目标**: 验证 StrategyEvaluator 在真实数据上的 Public/Private 分数分离机制是否符合 AIDE² 设计。

**验证步骤**:
1. 用真实 daily_returns.jsonl (5 条) 跑 `evaluate_from_shadow()`
2. 检查 `report.public_score` 与 `report.private_score` 是否分离
3. 检查 `report.reward_hacking_risk` 是否在合理范围
4. 检查 `report.recommendation` 是否为 "continue" (样本不足时不晋升不回滚)
5. 检查 `report.is_degraded` 是否为 True (5 条 < MIN_SAMPLES_FOR_DSR=15)

**预期**: 样本不足 → 降级报告, public_score=0, private_score=0, recommendation="continue"

### 2.2 Shadow 样本量统计

**目标**: 统计当前 Shadow 真实样本量, 评估是否满足 08-13 决策门槛 (≥20)。

**统计指标**:
- `total_samples`: daily_returns.jsonl 总条数
- `valid_samples`: daily_return 非 0 的条数 (排除停牌/数据问题)
- `date_range`: 最早 ~ 最晚日期
- `days_to_target`: 距离 20 条最小样本还需多少天
- `days_to_healthy`: 距离 120 条健康样本还需多少天

**预期**: 5 条真实数据, 3 条有效 (1.65%/-2.13%/0%), 距 20 条差 15 天

### 2.3 降级行为验证

**目标**: 验证样本不足时 StrategyEvaluator 正确降级, 不影响 V9 基线。

**验证点**:
- `is_degraded=True` + `degraded_reason` 包含 "insufficient_samples" 或 "small_sample"
- `public_score=0.0` + `private_score=0.0` (不产生误导性评分)
- `recommendation="continue"` (不晋升不回滚)
- HC-1: Feature Flag 关闭时返回降级报告 (不抛异常)
- HC-4: 不修改 daily_returns.jsonl / positions.json / V9 模型
