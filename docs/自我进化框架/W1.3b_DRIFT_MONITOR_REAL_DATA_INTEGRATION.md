## 二、设计方案 — DriftShadowIntegrator 桥接模块

### 2.1 核心思路

**不修改** DriftMonitor 和 DelayedLabelTracker 的核心逻辑 (HC-1: 不切 Feature Flag, 保持默认行为),
新增一个 **DriftShadowIntegrator** 桥接模块, 负责:

1. 从 `daily_returns.jsonl` 读取真实 Shadow 收益
2. 从 V9 模型产出读取预测分布
3. 调用 `DelayedLabelTracker.update_actual_labels_batch()` 注入真实收益作为标签
4. 调用 `DriftMonitor.run_daily_check()` 用真实特征 panel 做漂移检测
5. 调用 `DelayedLabelTracker.compute_delayed_metrics()` 计算 IC/IC_IR
6. 若 IC_IR 退化 > 阈值, 触发 DriftMonitor 告警 (桥接两者)

### 2.2 类设计

```python
# 位置: utils/alpha/drift_shadow_integrator.py

class DriftShadowIntegrator:
    """DriftMonitor + DelayedLabelTracker + Shadow 真实数据桥接器 (W1.3b).

    设计原则:
        1. 不修改 DriftMonitor / DelayedLabelTracker 核心逻辑 (HC-1)
        2. 不切 Feature Flag (USE_DRIFT_DETECTOR 保持 False, 用 sim_mode=True)
        3. fail-safe: 任一模块失败不中断 EOD 工作流
        4. 增量运行: 每日盘后调用, 累积漂移历史

    集成点:
        - v84_PostMarket (15:30) → run_phase4_5_shadow 之后
        - v84_EvolutionEval (16:05) → 评估前确保漂移数据已更新
        - 手动 CLI: py scripts/drift_shadow_integrator.py --date 2026-08-07
    """

    def __init__(
        self,
        drift_monitor: SimModeDriftMonitor,
        label_tracker: DelayedLabelTracker,
        daily_returns_path: Path = DEFAULT_DAILY_RETURNS_PATH,
        feature_panel_loader: Callable[[str], pd.DataFrame] = None,
        prediction_loader: Callable[[str], np.ndarray] = None,
        ic_degradation_threshold: float = 0.3,  # IC_IR 退化 > 0.3 触发告警
    ) -> None: ...

    def run_daily_integration(
        self,
        date: str,
        current_panel: Optional[pd.DataFrame] = None,
        current_predictions: Optional[np.ndarray] = None,
    ) -> IntegrationResult:
        """每日集成运行.

        步骤:
            1. 从 daily_returns.jsonl 读取当日真实收益
            2. 若 current_panel 传入, 调用 drift_monitor.run_daily_check()
            3. 若 current_predictions 传入, 调用 label_tracker.record_predictions_batch()
            4. 用真实收益更新 label_tracker 的 actual_label
            5. 调用 label_tracker.compute_delayed_metrics() 计算 IC/IC_IR
            6. 检测 IC_IR 退化, 若超阈值则生成告警

        Args:
            date: 日期 (YYYY-MM-DD)
            current_panel: 当日特征 panel (None 时跳过特征漂移检测)
            current_predictions: 当日预测分布 (None 时跳过预测漂移检测)

        Returns:
            IntegrationResult: 含 drift_reports, delayed_metrics, ic_degradation, alerts
        """
        ...

    def backfill_history(
        self,
        start_date: str,
        end_date: str,
        panel_history: Optional[dict[str, pd.DataFrame]] = None,
        prediction_history: Optional[dict[str, np.ndarray]] = None,
    ) -> list[IntegrationResult]:
        """历史回填 (用于 2026-07-23 ~ 2026-08-10 观察期).

        遍历日期范围, 对每个交易日调用 run_daily_integration.
        若 panel_history / prediction_history 未提供, 仅做收益标签回填 + IC 计算.

        Args:
            start_date: 起始日期
            end_date: 结束日期
            panel_history: {date: panel} 历史特征 panel
            prediction_history: {date: predictions} 历史预测

        Returns:
            list[IntegrationResult]: 每日结果
        """
        ...

    def calibrate_psi_thresholds(
        self,
        reference_period_days: int = 14,
        target_false_positive_rate: float = 0.05,
    ) -> dict[str, float]:
        """PSI 阈值校准 (W1.3b 核心交付之一).

        用参考期 (观察期前 N 天) 的特征分布作为基准,
        计算各特征的 PSI 分布, 校准阈值使得误报率 ≈ target_false_positive_rate.

        策略:
            1. 取参考期 daily_returns + 特征 panel
            2. 对每个特征, 用 rolling window 计算 PSI 序列
            3. 取 PSI 分布的 95th percentile 作为 HIGH 阈值
            4. 取 99th percentile 作为 CRITICAL 阈值
            5. 输出校准报告

        Args:
            reference_period_days: 参考期天数 (默认 14)
            target_false_positive_rate: 目标误报率 (默认 5%)

        Returns:
            {feature: {"low": float, "medium": float, "high": float, "critical": float}}
        """
        ...
```

### 2.3 数据流

```
W1.3a 产出                    W1.3b 新增
─────────────                ──────────────────────────────────────
daily_returns.jsonl  ──────► DriftShadowIntegrator
                              │
V9 模型预测 ──────────────────►│ (record_predictions_batch)
                              │
V9 特征 panel ────────────────►│ (run_daily_check)
                              │
                              ▼
                     ┌─────────────────────┐
                     │ DelayedLabelTracker │ ──► IC / IC_IR / RankIC
                     │   (update_label)   │
                     └─────────────────────┘
                              │
                     ┌─────────────────────┐
                     │   DriftMonitor      │ ──► PSI / KS / DriftReport
                     │ (run_daily_check)   │
                     └─────────────────────┘
                              │
                              ▼
                     IntegrationResult
                     (drift_reports + delayed_metrics + alerts)
                              │
                              ▼
                     reports/drift/integration_{date}.json
```

### 2.4 安全护栏

| 护栏 | 阈值 | 动作 |
|---|---|---|
| IC_IR 退化 | `|baseline_ic_ir - current_ic_ir| > 0.3` | 生成 HIGH 告警, 不自动回滚 (HC-4) |
| PSI 超阈值 | `psi >= 0.25` (HIGH) | 生成 DriftReport, 写入 reports/drift/ |
| 数据不足 | `len(records) < 20` | 降级模式, 仅记录不告警 |
| 模块异常 | DriftMonitor/DelayedLabelTracker 任一失败 | fail-safe 跳过, 不中断 EOD |
| Feature Flag | `USE_DRIFT_DETECTOR=False` | 用 sim_mode=True 绕过, 不切 Flag (HC-1) |
