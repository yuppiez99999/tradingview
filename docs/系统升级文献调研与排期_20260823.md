## 4. 验收标准（全局）

### 4.1 量化指标
- Alpha 因子：IC ≥ 基准 + 5%，因子数 -50%
- AI 决策：风险调整收益提升，防泄漏评估通过
- 对冲：尾部保护指标（CVaR）改善 ≥ 10%
- 组合优化：Sharpe 提升 ≥ 15%
- 执行：日成本降 ≥ 50%，无合规违规
- ML：预测精度提升，复杂度降 ≥ 10%

### 4.2 质量门禁
- 所有改动通过 pre-commit + CI（ruff/mypy/bandit/pytest）
- 覆盖率 ≥ 80%
- P0 文件无裸 print
- 零硬编码绝对路径
- 旧接口向后兼容

### 4.3 文档归档
- 每模块集成完成 → `cairn/LOG.md` 追加条目
- Sprint 完成 → `cairn/system-upgrade-lit-{sprint}.md` 沉淀
- 全量完成 → `docs/系统升级完成报告_20261102.md`
