## 六、关键经验沉淀

1. **子代理行号不可直接采信**：子代理易基于旧版本/幻觉报告不存在的缺陷（Wave6 全部待复核项为误报）。必须用 AST 脚本 + `read_file` 逐行确认。
2. **AST 扫描要处理默认值**：参数检查必须结合 `args.defaults`，避免误判合法默认值为"参数不符"。
3. **`except: pass` 需区分"容错回退"与"静默吞错"**：多级价格回退是合理设计；掩盖真实错误（如 `pd` 未导入）是 bug。
4. **修改前必须确认作用域**：`raise ... from e` 仅在对应 except 块内有效，避免引入 `NameError`。
