### 3.1 chrome-devtools-mcp 的对照价值（诚实记录）

Wave 14 曾注记 Crawl4AI 的安全披露史（v0.9.3 任意文件写入 / SSRF / 两处 XSS）。本轮出现的 `chrome-devtools-mcp` 具备两点 Crawl4AI 不具备的优势：

1. **官方来源**：ChromeDevTools 组织（Google 侧）维护，`pushed_at` 为昨日；
2. **许可干净**：Apache-2.0（宽松许可，符合 §2.3 新增判据）。

**结论**：若 2027 年确实需要动态站点采集，**优先评估 chrome-devtools-mcp 而非 Crawl4AI**。此为对照注记，不构成引入建议——当前 trafilatura+feedparser 已覆盖静态站点需求。
