## 4. 接入计划（最小化，3 项）

### 4.1 [阶段2a] 借鉴 Iteration Compact 模板格式 → 量化策略迭代单页模板
- **不复制 ECC 内容**，只借鉴其「Iteration Compact」的**单页结构化字段格式**
- 适配为量化策略迭代模板，字段映射：Goal→策略假设 / Mistake budget→回测容错 / Eval slices→IC 分层 / Rollback→策略下线条件
- 产出: `cairn/strategy-iteration-compact-template.md`
- 验收: 模板字段贴合量化语境，与现有 `factor-discovery-loop-engineering.md` 互补不冲突

### 4.2 [阶段2b] ECC python rules 作为 CI **对照基线**（非替代）
- 量化系统 ruff.toml/mypy.ini/.pylintrc 已更严格，**不替换**
- 仅把 ECC `rules/python/{coding-style,patterns,security,testing}.md` 作为**对照清单**，核对量化系统 CI 是否遗漏通用规则
- 产出: `docs/ecc-python-rules-crosscheck_20260821.md`（差异清单，无代码改动）
- 验收: 若发现量化系统未覆盖的通用规则，记录为可选增强项；否则记录"已全覆盖"

### 4.3 [阶段2c] deep-research skill 接入可行性评估（不直接配 MCP）
- deep-research 依赖 firecrawl/exa MCP，需额外配置 + API key
- 本阶段**仅评估**接入对宏观研究（康波/十五五/社保ETF/大宗商品）的增量价值，不直接配置
- 产出: `docs/deep-research接入可行性_20260821.md`
- 验收: 给出"建议接入/暂缓/不接入"结论 + 理由
