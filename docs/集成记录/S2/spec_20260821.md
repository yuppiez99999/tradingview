# S2 spec — timesfm 时序预测头 (requirement + design 合并)

> 2026-08-21 | 集成到 `lgb_tscv_trainer.py` (969行)

## 1. 现状与缺口

**主系统** `lgb_tscv_trainer.py`: LightGBM + TimeSeriesSplit, 基于特征矩阵预测, 需大量特征工程。
**缺口**: 长序列(>2048)零样本预测 + 分位区间, LightGBM 无概率预测。
**timesfm 2.5**: 200M 参数, 16k 上下文, 连续分位 horizon 1k, LoRA 微调, 零样本, Apache-2.0。

## 2. 需求 (EARS)

- **REQ-1 零样本预测**: 给定单变量时序 (价格/收益率), 返回 {point, p10, p50, p90} 分位预测, 无需训练。
- **REQ-2 预检降级**: 加载前检查 RAM(>2GB)/GPU(>1GB VRAM 可选)/磁盘(>1GB), 不满足则 `available=False`, 不崩溃。
- **REQ-3 依赖降级**: `import timesfm` 失败时 `available=False`, forecast 返回 None, 调用方降级到 LightGBM。
- **REQ-4 hybrid 融合**: `final_pred = α * lgb_pred + (1-α) * timesfm_pred`, α 可配置 (默认 0.6 偏 LightGBM)。
- **REQ-5 协变量**: 支持 XReg 协变量预测 (可选, 需 `timesfm[xreg]`)。
- **REQ-6 向后兼容**: `--predictor=lightgbm` (默认) 行为与集成前一致。
- **REQ-7 不可变性**: forecast 不修改输入序列, 返回新数组。
- **REQ-8 性能**: 单序列 forecast < 2s (CPU), 批量 15 标的 < 30s。

## 3. 设计

### 3.1 模块结构
```
utils/timesfm_predictor.py          # 主模块 (~280行)
config/timesfm_predictor.yaml       # 配置
tests/test_timesfm_predictor.py     # 单测 (mock timesfm)
```

### 3.2 接口
```python
@dataclass
class ForecastResult:
    point: np.ndarray               # 点预测
    p10: Optional[np.ndarray] = None
    p50: Optional[np.ndarray] = None
    p90: Optional[np.ndarray] = None
    available: bool = True
    model: str = "timesfm-2.5"

class TimesFMPredictor:
    def __init__(self, config_path: str = "config/timesfm_predictor.yaml"): ...
    def preflight_check(self) -> bool: ...           # RAM/GPU/磁盘
    def forecast(self, series: np.ndarray, horizon: int = 5) -> ForecastResult: ...
    def forecast_with_covariates(self, series, xreg_dynamic, xreg_static, horizon) -> ForecastResult: ...
    def hybrid_blend(self, lgb_pred: float, timesfm_result: ForecastResult, alpha: float = 0.6) -> float: ...
```

### 3.3 内部流程
```
__init__:
  ├─ load config
  ├─ try import timesfm → self._tfm = tfm.TimesFm(...) or None
  └─ preflight_check → self.available

forecast(series, horizon):
  if not self.available: return ForecastResult(point=zeros, available=False)
  try:
    ctx_len = min(len(series), 16384)
    point, quantiles = self._tfm.forecast(series[-ctx_len:], horizon)
    return ForecastResult(point, p10=quantiles[0.1], ...)
  except: return ForecastResult(available=False)

hybrid_blend(lgb_pred, timesfm_result, alpha):
  if not timesfm_result.available: return lgb_pred
  return alpha * lgb_pred + (1-alpha) * timesfm_result.point[0]
```

### 3.4 配置 (config/timesfm_predictor.yaml)
```yaml
enabled: true
model_version: "2.5"
checkpoint: "models/timesfm/"           # 800MB
context_length: 16384
horizon_default: 5
quantiles: [0.1, 0.5, 0.9]
preflight:
  min_ram_gb: 2.0
  min_disk_gb: 1.0
  gpu_optional: true
hybrid:
  alpha: 0.6                             # LightGBM 权重
device: "auto"                           # auto/cpu/gpu
```

### 3.5 集成 (lgb_tscv_trainer.py)
- `main()` argparse 加 `--predictor` (lightgbm/timesfm/hybrid, 默认 lightgbm)
- `--predictor timesfm`: 对每 symbol 用 `load_returns_history` 取时序 → `TimesFMPredictor.forecast`
- `--predictor hybrid`: LightGBM 训练后, latest_pred 用 `hybrid_blend` 融合 timesfm 预测
- 默认 lightgbm: 原流程不变 (向后兼容)

## 4. 降级策略
- timesfm 未安装 → available=False, forecast 返回 zeros, hybrid_blend 返回 lgb_pred
- preflight 不满足 → available=False
- forecast 异常 → 返回 ForecastResult(available=False), 日志 warning
- 整层失败 → 调用方降级到 LightGBM

## 5. 验收
- [ ] timesfm 未安装时 available=False, 不崩溃
- [ ] forecast 返回分位区间 (mock 验证)
- [ ] hybrid_blend 在 timesfm 不可用时返回 lgb_pred
- [ ] --predictor=lightgbm 与集成前一致 (回归)
- [ ] 单测覆盖 preflight/forecast/covariate/hybrid/降级, ≥80%
- [ ] ruff + pytest 通过

## 6. 不做 (YAGNI)
- 不做 LoRA 微调 (零样本足够, 微调留后续)
- 不做 GPU 强制 (CPU 可用, GPU 可选)
- 不做实时流式预测 (批量离线即可)
- 不做多变量 VAR (timesfm 是 univariate, 多变量用 XReg 协变量)
