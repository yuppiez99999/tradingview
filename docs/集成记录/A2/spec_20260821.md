# A2 spec — SkillSpector 安全门禁 (requirement + design 合并)

> 2026-08-21 | 集成到 `scripts/pre_commit_check.py` + `githooks/pre-commit`

## 1. 现状与缺口
**主系统**: githooks/pre-commit → scripts/pre_commit_check.py (P0 print门禁+NaN守卫+悬挂引用)。
**缺口**: 大量第三方 skill (FinClaw 1031 + ECC 64 + ai-berkshire 18) 未经安全扫描, AGENTS.md 标注 26.1% 技能有漏洞。
**SkillSpector**: NVIDIA 出品, 64 漏洞模式 16 类 (prompt injection/data exfil/privilege escalation/supply chain...), SARIF 输出, Apache-2.0。

## 2. 需求 (EARS)
- **REQ-1 增量扫描**: pre-commit 仅扫描 PR 改动的 skill 文件 (.claude/skills/ + SKILL.md), 不全量。
- **REQ-2 阈值阻断**: critical/high 阻断提交 (exit 1), medium/low 警告 (exit 0)。
- **REQ-3 降级**: skillspector 未安装时跳过 + 日志, 不阻断提交 (容错)。
- **REQ-4 SARIF 归档**: 全量扫描结果归档 reports/skill_security/YYYY-MM-DD.sarif。
- **REQ-5 可开关**: SKIP_SKILL_SCAN=1 跳过 (紧急); SKILL_SCAN_FULL=1 全量扫描。
- **REQ-6 性能**: 增量扫描 < 10s (单 skill), 全量 < 5min。

## 3. 设计
### 3.1 模块
```
scripts/skill_security_scan.py     # 封装 SkillSpector CLI (~200行)
tests/test_skill_security_scan.py  # 单测 (mock subprocess)
```

```python
def get_changed_skill_files(repo_root: Path) -> list[Path]:
    """git diff 获取改动的 skill 文件 (增量)。"""
def is_skill_file(path: Path) -> bool:
    """判断是否 skill 文件 (.claude/skills/ 或D 或 SKILL.md/skills/*.md)。"""
```

### 3.3 流程
```
scan_skills(targets):
  ├─ 检查 skillspector 可用 (subprocess --version)
  ├─ 不可用 → return ScanResult(available=False)
  ├─ 调用 skillspector scan <targets> --format sarif --no-llm
  ├─ 解析 SARIF → 统计 critical/high/medium/low
  ├─ 归档 SARIF 到 reports/skill_security/
  └─ return ScanResult(blocked = critical+high > 0)
```

### 3.4 集成 (pre_commit_check.py)
- 加 _check_skill_security() 函数
- SKIP_SKILL_SCAN=1 跳过
- 增量: get_changed_skill_files() → scan_skills() → blocked 则 exit 1
- 容错: 任何异常 exit 0 (不阻断开发)

## 4. 验收

- [ ] 增量扫描仅处理改动 skill 文件

- [ ] SKIP_SKILL_SCAN=1 跳过

## 5. 不做 (YAGNI)
- 不做 LLM 语义评估 (--no-llm, 纯静态规则, 避免依赖 API key)
- 不做 CI job (本次仅 pre-commit, CI 留后续)
- 不做实时修复建议 (仅报告, 修复人工)
