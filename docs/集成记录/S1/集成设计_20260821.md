    def score_relevance(self, news: NewsItem, symbol: str) -> float: ...

        """转为 signal_fusion 可消费的信号格式"""

### 3.3 集成点 (signal_fusion.py)
- 在多源融合的信号源列表加 `news_intelligence` 源
- 新闻信号权重可配置 (config/signal_fusion.yaml)
- 复用 TradingAgents 的多 LLM 路由 (DashScope/DeepSeek/Google/OpenRouter) 补充 glm5_client
