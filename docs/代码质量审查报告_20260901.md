| 文件 | now / base | 增量 | 性质 |

## 2. 🟡 建议项（P1，两周内）

### P1-1 bandit B608：SQL 字符串拼接（1 处，风险上调）

**位置**: `quant_modules/ai_hedge_fund/graph/checkpointer.py:107` — LangGraph SQLite checkpointer 的查询构造。

**判定**: 这是 AI Hedge Fund 生产链路模块（非 scripts/ 一次性脚本），SQL 注入面在"LLM 生成内容入库"场景下**不是纯理论风险** — LLM 输出若含恶意 SQL 片段且被拼入查询，存在实际攻击面。虽然输入主要来自系统自身的对话状态，但按 §1.2 安全清单（"无 SQL 字符串拼接 — 参数化查询"）应为 🔴；考虑该模块当前为研究/shadow 路径、非实盘资金链路，定为 **P1 优先执行**（半天工作量，修复后可彻底闭环）。

**修复**: 改参数化查询；若为第三方 LangGraph 代码样式则确认输入白名单后加 `# nosec B608` 注记说明理由（对齐 08-30 已处理的 code_graph_rag.py 同类项）。

### P1-2 新脚本 parse_tdx_results.py 22 个 ruff 违规（门禁逃逸样本）
