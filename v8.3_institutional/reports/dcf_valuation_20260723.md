## 八、附录:DCF模型公式

### 简化DDM模型

```
V₀ = Σ [Dt / (1+r)^t] + [Pn / (1+r)^n]

其中:
V₀ = 内在价值
Dt = t期预期股息(分配收益)
r = 折现率(WACC近似值)
n = 预测期(5年)
Pn = 终端价值(永续增长模型)

终端价值:
Pn = D(n+1) / (r - g)

其中:
g = 永续增长率(通常2-3%)
D(n+1) = 第n+1期预期股息
```

### CAPM模型(计算WACC近似值)

```
R = Rf + β × (Rm - Rf)
  = Rf + β × ERP

其中:
R = 预期回报率
Rf = 无风险利率
β = Beta系数
Rm = 市场回报率
ERP = 股权风险溢价
```
