# 风控审计修复方案 v8.6.1

## Context（背景）

以世界顶级对冲基金视角审计发现系统存在 6 个问题：
1. **P0**: `run_daily_eod.py` 不存在 — README 声称的"每日 EOD 后强制执行四 Guard 链"完全不存在
2. **P0**: `register_eod_task.ps1` 指向 v7.1 项目路径 — EOD 定时任务会静默失败
3. **P0**: `KillSwitch._get_margin_status()` 使用硬编码模拟值 0.20 — 保证金熔断形同虚设
4. **P1**: README 资金分配声称 400万/100万，实际代码为 300万/200万（用户确认代码正确）
5. **P1**: `trade_plan` 版本号为 v7.7 而非 v8.6.1
6. **P1**: `daily_workflow.py` 未调用 `RiskGuardIntegrator` — 四 Guard 链不在日常工作流中

用户决策：资金分配保持 60/40（代码正确），KillSwitch 读取持仓文件估算保证金。

---

## 修复方案（6 项）

### Fix 1: 创建 run_daily_eod.py（P0）

**目标**：实现 EOD 四 Guard 链强制执行入口

**创建文件**：`e:\各种PY程序\28-终极量化交易系统8.4\run_daily_eod.py`

**实现逻辑**：
1. 计算下一交易日（跳过周末）
2. 加载次日 trade_plan（`v8.3_institutional/trade_plans/trade_plan_{next_date}.json`）
3. 调用 `RiskGuardIntegrator(report_date=today).run_all_guards(next_trade_date=next_date)`
4. 保存更新后的 trade_plan（含 risk_guard 结果）
5. 生成 EOD 摘要报告到 `每日报告归档/{today}/eod_guard_report_{today}.md`
6. 若任一 Guard 失败，输出 CRITICAL 日志

**复用已有代码**：
- `utils/risk_guard_integrator.py:595` — `RiskGuardIntegrator.run_all_guards()`
- `utils/risk_guard_integrator.py:44` — `RiskGuardIntegrator.__init__(report_date)`

**命令行接口**：
```bash
python run_daily_eod.py [--date YYYY-MM-DD] [--dry-run]
```

### Fix 3: KillSwitch 读取持仓文件估算保证金（P0）

**目标**：用真实持仓数据替代硬编码 0.20

**修改文件**：`e:\各种PY程序\28-终极量化交易系统8.4\utils\kill_switch.py`

**修改方法**：`_get_margin_status()`（第 69-122 行）

**新逻辑**：
1. 读取 `config/positions.json`
2. 遍历 `positions` 字典，累加所有 `amount` 字段得到 `total_position_value`
3. 从 `meta.total_capital` 获取总资本
4. 计算 `margin_usage_ratio = total_position_value / total_capital`
5. 若文件不存在或解析失败，返回保守值 `0.50`（L1 阈值，触发警觉）
6. 保留 TRADING_ENV=production 的 fail-closed 逻辑不变

**数据源**：
- `config/positions.json:meta.total_capital` = 5,000,000
- `config/positions.json:positions[*].amount` = 各持仓市值
