# EOD 数据断链诊断（observed=0/0, actual_pnl=0）

## 症状
下游模块读不到上游预测/持仓数据：`DriftShadowIntegrator` observed=0/0、
压力测试 `actual_pnl=0`、alpha_signals 从不产出。

## 根因
双代码路径盲区——同一数据有多条产出路径，仅部分路径落盘；
或 CLI 未传入上游文件导致读取默认值；诊断报告可能过时，未反映当前代码状态。

## 修复
五步核查法：
1. 列出所有应产出文件；
2. 逐一验证存在；
3. 追溯上游代码路径（是否存在等价落盘）；
4. 区分代码缺失 vs 运行时问题；
5. 修复后重新运行验证。

## 验证命令
```bash
python assert_data_validity.py     # D1-D7 断言全 PASS
```

## 防复发
同一数据的所有产出路径必须有等价落盘行为；
诊断前重新运行代码验证当前状态，而非仅读旧诊断报告。
