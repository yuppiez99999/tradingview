## 系统概述

综合量化策略系统 v7.5 是一个专业量化交易平台，在 v7.4 基础上引入机构级风控、三联对冲、智能执行与严格回测协议。系统以 500 万元人民币为基础管理规模，目标年化收益 >= 8%，最大回撤控制在 15% 以内。

**v7.5 核心升级（机构级实盘交易系统）**：
- **风险预算**：Risk Parity + Improved Kelly Criterion + 三级回撤防御
- **三联对冲**：Beta/Vol/Correlation 三类对冲实时联动
- **智能执行**：Iceberg + TWAP/VWAP/POV + 滑点熔断 + NTP 时间同步
- **回测严谨性**：Walk-Forward + 三段极端行情压力测试
- **全模块自动调度**：盘前 Wind 校准 + v5 优化 + 每日工作流；盘后 黑天鹅测试 + 汇总报告
- **Qlib 信号集成**：本地 LightGBM 深度学习信号生成，36 个技术指标特征，自动注入 SignalFusion 并映射为订单调整（加仓 30% / 减仓 50% / 跳过）
- **订单智能调整**：Qlib 信号直接参与 Phase 5/6，强看多自动加仓、中性维持、看空减仓或跳过，实现信号到执行的闭环

**v7.4 核心升级（个股分档建仓执行）**：
基于外部 PDF 研报《中国神华股价分析与建仓策略》(2026-07-03)，将"三档分批建仓"策略数字化为可执行的 workflow 阶段，实现"研报→JSON→订单"的全自动转化：
- **三档建仓策略**：第一档(底仓)40-42元35%仓位 + 第二档(加仓)36-39元35%仓位 + 第三档(重仓)32-35元30%仓位
- **智能价格档位判断**：折价(中枢下方2%)积极买入 / 正常区间拆分上下午 / 溢价(中枢上方3%)跳过 / 异常波动(偏离8%)阻断
- **Phase 4 风险联动**：emergency_level≥2 阻断建仓 / =1 资金倍率减半 / =0 正常执行
- **股息率锚定**：4.64%→5.20%→5.80% 三档股息率递增，估值驱动+安全边际双重保障

**v7.3 核心升级（因果验证与稳健性检验）**：
借鉴 AERS 的因果推断方法论，为量化策略补上"因果性"这一环——一个策略过去赚钱不代表未来也赚，可能只是碰巧适配了历史行情。新增三大因果验证工具和五维稳健性检验框架：
- **DID 双重差分**：评估事件/信号对收益的真实因果影响，剔除市场整体波动干扰
- **安慰剂检验**：随机置换事件日期100次，验证策略收益是否显著优于随机水平（p<0.05）
- **RDD 断点回归**：验证均线突破、估值阈值类策略在断点处的真实收益跳跃
- **五维稳健性检验**：子样本一致性 + 参数敏感性 + 成本敏感性 + Bootstrap稳定性 + 剔除稳定性，综合评分0-100分

**v7.2 核心升级（黑天鹅极端行情防护）**：
基于对2000年互联网泡沫（NASDAQ -76.81%）和2008年次贷危机（S&P 500 -56.8%，VIX 89.53）两场历史级危机的深度研究，系统性修复了6项关键不足：
- **日内动态熔断**：四级熔断引擎（3%/5%/7%/9%跌幅），交易时段内30秒监控，解决盘前单次决策盲区
- **风控执行引擎**：将风控决策转化为实际可执行订单（减仓/期货对冲/期权保护），替代原有空壳执行
- **相关性崩溃非线性建模**：共振乘数因子（最高2.35x）+ 分散化失效损失 + 尾部放大效应，替代线性叠加
- **期权流动性自适应**：VIX>40启动流动性折价，VIX=89时实际覆盖率从100%降至1.5%，校准2008年权利金膨胀20倍
- **涨跌停板专项处理**：连续跌停计数+止损单积压管理+替代执行策略（期货对冲替代直接卖出）
- **对手方风险监控**：券商/期货公司信用风险评分+对冲有效性折价+雷曼式违约模拟

## 7月6日自动交易建仓计划

基于 2026年交易计划_优化版_v2.md、长江电力分红再投资分析、中国神华建仓策略、棉花期权保护策略，生成 7月6日开始的自动交易建仓计划。

### Qlib 信号集成说明

- **信号来源**：`daily_workflow.py --phase signal` 生成，写入 `phases.signal.qlib_signals`
- **训练方式**：`train_qlib_models.py` 对真实交易计划 21 个标的批量训练，默认 500 天周期
- **模型回退**：优先 Qlib 原生；不可用时回退本地 LightGBM，保证流程不中断
- **特征工程**：MA/MACD/RSI/BOLL/ATR/OBV/量比/波动率/量价背离/高低价位置等 36 个技术指标
- **注入方式**：通过 `SignalFusion.inject_qlib_signal()` 写入融合引擎
- **订单调整**：Phase 5/6 读取 Qlib 信号并映射为加仓 30% / 减仓 50% / 跳过，日志输出 `Qlib 加仓/减仓/跳过`

## 风控规则

### 个股止损

| 标的类型 | 止损线 | 触发操作 |
|----------|--------|----------|
| 宽基 ETF | -8% | 减半仓，观察3日 |
| 科技成长股 | -10% ~ -15% | 清仓，重新评估 |
| 防御/红利股 | -8% | 减半仓 |
| 黄金 ETF | -8% 减半仓 / -12% 清仓 | 避免误触发 |

### 组合回撤控制

| 回撤幅度 | 操作 |
|----------|------|
| -5% | 预警：检查持仓，准备加仓机会 |
| -8% | 减仓：权益仓位降至70%，现金提至30% |
| -10% | 警戒：权益仓位降至50%，现金提至50% |
| -15% | 清仓：全部止损，保留现金 |

### 日内断路器

| 指标 | 阈值 | 操作 |
|------|------|------|
| 单日组合回撤 | -3% | 停止当日买入 |
| 单日组合回撤 | -5% | 强制减仓30% |
