## 一、修复背景

系统在运行 `run_daily.bat pre` 时暴露以下数据异常问题：

1. **日期顺序混乱**：`returns_history.json` 中历史日期乱序，且混用 `T16:00:00.000Z` / `T00:00:00` 两种格式
2. **极端异常值**：组合加权年化收益率出现 `+3.585e+64%` 等不可能值
3. **Wind MCP 配额耗尽**：当日配额用尽后，系统未优雅降级，导致异常值污染后续决策
4. **除零/NaN/Inf 传播**：多个模块在计算夏普、最大回撤、波动率时未做边界检查

**修复目标**：
- 年化收益 ≥ 8%
- 最大回撤 < 15%
- 2030-12-31 强制清仓
- 系统稳定性：零崩溃、零异常值污染

## 三、核心修复细节

### 3.1 日期顺序异常自动纠正

**问题**：`returns_history.json` 日期乱序且混用两种格式  
**修复**：
```python
# 强制按日期排序，确保 start <= end
sorted_dates = sorted(dates, key=lambda d: str(d)[:10])
if dates != sorted_dates:
    data = np.array([data[date_to_row[d]] for d in sorted_dates])
    dates = sorted_dates
```

### 3.2 日期区间合法性校验

**问题**：排序后 `start_date > end_date`，导致 `days = -356`，年化计算爆炸  
**修复**：
```python
days = (datetime.strptime(end_date, "%Y-%m-%d") - datetime.strptime(start_date, "%Y-%m-%d")).days
if days <= 0:
    print(f"[ERROR] 日期区间异常: {start_date} → {end_date} (days={days})")
    return
years = max(days / 365.25, 0.01)
```

### 3.3 异常值多层过滤

**问题**：极端年化收益 `+3.585e+64%` 污染决策  
**修复**：
```python
# 有效数据点 < 5 个 → 跳过
if len(valid) < MIN_VALID_POINTS:
    continue

# 累计收益率接近 -1 → 跳过
if (1 + cum) <= 1e-6:
    print(f"[SKIP] {code}: 累计收益率异常")
    continue

# 年化收益超出合理范围 → 跳过
if not (MIN_ANNUALIZED <= annualized <= MAX_ANNUALIZED):
    print(f"[SKIP] {code}: 年化收益异常")
    continue
```

### 3.5 除零/NaN/Inf 传播保护

**问题**：多个模块在计算夏普、最大回撤、波动率时未做边界检查
