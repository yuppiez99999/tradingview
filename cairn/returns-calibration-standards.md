# 年化收益校准标准 v1.0

> **创建**: 2026-08-04 | **最后更新**: 2026-08-04
> **关联文件**: `v8.3_institutional/calibrate_returns_projection.py`、`tools/calc_realized_returns.py`
> **触发背景**: 300308 中际旭创年化 +483.6% 异常暴露阈值与收缩机制缺失

---

## 1. 适用范围

本标准适用于所有需要从历史价格数据计算已实现年化收益率的场景：

- `daily_workflow.py --phase calibrate`（Phase 1.5 收益预测校准）
- `tools/calc_realized_returns.py`（独立年化计算工具）
- 任何需要对个股/ETF/指数做年化收益率评估的模块

---

## 2. 核心参数

| 参数 | 值 | 含义 | 依据 |
|---|---|---|---|
| `MAX_ANNUALIZED` | **2.0** | 年化收益率上限 (+200%) | A 股个股单年度最大可重复收益率；超过视为短期暴涨外推 |
| `MIN_ANNUALIZED` | **-0.99** | 年化收益率下限 (-99%) | 个股最大可能年度跌幅 |
| `BAYESIAN_PRIOR` | **0.15** | 贝叶斯收缩先验 (+15%) | A 股长期权益收益率中枢（沪深 300 全收益年化约 8-12%，成长股溢价 +3-5%） |
| `SHRINK_THRESHOLD` | **±0.5** | 触发收缩的年化绝对值阈值 (±50%) | 超过 50% 年化在 A 股不可持续 |
| `SAMPLE_PERIOD_THRESHOLD` | **2.0 年** | 短周期判定阈值 | 样本期 < 2 年的年化可靠性低 |
| `MAX_SHRINK_WEIGHT` | **0.7** | 最大收缩强度 | 保留至少 30% 原始信号，不完全抹除 |

---

## 3. 计算流程

```
原始价格序列 (parquet)
    ↓
日收益率序列 = (P_t / P_{t-1}) - 1
    ↓
累计收益率 = product(1 + r_i) - 1
    ↓
样本期年数 = (最后日期 - 最初日期) / 365.25
    ↓
原始年化 = (1 + 累计收益)^(1/年数) - 1
    ↓
[短周期贝叶斯收缩] ← 年数 < 2 且 |年化| > 50%
    ↓
[阈值截断] ← 超出 [-99%, +200%]
    ↓
最终年化收益率
```

---

## 4. 短周期贝叶斯收缩机制

### 4.1 触发条件

同时满足以下两个条件时触发：
1. **样本期 < 2.0 年**（数据量不足，年化外推不可靠）
2. **|原始年化| > 50%**（极端值，均值回归概率大）

### 4.2 收缩强度公式

```
shrink_weight = max(0.0, min(MAX_SHRINK_WEIGHT, 1.0 - years / SAMPLE_PERIOD_THRESHOLD))
```

| 样本期 | 收缩强度 | 原始信号保留比例 |
|---|---|---|
| 0.5 年 | 70%（封顶） | 30% |
| 1.0 年 | 50% | 50% |
| 1.5 年 | 25% | 75% |
| 2.0 年 | 0% | 100% |

### 4.3 收缩后年化

```
annualized = annualized * (1 - shrink_weight) + BAYESIAN_PRIOR * shrink_weight
```

**物理直觉**：样本期越短，我们越不信任其极端年化，越倾向于向 A 股长期均值（15%）回归。

---

## 5. 阈值截断规则

收缩后仍需通过阈值截断：

| 情况 | 处理 | 日志级别 |
|---|---|---|
| 年化 > +200% | SKIP（该标的不参与组合加权年化计算，权重=0） | WARNING |
| 年化 < -99% | 截断为 -99% | INFO |
| 阈值内 | 正常使用 | INFO |

**SKIP 不代表删除**：该标的仍保留在 returns_history 中，仅不参与当次组合年化加权。

---

## 6. 日志输出规范

每次收缩和截断必须输出可审计日志：

```python
# 收缩日志
logger.info(
    f"  [{code}] 短周期贝叶斯收缩: {original*100:+.1f}% → "
    f"{shrunk*100:+.1f}% (收缩强度 {weight*100:.0f}%)"
)

# SKIP 日志
logger.warning(
    f"  [SKIP] {code}: 年化收益率异常 ({annualized*100:+.2f}%)，"
    f"超出阈值 [{MIN_ANNUALIZED*100:.0f}%, {MAX_ANNUALIZED*100:.0f}%]"
)
```

## 7. 已知边界与不适用场景

1. **借壳上市/重组标的**：价格序列存在结构性跳变，贝叶斯收缩可能误判——此类标的应从样本池排除
2. **ETF 联接基金**：价格数据可能非交易日（大额申赎导致跳价），应优先使用净值数据
3. **长期停牌后复牌**：复牌首日补涨/补跌会导致短期年化极端值——收缩机制可正确处理
4. **样本期 < 60 个交易日**：数据量过少，年化无意义——建议直接使用 BAYESIAN_PRIOR 作为先验
