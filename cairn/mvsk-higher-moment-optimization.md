# MVSK 高阶矩组合优化（YAND 启发）

> 记录丘成桐团队 YAND 论文洞察、P1 偏度/峰度优化实现、A/B 验证结果、P2/P3 落地计划。
> 对应 ROADMAP 里程碑"多策略组合优化"子任务。P1 已完成并验证 (2026-08-17)。

## 一、论文核心洞察（YAND, Yau et al. 2026）

来源：知乎专栏 `zhuanlan.zhihu.com/p/2032808759018401957`（QuantML），丘成桐团队 YAND（Yau's Affine-Normal Descent）。

### 1.1 均值-方差四个盲区
1. **正态分布假设**：方差好算，偏度峰度难算，70 年被锁定在二阶矩
2. **对称性盲区**：方差对涨跌同等惩罚，上行/下行风险不分
3. **尾部风险失明**：2008 危机 VAR 系统性低估极端损失概率
4. **参数敏感性**：Markowitz's Curse，输入微扰→权重剧震

### 1.2 高阶矩的"维度恐惧"
N=1000 时 cokurtosis 张量需 8TB。现有解法（参数化压缩/因子降维/稀疏化）各有代价。HRP 回避了高阶矩但不碰偏度峰度。

### 1.3 YAND 突破
- **不显式建 coskewness/cokurtosis 张量**，直接在收益矩阵上操作，存储 O(N⁴)→O(N²)
- **仿射正规方向**（Blaschke 1920s 微分几何），坐标不变性——不同资产收益尺度差几个数量级时仍稳定
- **精确四次线搜索**（利用 MVSK 目标四次多项式结构），消除 Armijo 步长调参
- A 股 5440 只 × 48374 训练周期实证

### 1.4 三个关键发现
1. **倒 U 型曲线**：高阶矩只在"中等野心"收益目标区间发挥最大价值。极高收益/极低波动两端边际效用递减
2. **配置分裂**：小规模直接配置，几百~几千用 PCG+停滞恢复，无一套代码跑天下
3. **Regime 依赖**：高波动肥尾 regime 下 MVSK 显著跑赢 MV；低波动近似正态 regime 下增量有限。不能 set and forget

### 1.5 三个未解决问题（论文承认，工程落地须警惕）
1. **交易成本未纳入**：MVSK 可能比 MV 产生更频繁权重调整，A 股 T+1+高冲击成本下理论优势可能被削弱
2. **样本矩不稳定**：偏度/峰度样本估计比方差更不稳定，低信噪比下峰度严重偏低
3. **历史矩外推边界**：未见过尾部事件无法外推，所有历史矩方法共同约束

### 2.2 目标函数
```
max  w'μ - (δ/2) TE² + γ_s · skew(w'r) - γ_k · exkurt(w'r)
```
- `+γ_s·skew`：鼓励正偏度（右尾），γ_s 典型 0.5-2.0
- `-γ_k·exkurt`：惩罚超额峰度（肥尾），γ_k 典型 0.1-1.0
- skew/exkurt 由 `return_matrix @ w` 直接算，**不建 coskewness/cokurtosis 张量**，存储 O(T×N)

### 2.3 向后兼容
- 不传 `return_matrix` → 退化为纯 MV，`mvsk_enabled=False`
- `γ_s=0 且 γ_k=0` → 即使传 `return_matrix` 也不启用
- SLSQP 失败 → fail-open 回退投影梯度/缩放法（纯 MV，不纳入高阶矩）
- 原有 31 个 `risk_budget_optimizer` 测试全 passed

### 2.4 踩坑：符号写反（contains: sign-error, mvsk-symbol-bug）

**初次实现时目标函数符号写反**：写成 `-γ_s·skew + γ_k·exkurt`（惩罚正偏度+鼓励肥尾），导致 A/B 实验中 MVSK 偏度反而更差（-0.768 vs MV 的 0.0）。

**修正**：改为 `+γ_s·skew - γ_k·exkurt`（鼓励正偏度+惩罚肥尾）。

**根因**：docstring 描述正确（"鼓励正偏度/惩罚超额峰度"）但代码符号与描述相反，未对照推导验证。教训：目标函数符号必须从"喜欢什么→最大化里加正项，讨厌什么→最大化里减正项"推导，不能凭直觉写。

## 三-C、γ_s/γ_k 网格搜索结果（真实 A 股，2026-08-17）

7×7=49 组合网格：γ_s∈[0.1,0.3,0.5,0.8,1.0,1.5,2.0] × γ_k∈[0.05,0.1,0.2,0.3,0.5,0.8,1.0]。

### 最优组合

|---|---|---|---|---|---|---|

### 关键发现（contains: gamma-grid-insights）
1. **最佳实践 γ_s=0.1, γ_k=0.05**：净收益 19.82%（vs MV 24%），峰度 5.12（vs MV 7.94，降幅 35%），偏度 0.293（vs MV 0.047）。**几乎不牺牲收益却显著改善分布**——这就是论文倒 U 型曲线的峰值
2. **MV 的 24% 确认是 Markowitz's Curse 过拟合**：所有 49 个 MVSK 组合收益都低于 24%，说明 MV 把权重堆到高 μ 估计的股票上。MVSK 轻量版 19.82% 更稳健
3. **偏度-峰度正相关**（contains: skew-kurt-tradeoff）：γ_s 越大偏度越好但**峰度也越高**。追求极端正偏度（右尾肥）反而带来整体肥尾。γ_s=2.0 偏度 1.575 但峰度 12.47（比 MV 的 7.94 还差！）
4. **帕累托前沿全是 γ_s=0.1**：收益-峰度帕累托最优解中 γ_s 恒取 0.1，用 γ_k 调峰度。**γ_s 应取小值，γ_k 是调峰度的主要工具**
5. **倒 U 型曲线确认**：γ=0（纯MV，24%但峰度7.94）→ γ=小（19.82%，峰度5.12，最优）→ γ=大（3.74%，峰度12.47，过度优化崩塌）。峰值在轻量高阶矩优化端

### 落地建议
- **生产默认参数**：γ_s=0.1, γ_k=0.05（轻量优化，收益代价 <4%，峰度改善 35%）
- **激进版**（风险预算更宽时）：γ_s=0.3, γ_k=0.1（偏度 0.48，峰度 5.05，收益 15.97%）
- **避免**：γ_s>1.0（偏度-峰度正相关导致峰度反弹，非帕累托最优）

## 三-D、三阶段最优搜索结果（真实 A 股，2026-08-17）

阶段1 细网格 108 组合（γ_s×γ_k×δ）+ 阶段2 滚动窗口稳定性 + 阶段3 样本外验证（train 376/test 126）。

### 结果
- **阶段1 样本内**：Top 10 全是 γ_k=0.02（最小），γ_s∈[0.05,0.15]。最佳 γ_s=0.05/γ_k=0.02 → 夏普 1.183 净收益 22.06%。δ 无影响（TE 约束绑定）
- **阶段2 滚动窗口**：10/10 全稳定（夏普 CV 0.12-0.13），窗口均值 1.75-1.90
- **阶段3 样本外**（contains: out-of-sample-failure, markowitz-curse-evidence）：
  - **MV 样本外夏普 -1.27，收益 -26.3%**（训练期 +24%→测试期 -26%，翻转 50%！）
  - MVSK 样本外夏普 -1.26，收益 -26.3%（略好于 MV 但都严重亏损）
  - **所有参数样本外都大幅亏损**，不是 γ 调参能解决的

### 核心发现（contains: mvsk-boundary, mu-estimation-is-root-cause）
1. **MV 的 24% 是严重过拟合的铁证**：训练 +24% → 测试 -26%，Markowitz's Curse 直接验证。μ 估计在 126 日测试期完全反转
2. **MVSK 改善分布但不改善 μ 估计**：高阶矩优化能降峰度提偏度，但目标函数仍依赖 w'μ，μ 估计不稳定时 MVSK 同样失效
3. **样本内 γ 越小越好是过拟合信号**：Top 10 全是 γ_k=0.02（最小值），说明在样本内轻量高阶矩优化"看起来好"但样本外失效
4. **滚动窗口稳定性 ≠ 样本外预测力**：CV 0.12 很稳定，但样本外仍亏。稳定性只说明参数不敏感，不说明 μ 估计有效

### 最优方案结论（contains: optimal-strategy）
**单独调 γ_s/γ_k 无法解决样本外失效**。最优方案必须是组合拳：
- **MVSK（改善分布）** + **μ 估计改进（改善收益预测）** 双管齐下
- μ 估计改进路径：Black-Litterman（`black_litterman_optimizer.py` 已有，用观点注入修正 μ）/ 收缩估计 / 动量信号替代历史均值
- 推荐：先用 BL 后验 μ 替换历史 μ，再进 MVSK 优化器。这是 P2 的前置条件
- γ_s/γ_k 仍用 0.1/0.05（轻量改善分布），但 μ 必须换更稳健的估计

**这把 P2 的定义从"YAND 核心算法"扩展为"BL+MVSK 联合优化"** — 单独 YAND 解的是"如何高效算高阶矩"，但样本外失效的根因是 μ 估计，不是高阶矩计算效率。

### 核心发现（contains: bl-mvsk-synergy, p2-validated）
1. **BL+MVSK 是唯一显著优于等权和 MV 的方案**：夏普 -0.923 vs MV -1.272 vs 等权 -1.380，少亏 10%（-16% vs -26%）

5. **μ 收缩诊断**：BL 后验 μ std=0.031 vs 历史 μ std=0.162（收缩 5 倍），极端 μ 估计向市场均衡回归

**BL+MVSK 联合优化方向正确且已验证**。γ_s=0.1/γ_k=0.05 + BL(动量观点, confidence=0.3, τ=0.05) 是当前最优配置。测试期虽全亏（下跌行情），但相对表现清晰：BL+MVSK 最优，证明 BL+MVSK 的协同效应在样本外持久。

## 五、P2/P3 落地计划（2026-08-17 三阶段搜索后修订）

### P2：BL+MVSK 联合优化（中等风险，~1.5 周）

**背景修订**：三阶段搜索发现样本外失效根因是 μ 估计不稳定（Markowitz's Curse），非高阶矩计算效率。P2 从"YAND 核心算法"改为"BL+MVSK 联合优化"。

**核心思路**：Black-Litterman 后验 μ（稳定）+ MVSK 高阶矩优化（改善分布）双管齐下
- BL 把不稳定的历史 μ 和稳定的市场均衡（隐含收益 Π=δΣw_mkt）融合 → 后验 μ 更稳健
- MVSK 用 BL 后验 μ + return_matrix 优化 → 既稳 μ 又改善分布

**实现步骤**：
1. 训练期算历史 μ_hist, cov, 市场均衡 w_mkt（等权或市值加权）
2. 构造 BL 观点：动量信号（过去 60 日累计收益）作为弱观点，confidence=0.3
3. BL 后验 μ_post = BL(Π, views, Σ, τ)
4. MVSK 优化：用 μ_post + return_matrix 进 `risk_budget_optimizer.py`（γ_s=0.1, γ_k=0.05）
5. 样本外验证：train 376 / test 126，对比 MV/MVSK/BL+MV/BL+MVSK/等权

**接入点**：`utils/black_litterman_optimizer.py`（已有 BL）+ `utils/risk_budget_optimizer.py`（P1 已扩展 MVSK），新建 `research/bl_mvsk_joint.py` 联合编排

**验证标准**：BL+MVSK 样本外夏普 > MV 样本外夏普，且样本外峰度 < MV 样本外峰度

## 七、SC-28：RegimeDetector 数据源失败路径 fail-closed（2026-09-12，Issue #13）

> 修订指针：`cairn/LOG.md` 2026-09-12 条目；审查报告 §03 SC-28 / §05 缺口3。

- **发现**：`RegimeDetector.detect` 无输入校验，`_compute_moments` 对非有限值不做处理。NaN 同时使 `m2 <= 0`（恒 False）与阈值比较（`vol_rank >= q` / `kurt > t` 恒 False）失效 → **数据源失败被静默判成 `LOW_VOL_NORMAL` / `use_mvsk=False`**，且 `volatility`/`excess_kurtosis` 输出 NaN、零告警。
- **实跑（旧码）**：全 NaN `(150,3)` → `low_vol_normal` / vol=NaN / trigger=normal；含 ±inf 同；空数组同；标量输入直接 `IndexError`。
- **影响面**：`research/regime_fixed_backtest.py`、`research/regime_switch_backtest.py` **仅消费 `use_mvsk`** → 数据故障静默回退 MV，回测结论被静默污染（与 §六 P3/P4 结论同源消费点）。
- **修复契约（唯一事实源 = 代码）**：
  - `Regime.UNKNOWN` 新枚举值；`RegimeResult.data_available`（默认 True 向后兼容）+ `unavailable_reason`。
