## 核心原理

分数阶差分 Δ^d x_t 在保持记忆性的同时实现平稳:

- d=0: 原始序列 (完全记忆, 非平稳)
- d=1: 一阶差分 (无记忆, 平稳) — 等价于对数收益
- d ∈ (0, 1): 部分记忆 + 平稳 (最优折中)

公式:
```
Δ^d x_t = Σ_{k=0}^{∞} w_k × x_{t-k}
w_0 = 1, w_k = w_{k-1} × (k - 1 - d) / k
```

权重衰减速度 ~ k^(-d-1)，d 越小衰减越慢 (记忆越长)。

## 实现要点

### 1. 权重计算 (compute_weights)

- 递推: w_k = w_{k-1} × (k-1-d) / k
- 停止条件: |w_k| < threshold (默认 1e-5)
- d=0: weights = [1, 0] (2个)
- d=1: weights = [1, -1, 0] (3个, 含尾部零)
- d=0.4: weights ≈ 1000个 (衰减慢)

### 2. 差分计算 (differencing)

- **标准模式** (n_w ≤ n): 从 t=n_w-1 开始, 完整权重窗口
- **截断模式** (n_w > n): 从 t=0 开始, 部分权重窗口 (短序列处理)
- **尾部零权重去除**: d=1.0 时 w_2=0, pop 后 n_w=2, 确保 d=1 等价于 np.diff

### 3. 平稳性检验 (_check_stationarity)

**方差比检验** (替代自相关检验):

```
VR = var(Δx) / (2 × var(x))
```

- 平稳序列: VR > 0.05 (有均值回归)
- 单位根 (随机游走): VR ≈ 0 (var(x) 随时间增长)

**踩坑记录**: 最初用一阶自相关 < 0.99 判断, 但随机游走 n=200 的自相关 ≈ 0.997, 会被误判为平稳。方差比检验更可靠。

### 4. 最优 d 搜索 (find_optimal_d)

- 目标: 在平稳性约束下最大化记忆保持 (最小化 d)
- 搜索: d ∈ [0, 1] 网格搜索, 找到第一个平稳的 d

## 验收标准

| 标准 | 状态 | 验证 |
|------|------|------|
| 记忆保持 | ✅ | 分数阶差分 memory_retained = 1-d > 0, 对数收益 = 0 |
| 平稳性 | ✅ | 方差比检验 VR > 0.05 |
| 4指数回测 | ✅ | 沪深300/中证500/创业板/上证50 全部平稳, 平均记忆70% |

## 与对数收益的对比

| 指标 | 对数收益 (d=1) | 分数阶差分 (d=0.4) |
|------|---------------|-------------------|
| 记忆保持 | 0% | 60% |
| 平稳性 | 平稳 | 平稳 |
| 信息保留 | 仅增量 | 增量 + 部分历史 |

分数阶差分在保持平稳性的同时保留了 60% 的历史记忆, 优于对数收益的 0% 记忆。
