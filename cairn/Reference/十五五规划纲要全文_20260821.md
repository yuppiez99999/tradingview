## 二、主要目标（第三章）

| 目标 | 量化指标 |
|---|---|
| 高质量发展 | GDP 增长保持在合理区间；居民消费率明显提高 |
| 科技自立自强 | 研发经费投入年均增长 **7%以上** |
| 人民生活品质 | 城镇调查失业率低于 **5.5%**；劳动年龄人口平均受教育年限 **11.7年**；人均预期寿命 **80岁** |
| 美丽中国 | 单位 GDP CO2 排放降低 **17%**；PM2.5 降至 **27μg/m³以下**；优良水体比例 **85%**；森林覆盖率 **25.8%** |
| 国家安全 | 粮食综合生产能力 **1.45万亿斤**；能源综合生产能力 **58亿吨标准煤** |
| 2035 远景 | 人均 GDP 达到中等发达国家水平 |
