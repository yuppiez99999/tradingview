### 2030 年目标
- 大型现代化煤矿产能比重提升至 **87%**

- 现代煤炭产业体系基本建成

### 九大重点任务
1. 优化煤炭开发空间布局（东中西梯级）

4. **煤矿智能化迭代升级**（AI 场景化应用）
5. 绿色低碳转型（煤矸石/矿井水/煤层气/煤炭与新能源融合）
6. 清洁高效利用（煤电转型升级/原料化利用）
7. 科技创新能力
8. 安全生产管理
9. 行业治理现代化

### 五大重大工程
煤炭供应保障基地 / 智能化迭代升级 / 煤炭与新能源融合 / 商品煤质量提升 / 技术装备创新

## 5. 《新型电力系统建设"十五五"规划》正文（发改能源〔2026〕942号）

> 来源: 经济日报 2026-08-17 https://www.nea.gov.cn/20260817/43f478dfe4724af583286b61f36dfa04/c.html
> 来源: 人民日报海外版 2026-08-07 https://www.nea.gov.cn/20260807/34bfc6ca545f4627b2a1c1f00462c141/c.html
> 通知页: https://www.ndrc.gov.cn/xxgk/zcfb/tz/202608/t20260803_1406883.html | 2026-08-03

### 2030 年目标
- 非化石能源发电量占比 **50%**（2025 年 42.3%）
- 非化石能源发电装机占比 **65%**
- 新型电力系统**初步建成**
- 28 亿千瓦以上新能源高水平消纳
- 支撑超过 **1.1 亿辆**电动汽车出行充电网络
- 虚拟电厂最大调节能力超过 **5000 万千瓦**
- "西电东送"规模突破 **4.2 亿千瓦**
- 新增省间电力互济能力 **4000 万千瓦**

### 2030 年装机目标
| 类别 | 目标 |
|---|---|
| 常规水电 | 4.1 亿千瓦 |
| 核电 | 1.1 亿千瓦 |
| 抽水蓄能 | 1.6 亿千瓦 |
| 生物质/光热/地热/海洋能 | 6500 万千瓦 |

### 五方面协同推进
1. **迈向清洁低碳**: 绿色低碳电力供给格局 + 风光水核多能并举 + 新一代煤电改造
2. **迈向安全充裕**: 主配微协同新型电网 + 电力供应保障 + 安全治理体系
3. **迈向经济高效**: 城乡用电保障 + 充电服务保障 + 清洁取暖 + 供电服务质量
4. **迈向供需协同**: 虚拟电厂 + 节电降碳 + 绿电应用 + 电气化水平
5. **迈向灵活智能**: 抽水蓄能 + 新型储能 + 煤电向调节性电源转型 + 车网融合 + AI 赋能

### 电力流向格局
- 东北/中北/西北"沙戈荒"基地群 + 西南水风光一体化基地群 → 东中部/川渝/南方负荷中心
- 海上风电基地 + 沿海核电基地 → 就近消纳
- 配网支撑 9 亿千瓦分布式新能源接入

### "电力+"融合
- **电力+算力**: 绿电直供算力负荷（大唐宁夏中卫永康 500MW 风电绿电直供算力）
- **电力+交通**: 充电基础设施 + 车网融合
- **电热/电氢**: 绿电制氢 + 非电利用

**对量化系统启示**: 
- 长江电力 — 常规水电 4.1 亿千瓦直接命中，补 alignment（绿色低碳 85）
- 宁德时代 — 新型储能 + 28 亿千瓦新能源消纳 + 1.1 亿辆充电网络，补 alignment（绿色低碳 90）
