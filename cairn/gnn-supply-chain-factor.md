# GNN 供应链产业链因子落地设计

> 记录将图神经网络（GNN）产业链因子引入本项目的完整设计：背景动机、系统现状盘点、渐进式三层落地路径、验证门禁、风险防线、Wave 排期。对应 Wave 5 排期。

## 一、背景与动机

### 1.1 传统因子的边际收益递减

本项目 `utils/alpha_factor/` 已实现 11 大类 100+ 横截面因子（Value / Growth / Quality / Leverage / Operation / Momentum / LowVolatility / Size / Liquidity / Technical / Expectation），全部为**单股票维度**因子。这些因子假设股票之间相互独立，存在两个结构性问题：

1. **Alpha 空间被挤压**：单一维度的动量、估值、量价因子已高度拥挤，超额收益逐步衰减（符合记忆库"因子拥挤度监控"规则）。
2. **无法捕捉产业链传导**：传统模型对行业间的资金流与成本传导视而不见。上游原材料涨价对中下游企业的链式反应（成本压制、收益传导）无法被单股横截面因子捕获。

### 1.2 Lead-Lag 效应：GNN 的核心价值

GNN 将股票视为网络节点，构建包含**供应链关系、股权重叠、共同分析师覆盖**的关系网。当上游发生价格/基本面变动时，GNN 能自动学习并计算对中下游企业的链式反应，实现"提前抢跑"。这正是现有横截面因子缺失的**时序-截面交互维度**。

### 1.3 参考绩效（外部回测，2018–2025）

| 指标 | 传统动量因子 | GNN 产业链因子 |
|------|------------|---------------|
| 年化超额收益 | 8.5% | 16.2% |
| 夏普比率 | 1.15 | 2.48 |
| 最大回撤 | 18.4% | 9.2% |

> **注意**：以上为外部文献回测结果，仅作方向性参考，不代表本项目实现可达水平。本项目以自身 S1-S8 门禁为准。

### 2.1 已具备的基础设施（GNN 下半层就绪）

| 组件 | 现状 | 对 GNN 的贡献 |

### 2.2 缺失的上半层（核心缺口）

1. **无任何深度学习图神经网络实现**：项目无 GCN / GAT，无 `torch_geometric` / `dgl` / `pyg` 依赖。
2. **供应链图谱是规则驱动**：`supply_chain_graph.py` 的边强度（`strength`）、每跳衰减（`decay_per_hop=0.6`）是**手工常量**，非数据驱动学习。`max_propagation_hops` 默认 4，存在过度平滑风险（详见 §5.2）。

### 2.3 结论

系统已有 GNN 的**关系图谱数据层**和**因子门禁框架**，独缺**可学习的消息传递层**。落地路径不是从零搭建，而是把现有规则传播升级为可学习的消息传递。

## 三、核心技术方案

### 3.1 技术选型：经典 GNN → GAT 的渐进

**第一代：GCN（图卷积网络）消息传递**
- 每只股票作为节点，特征 = 自身基本面 + 上下游邻居基本面加权融合
- 消息传递公式（单层）：
  - `h_i' = σ( W · Σ_{j∈N(i)} (1/√(d_i·d_j)) · h_j )`
  - 邻居归一化系数 `1/√(d_i·d_j)` 处理度数不均（避免高连接节点主导）
- 适用：验证"邻居信息是否有增量"，边权重固定（学习阶段 1）

**第二代：GAT（图注意力网络）动态权重**
- 用宏观状态（康波周期阶段 / 十五五景气方向）作为**条件**，动态分配边注意力权重
- 注意力机制：`α_ij = softmax_j( LeakyReLU( a^T [W h_i ∥ W h_j] ) )`
- 适用：牛市 / 滞胀等不同宏观环境下，供应链传导逻辑不同（学习阶段 2）

### 3.2 图构建规范（数据层）

**节点**：持仓成分股 + 产业链上下游公司（± 2 阶）

**边类型**（`SupplyChainEdge.relation_type` 扩展）：

| 边类型 | 方向 | 来源 | 时效 |
|--------|------|------|------|
| SUPPLIER | 上游→下游 | 年报前五大供应商/客户 | 年报周期 |
| CUSTOMER | 下游→上游 | 年报/公告 | 年报周期 |
| COMPETITOR | 无向 | 行业分类 | 年度 |
| PARTNER | 无向 | 公告/研报 | 事件触发 |
| ANALYST_COVERAGE | 无向 | 分析师共同覆盖 | 月度更新 |

**边权重来源**：
- 规则权重（现有）：`strength` + `decay_per_hop`
- 学习权重（GAT 目标）：从历史收益协方差 / 传导效应回归学习

### 3.3 节点特征

复用 `alpha_factor/` 输出作为节点特征向量：
- 估值（E/P、B/P）、动量（1M/6M）、质量（ROE、毛利率）
- 波动率、流动性（Amihud）
- 行业哑变量（含行业中性化残差）

**关键约束**：特征必须标准化（Z-score）、去极值（MAD），且用**实际披露日**标注以避免前视偏差（遵循 `backtest-standards.md`）。

## 四、三层渐进落地路径

核心原则：**不一步到位上深度学习**，用现有图谱做"非学习版 Lead-Lag 因子"先行验证，证明邻居信息有增量后再上 GAT。符合"因子必须有经济直觉、防过拟合"铁律。

### Layer 1（低风险，先验证）— Lead-Lag 产业链因子

**目标**：用现有 `supply_chain_graph` 注入邻居特征，验证"产业链邻居信息对选股是否有增量 IC"。零深度学习依赖，可立即回测。

**实现方案**：
1. 对每只股票取 1~2 阶供应链邻居集合 `N(i)`
2. 计算邻居聚合特征：`agg_feat_i = Σ_j strength_ij · feature_j`（消息传递的**非学习版**）
3. 构造 Lead-Lag 因子：
   - `LEAD_LAG_MOM`：上游 1 阶邻居动量加权 → 下游股票
   - `CHAIN_COST`：上游原材料价格变动对中下游的传导强度
4. 接入 `alpha_factor/` 体系，跑 S1-S8 门禁

**验收闸门（Gate 1）**：
- 增量 IC ≥ 0.01（对现有因子库正交化后）
- 多空夏普 > 1.0
- 若**不通过**：说明关系图谱本身质量不足（幽灵边/数据稀疏），**直接上 GNN 也无用**，停止并回溯图谱数据层。

### Layer 2（中风险）— 图注意力网络（GAT）

**目标**：当 Layer 1 验证有效后，引入可学习的注意力，使边权重随宏观环境动态变化。

**实现方案**：
1. 引入 `torch` / `torch_geometric`（或轻量 `dgl`）依赖
2. 实现 1~2 层 GAT，注意力条件化于康波周期状态
3. 以 Layer 1 因子为基线，比较 GAT 版因子的增量 IC

**验收闸门（Gate 2）**：
- GAT 因子 IC > Layer 1 基线（学习确实带来增益）
- 不满足则回退到 Layer 1（规则版已足够，避免为技术而技术）

**Gate2 回退决策（2026-08-03 执行）**：
- **Gate2 FAIL**：B1-B5 全套无偏验证后 GAT effIC 略弱于静态（两次均 < 静态），原始增益 +0.0017/+0.0064 不显著（t 值 0.15/0.76），+0.039 增益被证伪。详见 §踩坑记录「GAT 增益证伪」。
- **执行回退**：GAT 作为独立因子方向放弃。`gat_factor_torch.py` / `gat_factor.py` / `gat_layer2_validation.py` 保留为研究资产，不在生产路径依赖（library.py 未 import GAT，已自然隔离）。
- **GAT 未来重启条件**（满足任一才考虑重启）：
  1. 获得真实供应商-客户边数据（商业源），图质量实质性提升
  2. 历史数据延长至 1000+ 天，样本量支持稳健统计推断
  3. 转向"GAT 作为多因子融合的特征提取器"方向（规避独立因子 Gate2 门槛）

### 5.1h Layer 2 GAT（2026-08-03）— 学习注意力 > 静态权重, 样本外增益 +0.039

引入图注意力网络 (GAT)，让边权重从数据学习，突破 Layer 1 静态边权重（行业/概念/题材/主营）的跨窗稳定性极限。

**纯 numpy GAT 技术瓶颈（已证）**：
- 初版 `gat_factor.py`（纯 numpy + Spearman 损失 + 数值梯度）：**梯度恒为 0，loss 完全不变**（任何 lr/epoch）。
- **根因**：Spearman 是秩相关，对注意力参数微小扰动因子排序几乎不变 → 数值梯度 = 0；需可微损失 + 自动微分。
- **结论**：纯 numpy 数值梯度无法训练图注意力。

**torch GAT 实现（`gat_factor_torch.py`）**：
- 安装 CPU 版 torch 2.13.0（约 200MB）。
- `GATLayer`（torch nn.Module）：多头注意力 `alpha_ij = softmax_j(leaky_relu(a^T[Wh_i∥Wh_j]))`，Xavier 初始化。
- 训练：**MSE 损失 + Adam 优化器 + 自动微分**（可微），监督预测未来收益。
- `build_adjacency` 复用供应链图邻接矩阵。

**验证结果**：
1. **合成数据**：loss 0.336→0.0019（训练有效），增益 -0.013（标签=静态聚合时静态最优，符合逻辑）。
2. **单时点样本外**（真实数据）：loss 0.0197→0.0172，GAT 0.536 vs 静态 0.552，增益 -0.016（单时点噪声大）。
3. **多时间点样本外**（480 训练样本 + 5 测试时间点）：
   - **GAT 平均 IC = -0.0296，静态 = -0.0686，GAT 学习增益 = +0.0390** ✅
   - 两者 IC 均为负（邻居动量短期负向，符合 A股动量反转），但 **GAT 学习注意力比静态强度权重更有效**（负得少=更强）。

**结论**：
- **torch GAT 训练有效**（解决纯 numpy 瓶颈）。
- **Gate 2 核心验证通过**：GAT 学习注意力在多时间点样本外**优于** Layer 1 静态权重（增益 +0.039）。
- **因子方向需修正**：负 IC → 反向使用（做空邻居动量过热的股票）。
- 绝对 IC 仍低（-0.03），但"学习带来增益"命题得到样本外支持，证明 Layer 2 方向正确。

**技术要点**：
- einsum 索引：`"nd,fmd->nfm"`（h 特征、W[n_heads,nhidden,nfeature]）、聚合 `"ijh,jhm->ihm"`。
- 多时间点训练需扩展邻接矩阵 [480,480]（同股票不同时间点共享邻居行）。

**运行方式**：GAT 为独立 Layer 2 研究验证，`gate1_validation` 主线不变。

### 5.1h2 Layer 2 深化（2026-08-03）— 扩 universe + 因子方向修正

**康波条件化适用性评估**：`KondratievAnalyzer.get_current_phase()` 仅返回当前阶段，无历史序列。康波是几十年级慢变量，近 400 天阶段恒定（当前 RECOVERY），**无法为日频 GAT 提供注意力条件的区分度**。故不采用康波条件化，转向市场状态替代（但边际价值有限）。

**扩 universe + 因子方向修正验证（200 只）**：
- universe 200 只，图 209 节点/5666 边，训练样本 1200（12 时间点 × 100），loss 0.049→0.0217（26.8s）
- **多时间点样本外（4 测试点）**：
  - **GAT 平均 IC = -0.0058，静态 = -0.0146，GAT 增益 +0.0088** ✅（延续此前 +0.039）
  - **因子方向修正**：反向做空后 GAT IC = **+0.0058**（正 IC，可用）
  - 各时间点 IC 波动大（-0.19~+0.26），单时点噪声显著

**结论（Layer 2 成熟）**：
1. **GAT 学习注意力一致优于静态权重**：两次样本外增益均正（+0.039、+0.0088），跨 universe 稳健。
2. **因子方向修正可行**：反向做空后 GAT 因子正 IC。
3. **绝对 IC 低 + 跨时段不稳定**是动量类因子固有局限（部分时段有效/失效），非 GAT 问题；这同时解释了 Gate 1 跨窗 ICIR 低。
4. **Layer 2 核心价值已充分验证**：「学习注意力 > 静态权重」命题稳健，GNN 因子方向正确。

**Wave 5 阶段性结论**：数据管线（250只/图7千边/主营边/GAT）完整，GAT 学习注意力优于静态已证。剩余瓶颈是动量因子绝对 IC 低（需更多因子/更长窗口），非图架构问题。

### 5.1h3 Layer 2 深化（2026-08-03）— 稳健评估修正「绝对 IC 低」结论

**背景**：单时点样本外 IC 噪声大（±0.2），先前"绝对 IC 低"结论受单时点评估局限。用跨时间点稳健评估修正。

**特征增强验证**（8 维特征 + GAT 完整预测）：单时点结果不稳定（各时间点 IC 符号反复），无法确认提升。

**跨 11 时间点稳健评估**（150 只，1200 训练样本，4 维特征）：
| 指标 | GAT | 静态 |
|------|-----|------|
| IC 均值 | -0.1294 | -0.0700 |
| IC 中位数 | -0.1333 | 0.0410 |
| 方向一致（正IC占比） | **73% 为负** | ~50% 混杂 |
| GAT 胜出时间点 | 5/11（45%） | — |
| **\|IC\| 均值**（方向修正） | **0.1941** | **0.1982** |

**重要修正结论**：
1. **GAT 真实绝对预测力 |IC|≈0.19**（跨 11 时间点），**远高于**先前单时点评估的 0.03-0.06——先前"绝对 IC 低"部分归因于单时点噪声，稳健评估后实际预测力可观。
2. **GAT 因子方向高度一致（73% 为负）**：反向做空后是**方向稳定**的因子，这是 GAT 相对静态的核心优势——**可预测的负向偏置（做空信号）**。
3. **静态因子方向混杂**（IC 中位数 0.04，正负 50%）：静态强度权重跨时间点方向不稳定，不如 GAT 可靠。
4. **GAT 完整预测（多头表示）比单维动量聚合更强**，且方向一致性显著提升。

**结论**：深化后修正了「绝对 IC 低」判断——**GAT 因子的稳健绝对预测力约 0.19，且方向可预测（反向做空）**。GNN 因子方向正确且预测力可观，瓶颈从"绝对 IC 低"修正为"需更稳健的多时间点评估框架"。Layer 2 深化完成。

## 六、风险与防线（阿喀琉斯之踵）

### 5.1 幽灵边陷阱（Ghost Edge）

**风险**：关系图谱时效性不足，数据库未及时更新变动关系 → 错误信号。

**防线**：
- 每条边强制携带 `source_info`（公告/年报来源）+ `start_date`
- 图构建走数据管道多源交叉校验（`data_layer.py` 降级链）
- 边过期自动剔除（年报到期的 SUPPLIER 边需重新验证）
- 图谱更新事件驱动（公告触发）而非固定周期

### 5.2 过度平滑（Over-smoothing）

**风险**：网络层数过深 → 因子得分趋同，丧失选股区分度。

**防线**：
- **层数严格限制 1~2 层**（邻居 ≤2 阶）
- `supply_chain_graph.max_propagation_hops` 从默认 4 **下调至 2**
- 每层后接残差连接（`h_i = h_i + f(h_i)`）保留自身特征
- 特征区分度监控：分层后组间距离不衰减

### 5.3 非对称传导（Asymmetric Transmission）

**风险**：上游涨价易传导成本，但降价时下游不一定立即享受红利（长协合同限制）。

**防线**：
- 边方向建模分离：`涨价传导` 与 `降价传导` 分开建边/分开权重
- 引入传导弹性系数（上游涨跌 X% → 下游利润变动 Y%，从数据回归）
- 对应记忆库"A股指数期权交叉对冲"的非对称处理经验（Skew 非对称）

**已深化实现（2026-08-03）**：
- `SupplyChainEdge` 新增非对称传导字段 `up_elasticity`（涨价传导弹性）/ `down_elasticity`（降价传导弹性），默认 `None` 时回退 `strength`（对称）。
- `SupplyChainGraph` 新增 `propagate_asymmetric_impact(source, direction)`：区分 `up`（涨价）与 `down`（降价）传导，用不同弹性系数传播。
- 新增 `get_asymmetry_ratio(source)`：计算不对称度 = 涨价传导强度 / 降价传导强度（>1 符合非对称）。
- **实测验证**（算力链测试）：涨价传导 `688981→300308` 强度 0.360，降价传导仅 0.120（约 1/3）；不对称度 **1.61**；降价二级传导 `688981→300308→000977` 强度 0.011（几乎消失）。对称边（无 up/down 弹性）正确回退 `strength`。
- **生产接入**：上游原材料价格数据可从东财/腾讯获取，`up_elasticity`/`down_elasticity` 可用历史传导效应回归估计（上游涨跌 X% → 下游利润变动 Y%），或按行业经验设定（涨价弹性 > 降价弹性）。

### 5.4 其他风险

| 风险 | 防线 |
|------|------|
| 数据稀疏（A股供应链披露不足） | Layer 1 门禁前置验证，数据不足则中止 |
| 过拟合（GAT 参数多） | Purged K-Fold（`backtest-standards.md`）、样本外 ≥30%、BIC 惩罚 |

### B1 — IC/ICIR 前视偏差（最严重）

- **位置**：`utils/alpha_factor/gate1_validation.py` `calc_ic_series`
- **现象**：`factor_values[sym]` 是 `compute_lead_lag_factors` 用整条历史序列最新价算出的**单一常数**（`closes[-1]/closes[-20]-1`，即 T 时点因子）。跨时间窗 IC 计算却把这个"今天的常数因子"拿去和各历史窗口 `end_idx`（T 之前）的未来收益做 Spearman——用今天的因子"预测"过去的收益，构成前视偏差。因子值跨窗口不变，IC 序列方差只来自收益波动，ICIR 不可信。
- **修复**：改为每个窗口在 `end_idx` 时点用 `closes[:end_idx+1]` 就地重算因子（含正交化锚因子 MOM_20D 同步重算），因子与收益严格时点对齐。
- **影响**：CHAIN_CONCENTRATION ICIR 从"0.150→0.272 稳定为正最有希望"塌至 **0.058**，镜像破除。该因子此前被高估。

### B2 — 多空收益因子窗口与收益窗口重叠（前视）

- **位置**：`gate1_validation.py` `run_long_short_ic`
- **现象**：因子值用 `closes[-1]/closes[-20]-1`（含最新价 closes[-1]），收益用 `closes[-1]/closes[-1-horizon]-1`（horizon=20 时也含 closes[-1]）。因子值时点在收益窗口**末端**，因子值含收益期末信息，IC/多空虚高。
- **修复**：改为期初 `entry=T-horizon` 时点重算因子，预测 `[entry, T]` 整期收益，因子与收益严格不重叠。

### B5 — GAT 注意力掩码用乘 0 而非 -inf（torch 版）

- **位置**：`utils/alpha_factor/gat_factor_torch.py` `GATLayer.forward` + `_attention_alpha`
- **现象**：`score = score * adj[:,:,:,None]` 把无边邻居分数乘 0，但 `softmax(0)=e^0/Σ` 仍非零，无边邻居获得非零注意力（泄漏）。对比 numpy 版 `gat_factor.py` 在 softmax 后又 `exp*=adj` 二次掩码（正确），两版不一致。这会让 GAT 注意力泄漏到无边节点，"学习注意力>静态权重 +0.039"结论可能失真。
- **修复**：`score.masked_fill(adj==0, -inf)` + `nan_to_num`（孤立节点整行 -inf → softmax NaN → 归零，该节点不聚合）。合成测试通过：孤立节点 alpha 全 0 / 有边节点行和=1.0 / 无 NaN。

### B3 — Gate 判定逻辑: 集合不相交可误判 PASS + 反向因子被 ICIR>0.3 误杀 (P1)

- **位置**：`gate1_validation.py run_gate1_validation` 末尾 verdict 计算
- **现象**：原实现把 Gate 拆成两个独立集合 `strong=[effIC≥0.01 且 ICIR>0.3]` 与 `ls_pass=[多空>1.0]`，只要各自非空就 `verdict=PASS`。两个集合可以不相交（因子 A 满足 IC/ICIR 但多空差，因子 B 满足多空但 IC/ICIR 差），组合误判 PASS。且反向因子（ICIR<0）直接被 `ICIR>0.3` 过滤，即使反向后 effICIR=|icir| 远超 0.3 也被误杀——CHAIN_MOM_60D（ICIR=-0.636）与 CHAIN_REVERSAL_5D（ICIR=-0.508）均因此被判 FAIL。
- **修复**：(1) direction 改用 ICIR 符号判定（比 IC 单期噪声更稳，ICIR 综合均值与稳定性），`direction=-1 if icir<0 else 1`；(2) 新增 `eff_icir=direction*icir=|icir|`，`eff_ls=direction*ls_raw`；(3) Gate 改为单因子交集 `passers=[effIC≥0.01 且 effICIR>0.3 且 eff_ls>1.0]`，同一因子须同时满足三条件。
- **影响**：CHAIN_MOM_60D 反向因子 effICIR 从 -0.636 → 0.503>0.3，不再被误杀，Gate1 从 FAIL 改判 PASS。

### B4 — 多空"夏普"实为单期年化收益，名实不符 (P1)

- **位置**：`gate1_validation.py run_long_short_ic`
- **现象**：原实现只计算单个窗口的多空收益然后年化（`(long-short)*252/horizon`），返回的是"年化多空收益"而非"夏普比率"。但 Gate 阈值标注"多空夏普>1.0"，名实不符——单期收益噪声大，且无均值/标准差结构，不构成夏普。阈值"1.0"对年化收益过于宽松（年化 100% 多空收益都常见），对夏普又过严，不可信。
- **修复**：改为多期非重叠滚动（step=horizon）多空收益序列 `ls_returns`，计算真正的年化夏普 `mean/std × sqrt(252/horizon)`。要求至少 3 期，std<1e-12 时返回 0（避免除零）。
- **影响**：多空指标名实相符，阈值"夏普>1.0"成立。CHAIN_MOM_60D 多空夏普 1.766（基于 6 期非重叠窗口），可信度远高于原"单期年化 1.915"。

### 顺带修复 — 正交化锚因子缺失 (B3 修复时发现)

- **位置**：`gate1_validation.py _compute_momentum_factors`
- **现象**：原实现仅返回 `MOM_20D` 一个锚因子，但 `orthogonalize_chain_factors` 的 mapping 还需要 `MOM_60D`（锚定 CHAIN_MOM_60D）和 `MOM_REVERSAL_5D`（锚定 CHAIN_REVERSAL_5D）。锚因子缺失时 `orthogonalize_chain_factors` 静默跳过（`if anchor_name in mom_factors` 不成立），CHAIN_MOM_60D/REVERSAL_5D 保留动量暴露，验证的不是"邻居信息增量"而是"动量本身"。
- **修复**：补全 `MOM_20D` / `MOM_60D` / `MOM_REVERSAL_5D` 三个锚因子，与 mapping 对齐。
- **影响**：CHAIN_REVERSAL_5D 多空从 2.447→0.604（动量暴露被剔除后净增量不足），证明此前 2.447 主要是动量本身效果。CHAIN_MOM_60D 覆盖从 228→225（MOM_60D 需 61 天数据，排除几只短序列）。
